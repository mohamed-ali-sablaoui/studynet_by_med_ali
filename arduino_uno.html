Maîtriser Arduino Uno, pas à pas

Un cours pédagogique en français pour comprendre les composants, réaliser des branchements sûrs, programmer la carte et prévoir le résultat de chaque expérience. Chaque exemple contient le code, l'explication des instructions et le résultat attendu.

Comment suivre le cours ?

  1. Lis l'objectif et identifie les composants nécessaires.
  2. Débranche l'USB avant de modifier un câblage.
  3. Reproduis le montage, puis copie le code dans Arduino IDE.
  4. Sélectionne la carte Arduino Uno et le bon port série.
  5. Lis l'explication ligne par ligne, téléverse le code et compare avec le résultat attendu.
À savoir : tu peux étudier et compiler le code sans matériel, mais pour observer les composants, il faut une carte Arduino ou un simulateur compatible.
Leçon 1

Découvrir la carte Arduino Uno

Arduino Uno est une carte électronique programmable. Elle reçoit des informations de capteurs ou de boutons, traite ces informations grâce à son microcontrôleur, puis commande des composants comme des LED, un buzzer ou un servomoteur.

ÉlémentRôleExemple
Microcontrôleur ATmega328PExécute le programme.Décider d'allumer une LED.
Broches numériques D0 à D13Lire un état logique ou commander une sortie.Bouton sur D2, LED sur D8.
Entrées analogiques A0 à A5Mesurer une tension analogique.Potentiomètre sur A0.
Broches PWM marquées ~Produire un signal PWM pour varier la puissance moyenne.Faire varier la luminosité d'une LED.
5V, 3.3V, GNDAlimentation et référence électrique.Alimenter un capteur compatible.
Port USBEnvoyer le programme et communiquer avec l'ordinateur.Téléverser le sketch.
Bouton RESETRedémarrer le programme.Recommencer depuis le début.
À retenir : GND est la masse, la référence électrique de 0 V. Les éléments d'un circuit doivent partager la même référence GND lorsque le montage l'exige.
Leçon 2

Électricité et sécurité

Un circuit doit former une boucle électrique. Une LED est polarisée : la patte longue est généralement l'anode (+) et la patte courte la cathode (−). Une résistance en série limite le courant qui traverse la LED.

D8 ── résistance 220 à 330 Ω ── anode LED (+) cathode LED (−) ── GND

Tension (V)

Différence électrique entre deux points. Exemple : 5 V.

Résistance (Ω)

Elle limite le courant. Pour les exercices avec une LED, une résistance de 220 Ω ou 330 Ω est courante.

Règles importantes :
  • Ne relie jamais directement 5V à GND : cela crée un court-circuit.
  • Ne branche jamais le secteur électrique sur les broches Arduino.
  • N'alimente pas directement un moteur depuis une broche Arduino.
  • Respecte les tensions et courants acceptés par chaque composant.
  • Débranche l'USB avant de modifier le câblage.
Leçon 3

Utiliser Arduino IDE

  1. Installe Arduino IDE depuis le site officiel Arduino.
  2. Branche la carte avec un câble USB qui transporte les données.
  3. Sélectionne Arduino Uno dans le menu de choix de carte.
  4. Sélectionne le port série associé à la carte, par exemple COM3 sous Windows. Le numéro peut varier.
  5. Clique sur Vérifier pour compiler le programme.
  6. Clique sur Téléverser pour envoyer le programme à la carte.
Vérifier et téléverser sont différents : « Vérifier » contrôle et compile le code ; « Téléverser » envoie le programme compilé à la carte.

Si aucun port n'apparaît, vérifie le câble, essaie un autre port USB et consulte le Gestionnaire de périphériques. Certains câbles ne servent qu'à recharger.

Leçon 4

Structure d'un programme Arduino

Un programme Arduino est souvent appelé un sketch. Il contient deux fonctions essentielles : setup() et loop().

Code 1 — Squelette minimal
void setup() {
  // Instructions exécutées une seule fois au démarrage
}

void loop() {
  // Instructions répétées en continu
}
Explication de chaque ligne
  • void indique que la fonction ne renvoie pas de valeur.
  • setup() s'exécute une seule fois après le démarrage ou un reset.
  • Les accolades { } encadrent les instructions d'une fonction.
  • // démarre un commentaire. Le compilateur ignore le texte du commentaire.
  • loop() recommence continuellement après la fin de setup().
  • Le point-virgule ; termine la plupart des instructions, mais pas la déclaration d'une fonction.
Résultat attendu : aucun composant n'est commandé et aucun message n'est affiché. Ce code constitue seulement la base d'un programme.
Leçon 5

Les instructions essentielles et les broches

Sur l'Arduino Uno classique, les broches PWM sont D3, D5, D6, D9, D10 et D11, marquées par le symbole ~. analogWrite() produit un signal PWM, et non une véritable tension analogique variable.

Leçon 6 • Première pratique

Faire clignoter une LED

Matériel : Uno, LED, résistance de 220 à 330 Ω, fils et breadboard. Branchement : D8 → résistance → anode de la LED ; cathode → GND. Une LED intégrée est également disponible sur de nombreuses cartes à D13.

Code 2 — LED clignotante
const int led = 8;

void setup() {
  pinMode(led, OUTPUT);
}

void loop() {
  digitalWrite(led, HIGH);
  delay(1000);
  digitalWrite(led, LOW);
  delay(1000);
}
Explication ligne par ligne
  • const int led = 8; crée une constante entière appelée led qui représente la broche 8. const signifie que sa valeur ne changera pas.
  • void setup() commence la fonction d'initialisation.
  • pinMode(led, OUTPUT); configure D8 comme sortie afin de commander la LED.
  • void loop() démarre la partie répétée en continu.
  • digitalWrite(led, HIGH); place la sortie à l'état haut : la LED s'allume dans ce montage.
  • delay(1000); attend 1000 millisecondes, soit une seconde.
  • digitalWrite(led, LOW); place la sortie à l'état bas : la LED s'éteint.
  • Le dernier delay(1000) garde la LED éteinte pendant une seconde. Ensuite, loop() recommence.
Résultat attendu : la LED s'allume pendant environ une seconde, s'éteint pendant une seconde, puis répète ce cycle. La période totale est d'environ deux secondes.

Leçon 7

Commander une LED avec un bouton poussoir

Dans cette version, le bouton est relié à 5V lorsqu'on appuie. D2 est aussi reliée à GND par une résistance de rappel de 10 kΩ. Cette résistance évite que l'entrée reste dans un état indéfini lorsque le bouton est relâché.

5V ─── bouton ─── D2 │ 10 kΩ │ GND D8 ── résistance 220–330 Ω ── LED ── GND
Code 3 — Bouton avec résistance externe
const int led = 8;
const int bouton = 2;

void setup() {
  pinMode(led, OUTPUT);
  pinMode(bouton, INPUT);
}

void loop() {
  int etatBouton = digitalRead(bouton);
  digitalWrite(led, etatBouton);
}
Explication ligne par ligne
  • Les deux constantes donnent les numéros de broches de la LED et du bouton.
  • pinMode(led, OUTPUT) permet à la carte de commander la LED.
  • pinMode(bouton, INPUT) configure D2 comme entrée. Le circuit de résistance externe fixe son état au repos.
  • int etatBouton = digitalRead(bouton); lit D2 et enregistre le résultat dans une variable entière.
  • digitalWrite(led, etatBouton); copie l'état logique lu vers la LED.
Résultat attendu : bouton appuyé → D2 est HIGH → LED allumée. Bouton relâché → D2 est LOW grâce à la résistance → LED éteinte.
Leçon 8

Utiliser INPUT_PULLUP

INPUT_PULLUP active une résistance de rappel interne. Le branchement est plus simple : une borne du bouton va à D2 et l'autre à GND. La logique est inversée : bouton relâché = HIGH, bouton appuyé = LOW.

D2 ─── bouton poussoir ─── GND La résistance de rappel est activée à l'intérieur de l'Arduino.
Code 4 — LED allumée pendant l'appui
const int led = 8;
const int bouton = 2;

void setup() {
  pinMode(led, OUTPUT);
  pinMode(bouton, INPUT_PULLUP);
}

void loop() {
  int etatBouton = digitalRead(bouton);

  if (etatBouton == LOW) {
    digitalWrite(led, HIGH);
  } else {
    digitalWrite(led, LOW);
  }
}
Explication ligne par ligne
  • INPUT_PULLUP active la résistance interne et maintient l'entrée à HIGH au repos.
  • digitalRead(bouton) renvoie HIGH lorsque le bouton est relâché et LOW lorsqu'il est appuyé.
  • if (etatBouton == LOW) teste si la valeur est LOW. Le symbole == compare deux valeurs ; il ne réalise pas une affectation.
  • Si la condition est vraie, la commande digitalWrite(led, HIGH) allume la LED.
  • else signifie « sinon ». Dans ce cas, la LED s'éteint.
Résultat attendu : la LED s'allume uniquement pendant l'appui sur le bouton. Le bouton doit être relié à GND, pas à 5V, dans ce montage INPUT_PULLUP.
Leçon 9

Lire un potentiomètre

Le potentiomètre est une résistance réglable à trois bornes. Relie une borne extérieure à 5V, l'autre à GND et la borne centrale (curseur) à A0.

5V ───── borne extérieure POTENTIOMÈTRE A0 ───── borne centrale (curseur) GND ───── autre borne extérieure
Code 5 — Lire une valeur analogique
const int potentiometre = A0;

void setup() {
  Serial.begin(9600);
}

void loop() {
  int valeur = analogRead(potentiometre);
  Serial.println(valeur);
  delay(200);
}
Explication ligne par ligne
  • potentiometre = A0 indique que le curseur est connecté à l'entrée analogique A0.
  • Serial.begin(9600) démarre la communication avec l'ordinateur à 9600 bauds.
  • analogRead(potentiometre) mesure la tension sur A0 et renvoie habituellement une valeur entre 0 et 1023 sur un Uno classique.
  • int valeur stocke le résultat dans une variable entière appelée valeur.
  • Serial.println(valeur) affiche le résultat puis passe à la ligne suivante.
  • delay(200) attend 200 millisecondes avant la prochaine lecture.
Résultat attendu : ouvre le Moniteur série et règle sa vitesse sur 9600 bauds. En tournant le potentiomètre, tu verras des valeurs proches de 0 à une extrémité et proches de 1023 à l'autre.
Leçon 10

Faire varier la luminosité avec PWM

Le PWM allume et éteint une sortie très rapidement. La proportion de temps pendant laquelle le signal est actif change la puissance moyenne envoyée à la LED. Utilise une broche PWM comme D9 et une résistance en série.

Code 6 — Variation progressive
const int led = 9;

void setup() {
  pinMode(led, OUTPUT);
}

void loop() {
  for (int luminosite = 0; luminosite <= 255; luminosite++) {
    analogWrite(led, luminosite);
    delay(10);
  }

  for (int luminosite = 255; luminosite >= 0; luminosite--) {
    analogWrite(led, luminosite);
    delay(10);
  }
}
Explication ligne par ligne
  • led = 9 choisit D9, une broche PWM de l'Uno classique.
  • for (int luminosite = 0; luminosite <= 255; luminosite++) crée une boucle : elle commence à 0, continue jusqu'à 255 et ajoute 1 à chaque tour.
  • analogWrite(led, luminosite) applique la valeur PWM. 0 correspond à une sortie inactive et 255 à la valeur maximale.
  • delay(10) attend 10 ms à chaque étape afin de rendre le changement visible.
  • La deuxième boucle commence à 255 et diminue jusqu'à 0 grâce à luminosite--.
Résultat attendu : la LED augmente progressivement de luminosité, atteint son maximum, puis diminue jusqu'à s'éteindre. Le cycle recommence.
Leçon 11

Détecter la lumière avec une LDR

Une LDR est une résistance sensible à la lumière. Avec une résistance fixe de 10 kΩ, elle forme un diviseur de tension. Le point central se branche sur A0. Selon le sens du montage, la mesure peut augmenter ou diminuer avec la lumière.

5V ─── LDR ───┬─── A0 │ 10 kΩ │ GND
Code 7 — Allumer la LED dans l'obscurité
const int capteurLumiere = A0;
const int led = 8;
const int seuil = 500;

void setup() {
  pinMode(led, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int lumiere = analogRead(capteurLumiere);
  Serial.println(lumiere);

  if (lumiere < seuil) {
    digitalWrite(led, HIGH);
  } else {
    digitalWrite(led, LOW);
  }

  delay(200);
}
Explication ligne par ligne
  • Les constantes définissent l'entrée A0, la LED sur D8 et un seuil de départ égal à 500.
  • analogRead(capteurLumiere) lit la valeur mesurée par le diviseur de tension.
  • Serial.println(lumiere) affiche la mesure afin de comprendre comment elle varie.
  • if (lumiere < seuil) teste si la mesure est inférieure à 500.
  • Si le test est vrai, la LED s'allume ; sinon, elle s'éteint.
  • delay(200) attend 200 ms avant de recommencer.
Résultat attendu : si la valeur diminue dans l'obscurité, la LED s'allume lorsque la mesure passe sous 500. Ce seuil est à ajuster après observation des valeurs. Si la valeur augmente dans le noir avec ton montage, inverse la condition.
Leçon 12

Produire un son avec un buzzer

Un buzzer passif compatible peut produire différentes notes grâce à tone(). Vérifie le type de buzzer et son courant : un composant qui consomme trop doit être commandé par un circuit pilote.

Code 8 — Deux notes et une pause
const int buzzer = 8;

void setup() {
}

void loop() {
  tone(buzzer, 1000);
  delay(500);
  tone(buzzer, 1500);
  delay(500);
  noTone(buzzer);
  delay(500);
}
Explication ligne par ligne
  • buzzer = 8 sélectionne la broche de commande.
  • tone(buzzer, 1000) génère un son d'environ 1000 Hz.
  • delay(500) laisse la note durer une demi-seconde.
  • tone(buzzer, 1500) change la fréquence : le son devient plus aigu.
  • noTone(buzzer) arrête le son sur cette broche.
  • La dernière pause crée un silence avant la répétition du cycle.
Résultat attendu : le buzzer produit une note, puis une note plus aiguë, puis un silence. La séquence recommence.
Leçon 13

Contrôler un servomoteur

Un servo de position possède généralement trois fils : alimentation, GND et signal. Les couleurs varient selon le modèle. Un servo peut demander plus de courant que la carte ne peut fournir : utilise si nécessaire une alimentation adaptée et relie les masses GND ensemble.

Le code suivant utilise la bibliothèque Servo, disponible dans l'environnement Arduino standard.

Code 9 — Positionner le servo
#include <Servo.h>

Servo monServo;

void setup() {
  monServo.attach(9);
}

void loop() {
  monServo.write(0);
  delay(1000);
  monServo.write(90);
  delay(1000);
  monServo.write(180);
  delay(1000);
}
Explication ligne par ligne
  • #include <Servo.h> importe les fonctions de commande des servomoteurs.
  • Servo monServo; crée un objet appelé monServo.
  • monServo.attach(9) associe le signal du servo à D9.
  • monServo.write(0) demande la position 0°.
  • monServo.write(90) demande la position 90°.
  • monServo.write(180) demande la position 180°.
  • Chaque délai d'une seconde laisse le temps d'atteindre la position demandée.
Résultat attendu : le servo se déplace successivement vers 0°, 90° puis 180°. L'angle réellement disponible dépend du modèle.
Leçon 14

Mesurer une distance avec HC-SR04

Le capteur HC-SR04 envoie une impulsion ultrasonore et mesure le temps de retour de l'écho. Branche VCC à 5V, GND à GND, TRIG à D9 et ECHO à D10. Cette connexion ECHO convient à l'Uno classique 5 V ; une carte 3,3 V peut nécessiter une adaptation de niveau.

Code 10 — Distance en centimètres
const int trig = 9;
const int echo = 10;

void setup() {
  pinMode(trig, OUTPUT);
  pinMode(echo, INPUT);
  Serial.begin(9600);
}

void loop() {
  digitalWrite(trig, LOW);
  delayMicroseconds(2);
  digitalWrite(trig, HIGH);
  delayMicroseconds(10);
  digitalWrite(trig, LOW);

  long duree = pulseIn(echo, HIGH, 30000);

  if (duree == 0) {
    Serial.println("Aucun echo detecte");
  } else {
    float distance = duree * 0.0343 / 2;
    Serial.print("Distance : ");
    Serial.print(distance);
    Serial.println(" cm");
  }

  delay(300);
}
Explication ligne par ligne
  • trig est la sortie qui déclenche la mesure ; echo est l'entrée qui reçoit l'écho.
  • pinMode() configure TRIG en sortie et ECHO en entrée.
  • Le signal TRIG reste LOW 2 microsecondes, puis HIGH 10 microsecondes, avant de revenir à LOW.
  • pulseIn(echo, HIGH, 30000) mesure la durée de l'impulsion reçue, avec un délai maximal de 30 000 microsecondes.
  • Si duree == 0, aucun écho n'a été détecté dans le délai imparti.
  • duree * 0.0343 estime le trajet aller-retour en centimètres, car le son parcourt environ 0,0343 cm par microseconde.
  • On divise par 2, car le son fait l'aller jusqu'à l'objet puis le retour vers le capteur.
  • Serial.print() affiche sans retour à la ligne ; Serial.println() termine la ligne.
Résultat attendu : le Moniteur série affiche par exemple « Distance : 24.6 cm ». Cette valeur est illustrative ; la mesure réelle dépend de la distance et de la surface de l'objet.
Leçon 15

Utiliser le Moniteur série

Le Moniteur série affiche des informations envoyées par la carte à l'ordinateur. La vitesse choisie dans le Moniteur doit être identique à celle indiquée dans Serial.begin().

Code 11 — Afficher un compteur
int compteur = 0;

void setup() {
  Serial.begin(9600);
  Serial.println("Demarrage du programme");
}

void loop() {
  Serial.print("Compteur = ");
  Serial.println(compteur);
  compteur++;
  delay(1000);
}
Explication ligne par ligne
  • int compteur = 0; crée une variable entière qui commence à zéro.
  • Serial.begin(9600) ouvre la communication série à 9600 bauds.
  • Serial.println("Demarrage du programme") affiche un message une seule fois au démarrage.
  • Serial.print("Compteur = ") affiche le texte sans passer à la ligne.
  • Serial.println(compteur) affiche la valeur et passe à la ligne suivante.
  • compteur++ ajoute 1 à la variable.
  • delay(1000) attend une seconde.
Résultat attendu :
Demarrage du programme
Compteur = 0
Compteur = 1
Compteur = 2
Compteur = 3
...
Une nouvelle valeur apparaît environ chaque seconde.
Leçon 16

Lire la température et l'humidité avec DHT11

Le DHT11 mesure la température et l'humidité relative. Le câblage dépend du module : certains modèles ont trois broches et d'autres quatre. Suis les étiquettes du module. Installe la bibliothèque DHT sensor library d'Adafruit et sa dépendance Adafruit Unified Sensor si Arduino IDE la demande.

Code 12 — Mesures du DHT11
#include <DHT.h>

#define BROCHE_DHT 2
#define TYPE_DHT DHT11

DHT dht(BROCHE_DHT, TYPE_DHT);

void setup() {
  Serial.begin(9600);
  dht.begin();
}

void loop() {
  float humidite = dht.readHumidity();
  float temperature = dht.readTemperature();

  if (isnan(humidite) || isnan(temperature)) {
    Serial.println("Erreur de lecture du DHT11");
    delay(2000);
    return;
  }

  Serial.print("Temperature : ");
  Serial.print(temperature);
  Serial.println(" °C");
  Serial.print("Humidite : ");
  Serial.print(humidite);
  Serial.println(" %");

  delay(2000);
}
Explication ligne par ligne
  • #include <DHT.h> importe le code de la bibliothèque du capteur.
  • #define BROCHE_DHT 2 définit la broche de données D2.
  • #define TYPE_DHT DHT11 indique le modèle de capteur utilisé.
  • DHT dht(BROCHE_DHT, TYPE_DHT) crée l'objet qui communique avec le capteur.
  • dht.begin() initialise le capteur.
  • readHumidity() lit l'humidité relative ; readTemperature() lit la température en degrés Celsius.
  • isnan() vérifie si la valeur n'est pas un nombre valide. En cas d'erreur, un message est affiché.
  • return termine cette exécution de la fonction loop(). Elle sera appelée de nouveau ensuite.
  • Le délai de 2000 ms laisse suffisamment de temps entre les lectures du DHT11.
Résultat attendu : le Moniteur série affiche par exemple « Temperature : 24.0 °C » et « Humidite : 48.0 % ». Ces valeurs sont illustratives : les mesures réelles dépendent de l'environnement.
Leçon 17 • Projet final

Projet : lampe automatique

Objectif : utiliser une LDR sur A0 pour commander une LED sur D8. La LED s'allume lorsque la mesure de lumière passe sous un seuil défini. Utilise un diviseur de tension pour la LDR et une résistance en série avec la LED.

Code 13 — Programme complet
const int capteurLumiere = A0;
const int led = 8;
const int seuil = 500;

void setup() {
  pinMode(led, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int mesure = analogRead(capteurLumiere);

  Serial.print("Mesure de lumiere : ");
  Serial.println(mesure);

  if (mesure < seuil) {
    digitalWrite(led, HIGH);
  } else {
    digitalWrite(led, LOW);
  }

  delay(250);
}

Explication du programme

  1. Les constantes indiquent l'entrée du capteur, la sortie de la LED et le seuil de comparaison.
  2. pinMode(led, OUTPUT) prépare D8 à commander la LED.
  3. Serial.begin(9600) active la communication avec le Moniteur série.
  4. analogRead(capteurLumiere) lit la mesure de lumière et la stocke dans mesure.
  5. Les deux commandes série affichent la valeur mesurée.
  6. if (mesure < seuil) compare la mesure au seuil de 500.
  7. Si la mesure est inférieure au seuil, la LED s'allume ; sinon, elle s'éteint.
  8. delay(250) attend un quart de seconde avant la lecture suivante.
Résultat attendu : la LED change d'état lorsque la mesure passe d'un côté à l'autre du seuil. Ajuste la valeur 500 après avoir observé les valeurs dans le Moniteur série. Si ton montage mesure une valeur plus élevée dans le noir, inverse la condition.

Défis pour aller plus loin

  • Ajouter un potentiomètre pour régler le seuil.
  • Ajouter un buzzer pour signaler l'obscurité.
  • Afficher « Jour » ou « Nuit » dans le Moniteur série.
  • Utiliser deux seuils différents pour éviter les changements rapides autour d'une seule valeur.

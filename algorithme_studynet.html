Comment utiliser ce cours ?

Lis chaque chapitre dans l’ordre. Pour chaque exemple, essaie d’abord de prévoir le résultat avant de le regarder. Ensuite, modifie une valeur, refais le calcul à la main et explique pourquoi le résultat change.

La méthode en 5 étapes

  1. Comprendre la consigne.
  2. Identifier les données disponibles.
  3. Déterminer le résultat attendu.
  4. Écrire les étapes en pseudo-code.
  5. Tester avec plusieurs valeurs.

Une idée essentielle

Un algorithme est une suite d’étapes précises, ordonnées et finies qui résout un problème. Il ne dépend pas d’un langage particulier.

Un même algorithme peut être programmé en C, Python ou dans un autre langage.

Convention d’écriture utilisée dans ce cours

Tous les algorithmes suivent maintenant la même structure : le nom de l’algorithme, Début, les variables déclarées avec leur type, les traitements, puis Fin. Dans cette méthode, les déclarations des variables sont placées juste après Début, comme demandé.

Algorithme Nom_Programme
Début
    nom_variable : Type
    traitement
Fin
CHAPITRE 1

Découvrir l’algorithmique

1.1 Qu’est-ce qu’un algorithme ?

Un algorithme est une série d’instructions logiques, précises et organisées qui permet de passer de données de départ à un résultat. Il doit être suffisamment clair pour qu’une personne ou un ordinateur puisse suivre les étapes sans deviner ce qu’il faut faire.

Exemple de la vie quotidienne : préparer un thé : chauffer l’eau, mettre le thé dans une tasse, verser l’eau, attendre quelques minutes. L’ordre est important : verser l’eau avant de la chauffer ne donne pas le même processus.

1.2 Les qualités d’un bon algorithme

  • Précis : chaque instruction a un sens clair.
  • Ordonné : les instructions sont dans le bon ordre.
  • Fini : l’algorithme termine après un nombre fini d’étapes.
  • Correct : il fournit le résultat attendu pour les entrées prévues.
  • Compréhensible : ses noms et ses étapes sont faciles à suivre.

1.3 Algorithme, programme et langage

TermeSignificationExemple
ProblèmeCe qu’on veut résoudre.Calculer la somme de deux nombres.
AlgorithmeLa méthode de résolution.Lire A et B, calculer S ← A + B, afficher S.
ProgrammeL’algorithme écrit dans un langage exécutable.Code en C ou Python.
ExécutionLe programme fonctionne avec des valeurs précises.A=4, B=7 donne S=11.

1.4 Premier algorithme

Algorithme : somme de deux nombres
Algorithme Somme
Début
    A, B, S : Réel
    Écrire("Donner A : ")
    Lire(A)
    Écrire("Donner B : ")
    Lire(B)
    S ← A + B
    Écrire("La somme est : ", S)
Fin
Exemple d’exécution si A = 4 et B = 7 : Donner A : 4 Donner B : 7 La somme est : 11

À retenir : l’algorithme décrit la logique. Le symbole ← signifie « recevoir / prendre la valeur de ce qui est à droite ».

CHAPITRE 2

Analyser et résoudre un problème

2.1 Lire la consigne correctement

Avant d’écrire une seule instruction, cherche trois éléments :

Les entrées

Les informations fournies à l’algorithme : nombre, texte, tableau, choix de l’utilisateur…

Le traitement et la sortie

Le traitement transforme les entrées. La sortie est le résultat à afficher ou à retourner.

2.2 Exemple : calculer la moyenne de trois notes

ÉlémentRéponse
EntréesN1, N2, N3
TraitementM ← (N1 + N2 + N3) / 3
SortieAfficher M
Test10, 14, 12 → moyenne 12
Solution
Algorithme Moyenne3Notes
Début
    N1, N2, N3, M : Réel
    Lire(N1, N2, N3)
    M ← (N1 + N2 + N3) / 3
    Écrire("Moyenne = ", M)
Fin
Avec 10, 14 et 12 : Moyenne = 12

2.3 Les tests de validation

Ne teste pas seulement un cas. Pour une moyenne, teste des valeurs normales, des notes égales à zéro et des valeurs limites prévues par la consigne. Si les notes doivent être entre 0 et 20, il faut aussi décider quoi faire si l’utilisateur saisit 25.

Erreur fréquente : commencer directement à coder sans avoir identifié les entrées, les sorties et les règles. Cela produit souvent des oublis dans les conditions.
CHAPITRE 3

Variables, constantes et types

3.1 Une variable, c’est quoi ?

Une variable est un nom associé à une valeur qui peut changer pendant l’exécution. Imagine une boîte étiquetée : age. Elle contient d’abord 19, puis peut recevoir 20.

Affectation
Algorithme IncrementerAge
Début
    age : Entier
    age ← 19
    age ← age + 1
    Écrire(age)
Fin
Résultat : 20

La deuxième ligne se lit ainsi : « calculer l’ancienne valeur de age plus 1, puis ranger le résultat dans age ». Ce n’est pas une égalité mathématique classique.

3.2 Les types de données

Type algorithmiqueÀ quoi sert-il ?Exemples
EntierNombre sans partie décimale.-3, 0, 42
RéelNombre pouvant avoir une partie décimale.3,5 ; -0,25 ; 12,0
BooléenValeur logique.Vrai, Faux
CaractèreUn seul symbole.'A', '7', '?'
ChaîneSuite de caractères."Bonjour"
TableauCollection ordonnée d’éléments.[12, 8, 15]

3.3 Déclarer les variables

Dans le pseudo-code de ce cours, on annonce les variables avant le bloc Début. Le type permet de comprendre quelles valeurs sont prévues.

Déclaration
Algorithme DeclarationVariables
Début
    nom : Chaîne
    age : Entier
    moyenne : Réel
    admis : Booléen
    // Les variables sont déclarées avant leur utilisation.
Fin
nom peut contenir "Sami" ; age peut contenir 18 ; moyenne peut contenir 13,75 ; admis peut contenir Vrai ou Faux.

3.4 Les constantes

Une constante représente une valeur qui ne doit pas changer dans le problème. Elle rend le programme plus lisible et évite de répéter un nombre magique.

Exemple
Algorithme CalculPrixTTC
Début
    TVA, prixHT, prixTTC : Réel
    TVA ← 0.19
    prixHT ← 100
    prixTTC ← prixHT * (1 + TVA)
    Écrire(prixTTC)
Fin
Résultat : 119
Noms conseillés : note1, prix_total, nombreEtudiants. Choisis un nom parlant, commence par une lettre et évite les espaces et les accents dans les identifiants.
CHAPITRE 4

Entrées et sorties : Lire et Écrire

Lire récupère une donnée fournie par l’utilisateur. Écrire affiche un message ou une valeur. Elles permettent à l’algorithme de communiquer avec l’extérieur.

Demander un prénom
Algorithme Salutation
Début
    prenom : Chaîne
    Écrire("Quel est ton prénom ?")
    Lire(prenom)
    Écrire("Bonjour ", prenom, " !")
Fin
Saisie : Lina Affichage : Bonjour Lina !

Lire plusieurs valeurs

Calcul d’un rectangle
Algorithme AireRectangle
Début
    longueur, largeur, aire : Réel
    Écrire("Longueur et largeur : ")
    Lire(longueur, largeur)
    aire ← longueur * largeur
    Écrire("Aire = ", aire)
Fin
Saisie : 5 et 3 Aire = 15

Il faut utiliser les données après leur lecture. Une variable lue doit avoir une valeur valide avant d’être utilisée dans un calcul.

5.3 Opérateurs logiques

  • ET : toutes les conditions doivent être vraies.
  • OU : au moins une condition doit être vraie.
  • NON : inverse une valeur logique.
Accès autorisé si l’âge est suffisant et si la carte est valide
Algorithme VerifierAutorisation
Début
    age : Entier
    carteValide, autorise : Booléen
    autorise ← (age >= 18) ET (carteValide = Vrai)
    Écrire(autorise)
Fin
age = 20 et carteValide = Vrai → autorise = Vrai age = 20 et carteValide = Faux → autorise = Faux

5.4 Priorité des opérations

En général, les parenthèses sont évaluées d’abord, puis les multiplications/divisions, puis les additions/soustractions. Utilise des parenthèses quand tu veux éviter toute ambiguïté.

Comparer deux calculs
Algorithme PrioriteOperateurs
Début
    A, B : Entier
    A ← 2 + 3 * 4
    B ← (2 + 3) * 4
    Écrire(A, B)
Fin
A = 14 car 3 * 4 est calculé d’abord. B = 20 car les parenthèses imposent de calculer 2 + 3 d’abord.
CHAPITRE 6

Les conditions : Si, SinonSi, Sinon

Une condition permet à l’algorithme de choisir une action selon une situation. La condition est une expression qui vaut Vrai ou Faux.

6.1 Si simple

Afficher un message si la note est suffisante
Algorithme VerifierAdmission
Début
    note : Réel
    Lire(note)
    Si note >= 10 Alors
        Écrire("Admis")
    FinSi
Fin
note = 14 → Admis note = 7 → aucun message n’est affiché par ce bloc.

6.2 Si…Sinon

Nombre positif ou non positif
Algorithme PositifOuNon
Début
    N : Réel
    Lire(N)
    Si N > 0 Alors
        Écrire("Positif")
    Sinon
        Écrire("Nul ou négatif")
    FinSi
Fin
N = 5 → Positif N = 0 → Nul ou négatif N = -2 → Nul ou négatif

6.3 Plusieurs cas

Mention selon la note sur 20
Algorithme MentionNote
Début
    note : Réel
    Lire(note)
    Si note < 0 OU note > 20 Alors
        Écrire("Note invalide")
    SinonSi note < 10 Alors
        Écrire("Insuffisant")
    SinonSi note < 12 Alors
        Écrire("Passable")
    SinonSi note < 14 Alors
        Écrire("Assez bien")
    SinonSi note < 16 Alors
        Écrire("Bien")
    Sinon
        Écrire("Très bien")
    FinSi
Fin
note = 13 → Assez bien note = 18 → Très bien note = 25 → Note invalide
Attention à l’ordre : dans une chaîne de conditions, le premier cas vrai est exécuté. Vérifie les limites : note < 10 n’inclut pas 10, alors que note <= 10 l’inclut.

6.4 Conditions imbriquées

Une condition peut se trouver à l’intérieur d’une autre. Mais si une condition composée avec ET ou OU suffit, elle est souvent plus facile à lire.

Vérifier l’intervalle [0, 20]
Algorithme ValiderNote
Début
    note : Réel
    Lire(note)
    Si note >= 0 ET note <= 20 Alors
        Écrire("Note valide")
    Sinon
        Écrire("Note invalide")
    FinSi
Fin
note = 20 → Note valide note = -1 → Note invalide
CHAPITRE 7

La boucle Pour

La boucle Pour est adaptée quand on connaît le nombre de répétitions ou quand on parcourt une suite de valeurs. Le compteur prend successivement les valeurs indiquées.

7.1 Compter de 1 à 5

Affichage de 1 à 5
Algorithme AfficherDeUnACinq
Début
    i : Entier
    Pour i de 1 à 5 Faire
        Écrire(i)
    FinPour
Fin
1 2 3 4 5

Le compteur i vaut 1 au premier tour, puis 2, puis 3, puis 4, puis 5. La boucle s’arrête après la dernière valeur.

7.2 Calculer une somme

Somme des entiers de 1 à N
Algorithme SommeDeUnAN
Début
    N, i, somme : Entier
    Lire(N)
    somme ← 0
    Pour i de 1 à N Faire
        somme ← somme + i
    FinPour
    Écrire(somme)
Fin
N = 4 : somme évolue 0 → 1 → 3 → 6 → 10 Résultat final : 10

7.3 Table de multiplication

Table de 7
Algorithme TableDeSept
Début
    i : Entier
    Pour i de 1 à 10 Faire
        Écrire(7, " x ", i, " = ", 7 * i)
    FinPour
Fin
7 x 1 = 7 7 x 2 = 14 ... 7 x 10 = 70

7.4 Compteur et accumulateur

Compteur

Compte combien de fois une situation se produit. Exemple : nb ← nb + 1.

Accumulateur

Accumule une valeur, souvent une somme. Exemple : somme ← somme + valeur.

Avant la boucle, initialise toujours le compteur ou l’accumulateur. Sinon, il peut contenir une valeur incorrecte ou inconnue.
CHAPITRE 8

La boucle TantQue

La boucle TantQue répète un bloc tant qu’une condition est vraie. Elle convient lorsque le nombre de tours dépend des données saisies ou d’un événement.

Demander un nombre positif
Algorithme SaisirNombrePositif
Début
    N : Réel
    Écrire("Donner un nombre positif")
    Lire(N)
    TantQue N <= 0 Faire
        Écrire("Erreur. Recommencer : ")
        Lire(N)
    FinTantQue
    Écrire("Merci")
Fin
Si l’utilisateur saisit -3, puis 0, puis 8 : Erreur. Recommencer Erreur. Recommencer Merci

8.1 Le risque de boucle infinie

Une boucle peut ne jamais terminer si sa condition reste toujours vraie. Il faut généralement qu’une instruction à l’intérieur de la boucle modifie la situation qui contrôle la condition.

Exemple qui termine
Algorithme CompterJusquaTrois
Début
    i : Entier
    i ← 1
    TantQue i <= 3 Faire
        Écrire(i)
        i ← i + 1
    FinTantQue
Fin
1 2 3
Erreur : oublier i ← i + 1 ici ferait rester i à 1. La condition i <= 3 serait toujours vraie.

8.2 Pour ou TantQue ?

PourTantQue
Nombre de tours connu ou suite de valeurs.Nombre de tours inconnu à l’avance.
Ex. afficher les nombres de 1 à 10.Ex. répéter la saisie jusqu’à obtenir un nombre positif.
CHAPITRE 9

Les tableaux

Un tableau stocke plusieurs valeurs sous un seul nom. Chaque élément est repéré par un indice. Dans ce cours, on utilise souvent les indices de 0 à N−1 pour rester proche du C et de Python. Respecte toutefois la convention donnée dans ton cours scolaire.

Tableau de 5 notes
Algorithme AccederAuxElements
Début
    notes : Tableau[5] de Réel
    notes ← [12, 15, 8, 17, 10]
    Écrire(notes[0])
    Écrire(notes[3])
Fin
notes[0] = 12 notes[3] = 17

9.1 Parcourir un tableau

Afficher toutes les valeurs
Algorithme AfficherTableau
Début
    T : Tableau de Réel
    N, i : Entier
    Lire(N)
    Pour i de 0 à N - 1 Faire
        Écrire(T[i])
    FinPour
Fin
Pour T = [4, 9, 2], les valeurs affichées sont 4, 9, 2.

9.2 Calculer la somme et la moyenne

Somme d’un tableau
Algorithme SommeEtMoyenneTableau
Début
    T : Tableau de Réel
    N, i : Entier
    somme, moyenne : Réel
    somme ← 0
    Pour i de 0 à N - 1 Faire
        somme ← somme + T[i]
    FinPour
    moyenne ← somme / N
    Écrire(somme, moyenne)
Fin
T = [10, 12, 14] → somme = 36 ; moyenne = 12.

9.3 Compter les éléments qui vérifient une condition

Compter les notes supérieures ou égales à 10
Algorithme CompterNotesSuffisantes
Début
    T : Tableau de Réel
    N, i, nb : Entier
    nb ← 0
    Pour i de 0 à N - 1 Faire
        Si T[i] >= 10 Alors
            nb ← nb + 1
        FinSi
    FinPour
    Écrire(nb)
Fin
T = [7, 10, 15, 9, 12] → nb = 3.

9.4 Tableau : précautions

  • La taille N doit être cohérente avec le nombre d’éléments.
  • Avec des indices commençant à 0, le dernier indice est N - 1.
  • Ne lis jamais T[N] dans un tableau de taille N avec indices 0 à N−1.
  • Si N = 0, on ne peut pas calculer la moyenne en divisant par N.
CHAPITRE 10

Les chaînes de caractères

Une chaîne est un texte composé de caractères. Selon le langage et la notation du cours, on peut accéder aux caractères par un indice, compter leur nombre et parcourir la chaîne.

Parcourir un mot
Algorithme AfficherCaracteres
Début
    mot : Chaîne
    i : Entier
    mot ← "SALUT"
    Pour i de 0 à Longueur(mot) - 1 Faire
        Écrire(mot[i])
    FinPour
Fin
S A L U T

Compter les voyelles

Algorithme de comptage
Algorithme CompterVoyelles
Début
    mot : Chaîne
    nbVoyelles, i : Entier
    c : Caractère
    Lire(mot)
    nbVoyelles ← 0
    Pour i de 0 à Longueur(mot) - 1 Faire
        c ← Minuscule(mot[i])
        Si c = "a" OU c = "e" OU c = "i" OU c = "o" OU c = "u" OU c = "y" Alors
            nbVoyelles ← nbVoyelles + 1
        FinSi
    FinPour
    Écrire(nbVoyelles)
Fin
mot = "Bonjour" → 3 voyelles (o, o, u).

Selon la consigne, il peut être nécessaire de traiter aussi les lettres accentuées comme é, è, à et ù.

CHAPITRE 11

Fonctions et procédures

Une fonction ou une procédure permet de regrouper des instructions utiles, de leur donner un nom et de les réutiliser. Cela évite les répétitions et facilite les tests.

11.1 Fonction

Une fonction calcule généralement une valeur et la renvoie avec Retourner.

Fonction carré
Algorithme UtiliserFonctionCarre
Début
    Fonction Carre(x : Réel) : Réel
        Retourner(x * x)
    FinFonction
    resultat : Réel
    resultat ← Carre(5)
    Écrire(resultat)
Fin
Carre(5) retourne 25, donc resultat = 25.

11.2 Procédure

Une procédure réalise une action. Elle peut afficher un message, modifier une structure ou effectuer un traitement, sans nécessairement retourner une valeur.

Procédure de salutation
Algorithme UtiliserProcedureSalutation
Début
    Procédure DireBonjour(nom : Chaîne)
        Écrire("Bonjour ", nom)
    FinProcédure
    DireBonjour("Amine")
Fin
Bonjour Amine

11.3 Paramètres et variables locales

  • Paramètre : donnée reçue par la fonction, par exemple x.
  • Valeur retournée : résultat envoyé à l’instruction appelante.
  • Variable locale : variable utilisée seulement dans le bloc où elle est déclarée.
Une fonction doit avoir un rôle clair. Par exemple, EstPair(n) répond à une question logique, tandis que AfficherMenu() sert plutôt à afficher.
CHAPITRE 12

Recherche, minimum et maximum

12.1 Trouver le maximum

On initialise le maximum avec le premier élément, puis on compare chaque élément suivant. Si un élément est plus grand, il devient le nouveau maximum.

Maximum d’un tableau non vide
Algorithme MaximumTableau
Début
    T : Tableau de Réel
    N, i : Entier
    max : Réel
    max ← T[0]
    Pour i de 1 à N - 1 Faire
        Si T[i] > max Alors
            max ← T[i]
        FinSi
    FinPour
    Écrire(max)
Fin
T = [6, 3, 14, 9] → max = 14

12.2 Trouver le minimum

La logique est identique, mais on remplace la comparaison > par <.

Minimum
Algorithme MinimumTableau
Début
    T : Tableau de Réel
    N, i : Entier
    min : Réel
    min ← T[0]
    Pour i de 1 à N - 1 Faire
        Si T[i] < min Alors
            min ← T[i]
        FinSi
    FinPour
    Écrire(min)
Fin
T = [6, 3, 14, 9] → min = 3

12.3 Recherche séquentielle

On parcourt le tableau du début à la fin jusqu’à trouver la valeur cherchée ou atteindre la fin.

Rechercher une valeur
Algorithme RechercheSequentielle
Début
    T : Tableau de Réel
    N, i : Entier
    valeurCherchee : Réel
    trouve : Booléen
    trouve ← Faux
    i ← 0
    TantQue i < N ET trouve = Faux Faire
        Si T[i] = valeurCherchee Alors
            trouve ← Vrai
        Sinon
            i ← i + 1
        FinSi
    FinTantQue
    Si trouve Alors
        Écrire("Trouvé à l'indice ", i)
    Sinon
        Écrire("Absent")
    FinSi
Fin
T = [4, 8, 12, 3], valeurCherchee = 12 → trouvé à l’indice 2.
Le tableau doit être non vide pour l’algorithme du maximum/minimum présenté ici. Pour la recherche, vérifie que tu n’accèdes pas à T[i] lorsque i = N.
CHAPITRE 13

Tri et idée de complexité

13.1 Pourquoi trier ?

Trier consiste à mettre des valeurs dans un ordre donné, par exemple croissant ou décroissant. Cela facilite l’affichage et certaines recherches.

13.2 Tri par sélection — idée

À chaque position, on cherche le plus petit élément de la partie non triée puis on l’échange avec l’élément à cette position. C’est facile à comprendre, même si ce n’est pas le tri le plus rapide pour de grandes données.

Pseudo-code du tri par sélection
Algorithme TriSelection
Début
    T : Tableau de Réel
    N, i, j, indiceMin : Entier
    Pour i de 0 à N - 2 Faire
        indiceMin ← i
        Pour j de i + 1 à N - 1 Faire
            Si T[j] < T[indiceMin] Alors
                indiceMin ← j
            FinSi
        FinPour
        échanger T[i] et T[indiceMin]
    FinPour
Fin
Départ : [5, 2, 4, 1] Après tri croissant : [1, 2, 4, 5]

13.3 Complexité, première idée

La complexité décrit comment le travail ou la mémoire nécessaires évoluent quand la taille des données augmente.

NotationIdée généraleExemple courant
O(1)Temps constant.Lire un élément à un indice connu.
O(N)Travail proportionnel au nombre d’éléments.Parcourir un tableau une fois.
O(N²)Deux parcours imbriqués sur les données.Tri par sélection.
O(log N)Le problème est réduit par facteur à chaque étape.Recherche dichotomique dans un tableau trié.

À ce stade, retiens surtout l’intuition : si on double N, une méthode O(N) demande environ deux fois plus de travail, tandis qu’une méthode O(N²) peut en demander environ quatre fois plus.

CHAPITRE 14

Enregistrements et énumérations

14.1 Enregistrement (structure)

Un enregistrement regroupe plusieurs informations de types différents qui décrivent un même objet. En C, on retrouve l’idée avec struct.

Un étudiant
Algorithme ManipulerEtudiant
Début
    Type Etudiant = Enregistrement
        nom : Chaîne
        age : Entier
        moyenne : Réel
    FinEnregistrement
    etu : Etudiant

    etu.age ← 19
    etu.moyenne ← 14.5

14.2 Énumération

Une énumération définit un ensemble limité de valeurs nommées. Elle est utile quand une variable ne peut prendre qu’un choix parmi plusieurs états prévus.

Jours de la semaine
Algorithme UtiliserEnumerationJour
Début
    Type Jour = (Lundi, Mardi, Mercredi, Jeudi, Vendredi, Samedi, Dimanche)
    jour : Jour
    jour ← Mercredi
    Si jour = Mercredi Alors
        Écrire("Milieu de semaine")
    FinSi
Fin

CHAPITRE 15

Tracer un algorithme à la main

Une table de trace permet de suivre la valeur des variables après chaque instruction. Elle aide à comprendre les boucles et à repérer les erreurs.

Tracer la somme de 1 à 4
Algorithme SommeDesQuatrePremiers
Début
    i, somme : Entier
    somme ← 0
    Pour i de 1 à 4 Faire
        somme ← somme + i
    FinPour
    Écrire(somme)
Fin
Étape | i | somme avant | somme après Départ | — | — | 0 Tour 1 | 1 | 0 | 1 Tour 2 | 2 | 1 | 3 Tour 3 | 3 | 3 | 6 Tour 4 | 4 | 6 | 10 Résultat final : 10

Comment construire ta table de trace ?

  1. Écris les noms des variables en colonnes.
  2. Inscris leurs valeurs initiales avant la première instruction.
  3. Exécute une instruction à la fois.
  4. À chaque tour de boucle, note les nouvelles valeurs.
  5. Compare le résultat final avec ce que tu avais prévu.

Construire un algorithme pas à pas

Ce petit laboratoire te guide dans un problème classique : calculer le prix total après une remise. Complète les étapes, puis compare avec la solution.

Énoncé

Lire le prix unitaire et la quantité. Calculer le sous-total. Si le sous-total est supérieur ou égal à 100, appliquer une remise de 10 %. Afficher le montant à payer.

Réflexion avant le code

Solution complète
Algorithme PrixAvecRemise
Début
    prix, sousTotal, total : Réel
    quantite : Entier
    Lire(prix, quantite)
    sousTotal ← prix * quantite
    Si sousTotal >= 100 Alors
        total ← sousTotal * 0.90
    Sinon
        total ← sousTotal
    FinSi
    Écrire("À payer : ", total)
Fin
prix = 25 ; quantite = 4 sousTotal = 25 × 4 = 100 Remise = 10 À payer = 90

Exercice 1 — Périmètre d’un rectangle

Lire la longueur L et la largeur l, puis afficher le périmètre.

Correction
Algorithme PerimetreRectangle
Début
    L, l, P : Réel
    Lire(L, l)
    P ← 2 * (L + l)
    Écrire(P)

Explication : on additionne les deux dimensions, puis on multiplie la somme par 2.

Exercice 3 — Factorielle

La factorielle de N, notée N!, est le produit des entiers de 1 à N. Par convention, 0! = 1.

Correction (N entier positif ou nul)
Algorithme Factorielle
Début
    N, i, fact : Entier
    Lire(N)
    fact ← 1
    Pour i de 1 à N Faire
        fact ← fact * i
    FinPour
    Écrire(fact)
Fin
N = 4 → 1 × 2 × 3 × 4 = 24 N = 0 → la boucle ne tourne pas, fact reste 1.

À vérifier : si N est négatif, la factorielle n’est pas définie dans cet exercice. Il faut donc vérifier l’entrée si la consigne le demande.

Exercice 7 — Vérifier une saisie

Demander une note jusqu’à ce qu’elle soit comprise entre 0 et 20.

Correction
Algorithme ValiderNoteSaisie
Début
    note : Réel
    Lire(note)
    TantQue note < 0 OU note > 20 Faire
        Écrire("Note invalide, recommencer")
        Lire(note)
    FinTantQue
    Écrire("Note acceptée")
Fin
Saisies : 25, -1, 14 → après les deux erreurs : Note acceptée.

Les 7 réflexes avant de rendre un exercice

  1. Ai-je bien compris ce qu’il faut afficher ?
  2. Ai-je listé toutes les entrées et les variables nécessaires ?
  3. Ai-je choisi les bons types de données ?
  4. Ai-je initialisé les compteurs et accumulateurs ?
  5. Mes conditions couvrent-elles les cas limites ?
  6. Mes boucles progressent-elles et terminent-elles ?
  7. Ai-je testé un cas normal et un cas limite ?
Conseil final : pour progresser, écris d’abord l’algorithme sur papier. Quand il est clair et testé, traduis-le en C ou en Python. Les langages changent, mais la logique reste la même.

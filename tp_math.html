Cours approfondi de GNU Octave

GNU Octave est un logiciel libre de calcul numérique, particulièrement utile en mathématiques. Il permet d’effectuer des calculs, de manipuler des vecteurs et des matrices, d’écrire des algorithmes, de résoudre des systèmes linéaires et de représenter graphiquement des fonctions.

À retenir : Octave est une calculatrice puissante, mais aussi un environnement de programmation : vous fournissez des données, effectuez des calculs, puis affichez les résultats ou tracez des courbes.

Première étape : où écrire le code ?

  • Command Window : Saisissez une commande et appuyez sur Entrée pour afficher immédiatement le résultat.
  • Editor : Écrivez plusieurs commandes dans un fichier et enregistrez-le avec une extension se terminant par .m.
  • Current Folder : Le dossier de travail dans lequel Octave recherche vos fichiers.
Règle importante : Essayez les exemples vous-même. Lire ne suffit pas : saisissez la commande, observez le résultat et modifiez les valeurs pour comprendre.

2. Variables et calculs — variables et calculs

Une variable est un nom associé à une valeur que l’on pourra réutiliser. Dans Octave, = signifie affecter une valeur à une variable ; ce n’est pas un test d’égalité.

a = 12;
b = 4;
somme = a + b;
difference = a - b;
produit = a * b;
quotient = a / b;
puissance = a^2;
OpérateurSignificationExempleRésultat
+addition2+35
-soustraction8-35
*Multiplication4*312
/Division10/25
^Puissance2^38
()Définir la priorité des opérations(2+3)*420

Saisir une valeur auprès de l’utilisateur

x = input("Donner x : ");
y = x^2 + 2*x + 1;
disp(y);

Si l’utilisateur saisit 2le résultat est 9car \(2^2+2×2+1=9\).

Les noms des variables distinguent les majuscules et les minuscules : Note etnote ce sont deux noms différents. Choisissez des noms explicites et n’utilisez pas d’espaces.

3 bis. Syntaxe, types de données et méthode de travail

3 bis.1 Comment Octave exécute les instructions

Octave lit les instructions dans l’ordre, de haut en bas. Chaque instruction peut créer une variable, calculer une expression, afficher une valeur ou modifier une matrice.

a = 4;
b = 3;
c = a + b;
disp(c);

La première ligne mémorise 4 dans a, la deuxième mémorise 3 dans b, la troisième calcule leur somme dans c et la dernière affiche 7.

3 bis.2 Les types numériques et logiques

x = 12;             % nombre réel
z = 3 + 2i;          % nombre complexe
texte = "Bonjour";   % chaîne de caractères
ok = (x > 10);       % valeur logique : vrai

Octave accepte les nombres réels et complexes. Une comparaison produit une valeur logique : vrai (1) ou faux (0). Les chaînes de caractères servent à afficher des messages.

3 bis.3 Priorité des opérations

Les parenthèses sont prioritaires, puis les puissances, puis les multiplications/divisions, puis les additions/soustractions. Utilise des parenthèses lorsque l’expression risque d’être ambiguë.

r1 = 2 + 3 * 4;      % 14
r2 = (2 + 3) * 4;    % 20
r3 = 2^3 + 1;        % 9

3 bis.4 Constantes utiles

Constante / commandeRôle

Évite d’utiliser i ou j comme unité imaginaire après leur avoir donné une autre valeur. Pour un nombre complexe, tu peux écrire explicitement 1i.

3. Les vecteurs — vecteurs

Créer un vecteur

A = [1 2 3 4]
B = [1; 2; 3; 4]
C = 1:5
D = 0:2:10
E = linspace(0, 1, 5)
  • [1 2 3]: vecteur ligne.
  • [1; 2; 3]: vecteur colonne ; le point-virgule sépare les lignes.
  • 1:5: valeurs de 1 à 5 avec un pas de 1.
  • 0:2:10: début, pas, fin.
  • linspace(a,b,n): crée n points régulièrement espacés entre a et b.

Accéder aux éléments

A = [10 20 30 40];
A(1)       % premier élément = 10
A(3)       % troisième élément = 30
A(2:4)     % éléments de 2 à 4
A(end)     % dernier élément = 40
A(2) = 99; % modifier le deuxième élément
L’indexation dans Octave commence à 1 et non à 0. Par conséquent, A(0) est incorrect.

Opérations sur les vecteurs

A = [2 4 6];
B = [1 3 5];
A + B       % [3 7 11]
A .* B      % [2 12 30]
A .^ 2      % [4 16 36]
sum(A)      % 12
mean(A)     % 4
max(A)      % 6
min(A)      % 2

4. Les matrices — matrices

Une matrice est un tableau de nombres organisé en lignes et en colonnes. Si elle contient 2 lignes et 3 colonnes, sa taille est 2 × 3.

A = [1 2 3; 4 5 6; 7 8 9]
A = 1 2 3 4 5 6 7 8 9

L’espace sépare les colonnes et; le point-virgule sépare les lignes.

Matrices prédéfinies

CommandeRésultat / utilisation
zeros(2,3)Matrice de zéros : deux lignes et trois colonnes.
ones(3,2)Matrice de uns : trois lignes et deux colonnes.
eye(3)Matrice identité 3 × 3.
rand(2,2)Matrice de nombres aléatoires entre 0 et 1.

Accéder aux lignes et aux colonnes

A = [10 20 30; 40 50 60; 70 80 90];
A(2,3)  % 60: deuxième ligne, troisième colonne
A(1,:)  % première ligne entière
A(:,2)  % deuxième colonne entière
A(3,1) = 99; % modifier l’élément

A(i,j): i Le numéro de ligne etj le numéro de colonne. Les deux-points : signifient « tous » dans la dimension concernée.

Informations sur une matrice

A = [2 4 6; 1 3 5];
size(A)      % [2 3]
length(A)    % 3 : dimension la plus grande
numel(A)     % 6: Nombre d’éléments
sum(A)       % somme de chaque colonne: [3 7 11]
sum(A(:))    % somme de tous les éléments: 21
max(A(:))    % élément maximal: 6
min(A(:))    % élément minimal: 1

5. Opérations sur les matrices — opérations sur les matrices

A = [1 2; 3 4];
B = [5 6; 7 8];
A + B   % addition
A - B   % soustraction
A * B   % multiplication matricielle
A'      % transpose: transposition : échange les lignes et les colonnes
det(A)  % déterminant
inv(A)  % inverse, s’il existe

Différence entre * et .* (très important)

SymboleQue fait-il ?Exemple
A * BMultiplication matricielle ; le nombre de colonnes de A doit être égal au nombre de lignes de B.Multiplication matricielle classique.
A .* BMultiplie chaque élément par l’élément correspondant ; les dimensions doivent être compatibles.[1 2].*[3 4] → [3 8]
A ./ BDivision élément par élément.[4 8]./[2 4] → [2 2]
A .^ 2Élève chaque élément au carré séparément.[2 3].^2 → [4 9]
Lorsqu’un point précède l’opérateur (.*, ./ et .^), l’opération s’effectue généralement élément par élément. En revanche, * et^ correspondent aux opérations matricielles de l’algèbre linéaire.

Résoudre un système d’équations linéaires

Exemple de système : \(2x+y=5\) et \(x+3y=6\).

A = [2 1; 1 3];
b = [5; 6];
X = A\\b
X = 1.8000 1.4000

Cela signifie que x = 1.8 ety = 1.4. Pour résoudre A*X=b, la commande A\\b est généralement préférable au calcul de inv(A)*b.

Différence essentielle : x = 5 affecte la valeur 5 à la variable. En revanche, x == 5 vérifie si x est égal à 5.

7. Conditions — if / elseif / else

Les conditions permettent au programme de choisir quoi faire selon une valeur ou une situation.

x = input("Donner un nombre : ");

if x > 0
    disp("Positif");
elseif x < 0
    disp("Negatif");
else
    disp("Zero");
end
  • if: si la condition est vraie.
  • elseif: teste une autre condition si la première est fausse.
  • else: si aucune condition précédente n’est vraie.
  • end: termine la structure conditionnelle.

Exemple : pair ou impair

n = input("Donner un entier : ");
if mod(n,2) == 0
    disp("Pair");
else
    disp("Impair");
end

mod(n,2) Le reste de la division de n par 2 est calculé. Si ce reste est nul, le nombre est pair.

8. Boucles — boucles for et while

for: Nombre d’itérations connu

for i = 1:5
    disp(i);
end
1 2 3 4 5

La variable i prend successivement les valeurs 1, 2, 3, 4 et 5. À chaque itération, les instructions de la boucle sont exécutées.

Exemple : somme de 1 à 10

s = 0;
for i = 1:10
    s = s + i;
end
disp(s);
55

On commence par s=0et, à chaque itération, on ajoute la valeur de i à la somme.

while: Répéter tant que la condition est vraie

i = 1;
while i <= 5
    disp(i);
    i = i + 1;
end
Dans while, n’oubliez pas de modifier la variable utilisée dans la condition. Si celle-ci reste toujours vraie, le programme peut tourner indéfiniment.

Comment choisir ?

for Lorsque le nombre d’itérations est connu, par exemple de 1 à 10. while Lorsque vous voulez répéter les instructions tant qu’une condition est vérifiée.

Créer votre propre fonction

Créez un fichier nommé carre.m et écrivez :

function y = carre(x)
    y = x.^2;
end

Enregistrez le fichier, puis saisissez carre(5) dans la fenêtre de commande : le résultat est 25. Le nom du fichier doit correspondre au nom de la fonction principale.

10 bis. Modèles classiques de TP Math

Calculer la somme et la moyenne d’un vecteur

notes = [12 15 9 14 10];
s = sum(notes);
m = mean(notes);
disp(s);
disp(m);

La somme vaut 60 et la moyenne vaut 12. Si les notes sont stockées dans un vecteur, les fonctions intégrées évitent une boucle lorsque celle-ci n’est pas demandée.

Compter les valeurs qui vérifient une condition

A = [3 12 8 15 9 17];
nombre = sum(A >= 10);

La comparaison A >= 10 crée un vecteur logique. La somme des valeurs logiques compte les éléments qui satisfont la condition : ici, 3 valeurs.

Créer une table de valeurs d’une fonction

x = -2:1:2;
y = x.^2;
tableau = [x; y]

La première ligne contient les valeurs de x et la deuxième leurs images par la fonction carrée. Pour afficher les deux lignes sous forme de colonnes, utilise [x(:), y(:)].

Calculer une factorielle avec une boucle

n = 5;
p = 1;
for k = 1:n
    p = p * k;
end
disp(p);

Le résultat est 120. On initialise le produit à 1, puis on le multiplie par chaque entier de 1 à n. Pour n = 0, la factorielle vaut 1 : il faut traiter ce cas correctement.

10. Graphiques — tracer des fonctions

Pour tracer \(f(x)=x^2\), créez les valeurs de x, calculez y, puis utilisez plot.

x = -5:0.1:5;
y = x.^2;
plot(x,y);
grid on;
title("f(x) = x^2");
xlabel("x");
ylabel("f(x)");
  • x = -5:0.1:5: valeurs de -5 à 5 avec un pas de 0,1.
  • y = x.^2: calcule le carré de chaque élément.
  • plot(x,y): trace la courbe.
  • grid on: affiche la grille.
  • title: titre du graphique.
  • xlabel etylabel: noms des axes.

Tracer deux fonctions sur la même figure

x = -5:0.1:5;
f = x.^2;
g = 2*x;
plot(x,f,"b",x,g,"r");
grid on;
legend("f(x)=x^2","g(x)=2x");

"b" en bleu et"r" en rouge. legend Une légende permet d’identifier chaque courbe.

Lorsque la fonction est calculée sur un vecteur, utilisez généralement les opérateurs élément par élément comme x.^2 etsin(x). Choisissez un pas assez petit, par exemple 0,1, pour obtenir une courbe plus précise.

11. Équations et systèmes — équations et systèmes

Équation du second degré

Équation : \(ax^2+bx+c=0\). On calcule \(\Delta=b^2-4ac\).

  • Si \(\Delta>0\): deux solutions réelles.
  • Si \(\Delta=0\): une solution réelle double.
  • Si \(\Delta<0\): aucune solution réelle.
a = input("Donner a : ");
b = input("Donner b : ");
c = input("Donner c : ");

if a == 0
    disp("Pas une equation du second degre");
else
    delta = b^2 - 4*a*c;
    if delta > 0
        x1 = (-b + sqrt(delta))/(2*a);
        x2 = (-b - sqrt(delta))/(2*a);
        disp(x1);
        disp(x2);
    elseif delta == 0
        x = -b/(2*a);
        disp(x);
    else
        disp("Pas de solution reelle");
    end
end
Essayez a=1 etb=-3 etc=2; vous obtenez les solutions 2 et 1.

Résoudre un système linéaire

Exemple : \(2x+y=5\) et \(x+3y=6\).

A = [2 1; 1 3];
b = [5; 6];
X = A\\b;

Résultat : X = [1.8; 1.4]soit x=1.8 ety=1.4.

Dérivée et intégrale numériques

f = @(x) x.^2;
x = 2;
h = 0.0001;
derivee = (f(x+h)-f(x-h))/(2*h);

I = quad(f,0,1);

La dérivée numérique est approximativement égale à 4 et l’intégrale de 0 à 1 est approximativement égale à \(1/3\). Le calcul symbolique nécessite généralement le package symbolic, tandis que cet exemple repose sur un calcul numérique approché.

12. Scripts et fichiers .m — script complet

Un script est un fichier contenant une suite d’instructions exécutées dans l’ordre.

  1. Ouvrez l’éditeur d’Octave.
  2. Saisissez les commandes.
  3. Enregistrez le fichier sous un nom tel que exercice1.m.
  4. Exécutez-le avec le bouton Run ou saisissez exercice1 dans la fenêtre de commande si le fichier se trouve dans le dossier courant.

Exemple : calculer une moyenne et prendre une décision

clc;
clear;

note1 = input("Donner la premiere note : ");
note2 = input("Donner la deuxieme note : ");

moyenne = (note1 + note2)/2;
disp("La moyenne est : ");
disp(moyenne);

if moyenne >= 10
    disp("Admis");
else
    disp("Non admis");
end

Ce programme lit deux nombres, calcule leur moyenne, l’affiche, puis vérifie si elle est supérieure ou égale à 10.

Les commentaires

% Ceci est un commentaire
x = 5; % valeur de x

Tout texte placé après le symbole % sur la même ligne n’est pas exécuté ; il sert à expliquer le code.

13. Erreurs fréquentes — erreurs fréquentes

ErreurCause possibleSolution
undefined variableLa variable a été utilisée avant d’être définie, ou son nom est mal orthographié.Définissez la variable et vérifiez son orthographe.
nonconformant argumentsLes dimensions des matrices ne sont pas compatibles avec l’opération.Vérifiez size(A) etsize(B).
Erreur avec A(0)L’indexation commence à 1.Utilisez le premier élément A(1).

Comment repérer une erreur ?

  1. Lisez le message d’erreur, notamment le nom du fichier et le numéro de ligne.
  2. Vérifiez les parenthèses () et[] et la présence de end.
  3. Vérifiez les noms des variables.
  4. Testez chaque partie séparément avant d’exécuter tout le programme.
  5. Utilisez help nom_commande pour obtenir de l’aide.

14. Méthode pour résoudre un exercice de TP ou de devoir surveillé

  1. Comprendre la consigne : Quelles sont les données ? Quel résultat faut-il calculer ?
  2. Identifier le type de données : nombre, variable, vecteur, matrice ou fonction.
  3. Décrire l’algorithme en mots : lire les données ← calculer ← tester la condition si nécessaire ← afficher le résultat.
  4. Choisir les commandes adaptées : input pour la saisie, les opérateurs pour les calculs, if pour les décisions, for pour les répétitions, plot pour les graphiques.
  5. Tester un petit exemple : Choisissez des nombres dont vous connaissez le résultat à la main.
  6. Vérifier les cas particuliers : division par zéro, dimensions incompatibles d’une matrice ou coefficient a nul dans une équation du second degré.
  7. Interpréter le résultat : Ne vous contentez pas du code ; vérifiez que le résultat répond à la question.
Conseil pour réussir : Comprenez pourquoi chaque commande est utilisée au lieu de mémoriser le code. Le même principe peut apparaître avec d’autres valeurs dans un devoir surveillé.

15. Exercices — Testez vos connaissances

Choisissez une réponse pour chaque question, puis cliquez sur « Corriger ». La correction s’affiche directement dans la page.

1. Quelle commande renvoie le nombre total d’éléments d’une matrice ?
Bonne réponse : numel(A) compte tous les éléments.
2. Si A=[1 2; 3 4], quelle est la valeur de A(2,2) ?
Bonne réponse : 4, deuxième ligne et deuxième colonne.
3. Comment élever au carré chaque élément du vecteur x ?
Bonne réponse : x.^2 pour élever chaque élément au carré.
4. Quel symbole compare deux valeurs ?
Bonne réponse : == pour comparer, et= pour affecter une valeur.
5. Quelle commande trace y en fonction de x ?
Bonne réponse : plot(x,y).
6. Quand choisir for ?
Bonne réponse : for convient lorsque le nombre d’itérations est connu.

Défi pratique

Écrivez un programme qui crée A=[2 4 6 8]calcule la somme et l’élément maximal, puis trace la fonction \(y=x^2\) sur l’intervalle de -3 à 3. Essayez avant de relire les leçons 4, 9 et 10.

Afficher la solution du défi
clc;
clear;
A = [2 4 6 8];
S = sum(A);
M = max(A);
disp(S);
disp(M);

x = -3:0.1:3;
y = x.^2;
plot(x,y);
grid on;
title("y = x^2");
xlabel("x");
ylabel("y");

La somme vaut 20 et l’élément maximal vaut 8. Le programme trace ensuite la courbe de la fonction.

0. Avant de commencer : qu’est-ce que Python ?

Python est un langage de programmation. On écrit des instructions dans un fichier, puis l’interpréteur Python les exécute. Il est utilisé pour l’automatisation, les sites web, l’analyse de données, l’intelligence artificielle et l’apprentissage de la programmation.

Le code

print("Bonjour !")
print("Je découvre Python.")

Résultat affiché

Bonjour !
Je découvre Python.

Comment lire ce cours ?

  1. Lis l’explication pour comprendre l’idée.
  2. Observe chaque ligne du code.
  3. Compare le résultat attendu avec ce que tu obtiens.
  4. Regarde l’algorithme : il décrit la logique sans dépendre d’un langage particulier.
  5. Modifie le code et prédis le nouveau résultat avant de l’exécuter.
À retenir : Python utilise l’indentation (les espaces au début des lignes) pour délimiter les blocs après if, for, while, def, etc. En général, utilise 4 espaces.

1. Variables et types de données

Une variable est un nom associé à une valeur. Imagine une boîte étiquetée : le nom est l’étiquette et la valeur est ce qu’on y range. En Python, on crée une variable avec le signe =, appelé opérateur d’affectation.

Exemple commenté

age = 19           # int : entier
moyenne = 14.5     # float : nombre décimal
est_admis = True   # bool : vrai ou faux
print(nom)
print(age)
print(moyenne)
print(est_admis)

Les commentaires commencent par #. Python ignore le texte placé après ce symbole sur la même ligne.

3. Entrées et sorties : print() et input()

print() affiche une information. input() demande une saisie à l’utilisateur et renvoie toujours du texte (str). Si la saisie doit servir dans un calcul, il faut la convertir.

Exemple : calculer l’âge l’année prochaine

nom = input("Votre nom : ")
age = int(input("Votre âge : "))
print("Bonjour", nom)
print("L'année prochaine, vous aurez", age + 1, "ans.")

Le préfixe f permet d’insérer une variable entre accolades { } dans une chaîne.

4. Conditions : if, elif, else

Une condition permet au programme de choisir quelles instructions exécuter. Python vérifie la condition après if. Si elle est fausse, il peut tester elif, puis utiliser else si aucune condition précédente n’est vraie.

note = 14
if note >= 16:
    print("Très bien")
elif note >= 10:
    print("Admis")
else:
    print("Non admis")
Admis

Avec note = 14, le premier test est faux (14 n’est pas supérieur ou égal à 16). Le deuxième est vrai (14 est supérieur ou égal à 10), donc Python affiche « Admis » et ne teste pas les autres branches.

Exemple : pair ou impair

n = 17
if n % 2 == 0:
    print("Pair")
else:
    print("Impair")
Impair

Un entier est pair si le reste de sa division par 2 est égal à zéro. L’opérateur % donne ce reste.

Algorithme équivalent

5. Boucles : répéter des instructions

A. La boucle for

for répète un bloc pour chaque élément d’une séquence. Avec range(), on peut produire une suite d’entiers. La borne finale de range(debut, fin) n’est pas incluse.

for i in range(1, 6):
    print(i)
1
2
3
4
5

range(1, 6) commence à 1 et s’arrête juste avant 6. Pour afficher 0 à 4, on peut écrire range(5).

B. La boucle while

while répète les instructions tant que sa condition est vraie. Il faut faire évoluer une variable afin que la condition devienne éventuellement fausse, sinon on risque une boucle infinie.

i = 1
while i <= 3:
    print("Tour", i)
    i = i + 1
Tour 1
Tour 2
Tour 3

C. Calculer une somme

n = 5
somme = 0
for i in range(1, n + 1):
    somme = somme + i
print(somme)
15

Le programme calcule 1 + 2 + 3 + 4 + 5. Au départ, somme vaut 0. À chaque tour, on ajoute la valeur courante de i.

D. break et continue

for n in range(1, 6):
    if n == 3:
        continue
    print(n)
1
2
4
5

continue saute le reste du tour actuel. break, lui, arrête complètement la boucle.

Piège : range(1, n) n’inclut pas n. Pour aller de 1 à n inclus, écris range(1, n + 1).

8. Fonctions

Une fonction est un bloc nommé qui réalise une tâche. Elle évite de répéter le même code et permet de découper un programme en petites parties faciles à tester.

def saluer(nom):
    print(f"Bonjour {nom} !")

saluer("Meriem")
saluer("Sami")
Bonjour Meriem !
Bonjour Sami !

def définit la fonction ; nom est un paramètre ; l’appel saluer("Meriem") transmet un argument à la fonction.

return : renvoyer un résultat

def carre(n):
    return n * n

resultat = carre(4)
print(resultat)
16

return renvoie une valeur à l’endroit où la fonction a été appelée. Contrairement à print(), il ne sert pas directement à afficher.

Plusieurs paramètres et valeur par défaut

def moyenne(a, b, c=0):
    return (a + b + c) / 3

print(moyenne(12, 15, 18))
print(moyenne(12, 15))
15.0
9.0

Attention : cet exemple applique toujours une division par 3. Si le troisième nombre est facultatif, il faut adapter la formule ou utiliser une autre fonction. L’exemple sert à montrer la valeur par défaut, pas à calculer une moyenne de deux notes correctement.

Version plus robuste pour la moyenne

def moyenne(notes):
    if len(notes) == 0:
        return None
    return sum(notes) / len(notes)

print(moyenne([12, 15]))
print(moyenne([]))
13.5
None

10. Erreurs et exceptions

Une erreur de syntaxe signifie que le code ne respecte pas les règles du langage. Une erreur d’exécution survient pendant le programme, par exemple lors d’une division par zéro. try/except permet de gérer certaines erreurs prévues.

try:
    a = float(input("Numérateur : "))
    b = float(input("Dénominateur : "))
    resultat = a / b
except ValueError:
    print("Veuillez saisir des nombres valides.")
except ZeroDivisionError:
    print("Impossible de diviser par zéro.")
else:
    print("Résultat :", resultat)

Le résultat dépend des valeurs saisies. Si le dénominateur vaut 0, le message « Impossible de diviser par zéro. » s’affiche.

Lire un message d’erreur

  • SyntaxError : la syntaxe est incorrecte.
  • NameError : le nom d’une variable ou fonction est inconnu, souvent à cause d’une faute de frappe.
  • TypeError : une opération n’est pas adaptée au type de valeur.
  • ValueError : le type est acceptable mais la valeur ne l’est pas, par exemple int("abc").
  • ZeroDivisionError : division par zéro.
Conseil : lis d’abord la dernière ligne du message d’erreur, puis repère le numéro de ligne et examine les lignes proches.

11. Lire et écrire dans des fichiers

Python peut conserver des données dans un fichier texte. L’instruction with open(...) ferme automatiquement le fichier après le bloc, même si une erreur survient.

Écrire un fichier

with open("notes.txt", "w", encoding="utf-8") as fichier:
    fichier.write("Bonjour Python\n")
    fichier.write("Deuxième ligne\n")

Le mode "w" crée le fichier ou remplace son contenu. Le caractère \n passe à la ligne.

Lire un fichier

with open("notes.txt", "r", encoding="utf-8") as fichier:
    contenu = fichier.read()
print(contenu)
Bonjour Python
Deuxième ligne

Le mode "r" lit un fichier existant. Le mode "a" ajoute du contenu à la fin. Dans un environnement en ligne, les fichiers peuvent être isolés de ton PC.

12. Compréhensions de listes

Une compréhension permet de créer une liste à partir d’une séquence en une expression compacte. Il faut d’abord comprendre la boucle classique, puis apprendre cette écriture.

Avec une boucle classique

carres = []
for n in range(1, 5):
    carres.append(n * n)
print(carres)

Avec une compréhension

carres = [n * n for n in range(1, 5)]
print(carres)
[1, 4, 9, 16]

On peut aussi filtrer les éléments :

pairs = [n for n in range(1, 11) if n % 2 == 0]
print(pairs)
[2, 4, 6, 8, 10]

La structure est généralement [expression for élément in séquence if condition]. La partie if est facultative.

13. Introduction aux classes et aux objets

La programmation orientée objet organise le programme autour d’objets. Une classe décrit un modèle ; un objet est une instance de ce modèle. Les attributs représentent ses données et les méthodes ses comportements.

class Etudiant:
    def __init__(self, nom, note):
        self.nom = nom
        self.note = note

    def afficher(self):
        print(f"{self.nom} a obtenu {self.note}/20")

e1 = Etudiant("Ali", 16)
e1.afficher()
Ali a obtenu 16/20
  • class Etudiant définit une classe.
  • __init__ initialise l’objet au moment de sa création.
  • self représente l’objet courant.
  • self.nom et self.note sont des attributs.
  • afficher() est une méthode.

Ce chapitre est une introduction : commence par maîtriser variables, conditions, boucles, listes et fonctions avant d’approfondir les classes.

Le calcul donne 1 × 2 × 3 × 4 × 5 = 120. On initialise à 1 car c’est l’élément neutre de la multiplication.

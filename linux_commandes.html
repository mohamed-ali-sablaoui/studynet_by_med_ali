1. Introduction au système Linux

Comment utiliser ce cours : lisez d’abord la définition de chaque commande, observez l’exemple, puis exécutez-le dans un dossier d’essai. Modifiez un seul élément à la fois et vérifiez le résultat avec ls ou pwd. Les commandes de suppression et d’administration doivent être utilisées avec prudence.

Linux est le noyau d’un système d’exploitation. Ubuntu, Debian et Fedora sont des distributions Linux : elles réunissent le noyau, des outils système, des applications et un environnement de travail.

Un système d’exploitation gère le matériel, la mémoire, les fichiers, les programmes et les utilisateurs. On peut utiliser Linux avec une interface graphique ou avec un terminal.

Vocabulaire essentiel

  • Terminal : application dans laquelle on saisit des commandes.
  • Shell : programme qui interprète les commandes, par exemple Bash.
  • Commande : instruction donnée au système.
  • Répertoire : autre nom d’un dossier.
  • Utilisateur administrateur : compte autorisé à effectuer des opérations système.
À retenir : le terminal permet de contrôler le système en saisissant des commandes, sans devoir passer systématiquement par l’interface graphique.

2. Ouvrir et comprendre le terminal

Dans Ubuntu, ouvre l’application Terminal. Selon la configuration, le raccourci Ctrl + Alt + T fonctionne.

Exemple d’invite :

utilisateur@ordinateur:~$
  • utilisateur : nom du compte.
  • ordinateur : nom de la machine.
  • ~ : répertoire personnel de l’utilisateur.
  • $ : invite d’un utilisateur normal. Le symbole # est souvent associé à une session administrateur.

Une commande peut avoir cette forme :

commande [options] [arguments]

Exemple : ls -l /home. ls est la commande, -l une option, et /home l’argument indiquant où regarder.

Conseil : écris la commande exactement, puis appuie sur Entrée. Linux distingue généralement les majuscules et les minuscules : Fichier.txt et fichier.txt sont deux noms différents.

4. Se déplacer dans l’arborescence

Linux organise les fichiers dans une arborescence qui commence à la racine /. Le répertoire personnel d’un utilisateur est généralement situé dans /home/nom.

Commande / symboleSignification
cd dossierEntrer dans un dossier.
cd ..Remonter au dossier parent.
cd ~Aller au répertoire personnel.
cd /Aller à la racine.
cd -Revenir au répertoire précédent.
.Désigne le répertoire courant.
..Désigne le répertoire parent.
/home/userChemin absolu, qui commence par /.
Documents/cours.txtExemple de chemin relatif, calculé depuis le dossier courant.

Exemple guidé

pwd
ls
cd Documents
pwd
cd ..
pwd
cd ~

La commande cd Documents ne fonctionne que si le dossier Documents existe dans le dossier courant. Utilise ls pour vérifier.

À retenir : cd change le répertoire de travail. cd .. permet de remonter au répertoire parent et cd ~ de revenir au répertoire personnel.

5. Créer, copier, déplacer et supprimer

CommandeUtilitéExemple
mkdirCréer un dossier.mkdir TP
mkdir -pCréer une suite de dossiers parents si nécessaire.mkdir -p TP/linux/seance1
touchCréer un fichier vide s’il n’existe pas, ou actualiser sa date.touch notes.txt
cpCopier un fichier.cp notes.txt copie.txt
cp -rCopier un dossier et son contenu.cp -r TP TP_copie

rmdirSupprimer un dossier vide.rmdir dossier_vide
rm -rSupprimer un dossier et son contenu.À utiliser avec une grande prudence.
Attention : rm supprime généralement sans passer par une corbeille. Vérifie toujours le chemin avec pwd et le nom avec ls. Évite rm -rf si tu ne comprends pas exactement la cible.

Exemple pratique

mkdir TP_Linux
cd TP_Linux
touch cours.txt
cp cours.txt sauvegarde.txt
mv sauvegarde.txt copie_cours.txt
ls -l
cd ..

Résultat attendu : dans TP_Linux, tu trouveras cours.txt et copie_cours.txt.

Les espaces dans les noms

Pour créer un dossier dont le nom contient des espaces, utilise des guillemets :

mkdir "Mon cours Linux"
cd "Mon cours Linux"

6. Lire et rechercher dans les fichiers

CommandeFonction
cat fichier.txtAffiche le contenu complet d’un fichier texte.
less fichier.txtParcourt un fichier page par page ; appuie sur q pour quitter.
head fichier.txtAffiche les 10 premières lignes par défaut.
head -n 5 fichier.txtAffiche les 5 premières lignes.
tail fichier.txtAffiche les 10 dernières lignes par défaut.
wc -l fichier.txtCompte les lignes.
grep "mot" fichier.txtRecherche les lignes contenant un motif.
find . -name "*.txt"Recherche les fichiers .txt à partir du dossier courant.

Écrire dans un fichier : redirections

  • echo "Bonjour" > salut.txt : crée le fichier ou remplace son contenu.
  • echo "Deuxième ligne" >> salut.txt : ajoute le texte à la fin.
  • cat salut.txt : vérifie le résultat.
Le symbole > écrase le contenu existant. Utilise >> si tu veux ajouter une ligne sans effacer les anciennes.

Exemple avec grep

echo "Linux est un système" > texte.txt
echo "J'apprends les commandes Linux" >> texte.txt
grep "Linux" texte.txt

7. Exploitation et informations du système

Ces commandes aident à surveiller les ressources et à connaître la configuration de l’ordinateur.

CommandeCe qu’elle indique

8. Gestion des processus

Un processus est un programme en cours d’exécution. Chaque processus possède généralement un identifiant appelé PID.

CommandeFonction
psAffiche des processus liés à la session courante.
ps auxAffiche une liste détaillée de nombreux processus.
topSurveille en direct les processus et les ressources ; touche q pour quitter.
sleep 30Lance un processus qui attend 30 secondes.
jobsAffiche les tâches lancées en arrière-plan depuis le shell actuel.
kill PIDEnvoie un signal au processus indiqué.

Pour tester sans risque, lance sleep 30. Dans un autre terminal, cherche son PID avec ps aux | grep sleep. Le symbole | (pipe) transmet la sortie d’une commande à la suivante.

N’arrête pas un processus système au hasard. Si tu utilises kill, vérifie le PID et assure-toi qu’il s’agit bien du processus que tu souhaites arrêter.

9. Utilisateurs, droits et permissions

Linux utilise des permissions pour contrôler qui peut lire, modifier ou exécuter un fichier. Les trois catégories principales sont :

  • u (user) : propriétaire du fichier.
  • g (group) : groupe associé au fichier.
  • o (others) : les autres utilisateurs.

Les permissions courantes :

  • r = read (lecture), valeur numérique 4.
  • w = write (écriture), valeur numérique 2.
  • x = execute (exécution), valeur numérique 1.

Exemple d’affichage : -rwxr-xr--. Le premier caractère indique le type ; les trois caractères suivants correspondent au propriétaire, puis au groupe, puis aux autres.

CommandeExplication
ls -lAfficher les permissions et le propriétaire.
chmod 755 script.shPropriétaire : lecture, écriture, exécution ; groupe et autres : lecture et exécution.
chmod u+x script.shAjouter le droit d’exécution au propriétaire.
chown utilisateur fichierChanger le propriétaire, si les droits nécessaires sont disponibles.
idAfficher l’identité numérique et les groupes de l’utilisateur.

Calcul de 755 : propriétaire 7 = 4+2+1 (rwx), groupe 5 = 4+1 (r-x), autres 5 = 4+1 (r-x).

10. Installer et mettre à jour les logiciels sur Ubuntu

Ubuntu utilise le gestionnaire de paquets APT. Une connexion Internet peut être nécessaire pour télécharger les mises à jour ou les logiciels.

sudo apt update
sudo apt upgrade
sudo apt install nom_du_paquet
sudo apt remove nom_du_paquet
  • sudo demande des privilèges élevés pour exécuter la commande.
  • apt update actualise la liste des paquets disponibles ; il n’installe pas à lui seul toutes les mises à jour.
  • apt upgrade installe les mises à jour disponibles pour les paquets installés.
  • apt install installe un paquet.
  • apt remove désinstalle un paquet.
Lis ce que le terminal propose avant de confirmer une opération avec Y. N’exécute pas une commande avec sudo si tu ne comprends pas son effet. Le mot de passe saisi dans le terminal ne s’affiche généralement pas, même sous forme d’astérisques : c’est normal.

11. Commandes réseau

CommandeFonctionÀ savoir
ip addrAffiche les interfaces et adresses IP.Utile pour vérifier si une interface possède une adresse.
ip routeAffiche les routes réseau.Permet notamment de voir la route par défaut.
ping -c 4 8.8.8.8Teste l’accessibilité d’une adresse IP.Envoie quatre requêtes.
ping -c 4 google.comTeste la connectivité et la résolution du nom.Un échec peut venir du réseau ou du DNS.
hostname -IAffiche les adresses IP associées à la machine.La sortie dépend de la configuration.
curl -I https://example.comTeste une requête HTTP et affiche les en-têtes.Suppose que curl est installé.

Comprendre les résultats de ping :

  • Si l’adresse IP répond mais pas le nom de domaine, la résolution DNS peut être en cause.
  • Si les deux échouent, vérifie d’abord la connexion, l’adresse IP, la route et les règles réseau.
  • Certains réseaux bloquent les requêtes ping : un échec ne prouve pas toujours que tout Internet est indisponible.

12. Obtenir de l’aide

  • commande --help : affiche souvent une aide rapide.
  • man commande : ouvre le manuel détaillé. Appuie sur q pour quitter.
  • apropos mot : cherche dans les descriptions des pages de manuel, si la base est disponible.
  • which python3 : indique le chemin du programme trouvé dans le PATH.
  • type cd : indique comment le shell interprète une commande.

Exemples :

ls --help
man cp
which python3
type cd

Pour les commandes intégrées au shell, comme cd, la commande help cd peut être plus utile que man cd.

13. Travaux pratiques guidés

Durée indicative : 15–25 min

Objectif

Créer une arborescence, écrire un fichier, le copier, chercher un mot et consulter les informations système.

Étape A — Préparer les dossiers

cd ~
mkdir -p TP_Linux/seance1
cd TP_Linux/seance1
pwd
ls -la

Explication : mkdir -p crée les dossiers intermédiaires nécessaires ; pwd confirme le chemin courant.

Étape B — Créer et remplir un fichier

echo "Je decouvre Linux" > notes.txt
echo "J'apprends les commandes fondamentales" >> notes.txt
cat notes.txt
wc -l notes.txt

Le résultat de wc -l devrait indiquer 2 lignes.

Étape C — Copier et rechercher

cp notes.txt notes_backup.txt
grep "Linux" notes.txt
find . -name "*.txt"
ls -l

Étape D — Observer le système

whoami
uname -a
free -h
df -h
ip addr

Étape E — Nettoyage optionnel

Si tu veux supprimer uniquement le TP que tu viens de créer, reviens au dossier personnel, vérifie le nom, puis supprime-le :

cd ~
ls
# Vérifie que TP_Linux est bien le dossier créé pour cet exercice
rm -r TP_Linux
L’étape E est facultative. Ne lance pas rm -r si tu n’es pas certain du chemin et du contenu : la suppression peut être définitive.

14. Bonnes pratiques de sécurité

  1. Vérifie ton emplacement avec pwd avant de déplacer ou supprimer des éléments.
  2. Utilise ls pour vérifier les noms de fichiers et de dossiers.
  3. Comprends une commande avant d’ajouter sudo.
  4. Évite les commandes de suppression récursive sur des chemins inconnus.
  5. Ne copie pas aveuglément des commandes provenant d’un site ou d’un message.
  6. Fais une sauvegarde des fichiers importants avant toute opération risquée.
  7. Si une commande affiche « Permission denied », vérifie le chemin et les droits au lieu de forcer immédiatement l’opération.

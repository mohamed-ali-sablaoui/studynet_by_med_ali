MODULE 01

Introduction à Python et à la programmation

1. Qu'est-ce que la programmation ?

La programmation consiste à donner à un ordinateur une suite d'instructions précises pour réaliser une tâche. Un programme est donc un ensemble d'instructions écrites dans un langage compréhensible par un interpréteur ou un compilateur.

Exemple : calculer la moyenne de trois notes.

note1 = 14
note2 = 16
note3 = 12

moyenne = (note1 + note2 + note3) / 3

print(moyenne)

2. Qu'est-ce que Python ?

Python est un langage de programmation de haut niveau, interprété, à typage dynamique et multiparadigme. Il est utilisé dans le développement web, l'automatisation, l'intelligence artificielle, la science des données, la cybersécurité, les applications et les calculs scientifiques.

3. Comment Python exécute-t-il un programme ?

  1. Le programmeur écrit un fichier source portant généralement l'extension .py.
  2. L'interpréteur Python analyse le code.
  3. Le code est compilé en bytecode dans l'implémentation CPython.
  4. La machine virtuelle Python exécute ce bytecode.
  5. Le programme produit un résultat ou signale une erreur.

4. Installer et exécuter Python

Télécharger Python depuis le site officiel : python.org/downloads.

Vérifier l'installation dans le terminal :

python --version
python -V

Sur Windows, il est également possible d'utiliser :

py --version
py programme.py

Pour ouvrir le mode interactif :

python

Pour quitter :

exit()

7. L'indentation

L'indentation représente les espaces placés au début d'une ligne. En Python, elle détermine les blocs d'instructions. On utilise généralement quatre espaces.

    print("Majeur")
    print("Accès autorisé")

Attention : une indentation incorrecte peut provoquer une erreur IndentationError. Python ne fonctionne pas comme C ou Java où les accolades délimitent habituellement les blocs.

MODULE 06

Boucles : for et while

1. La boucle for

Elle permet de parcourir les éléments d'une séquence ou d'un objet itérable. 

for i in range(5):
    print(i)

2. La fonction range()

range(5)       # 0, 1, 2, 3, 4
range(2, 7)    # 2, 3, 4, 5, 6
range(0, 10, 2)# 0, 2, 4, 6, 8
range(10, 0, -1)

La borne finale n'est jamais incluse. Le pas peut être positif ou négatif, mais pas nul.

3. La boucle while

i = 1

while i <= 5:
    print(i)
    i += 1

4. break

Interrompt immédiatement la boucle.

for i in range(10):
    if i == 5:
        break
    print(i)

5. continue

Ignore le reste de l'itération actuelle.

for i in range(10):
    if i % 2 == 0:
        continue
    print(i)

6. pass

Instruction vide utilisée comme emplacement provisoire.

if True:
    pass

7. Boucles imbriquées

for i in range(1, 4):
    for j in range(1, 4):
        print(i, j)

8. else avec les boucles

Le bloc else d'une boucle s'exécute si celle-ci se termine normalement, sans être interrompue par break. 

for n in range(2, 10):
    if n == 5:
        break
else:
    print("Boucle terminée normalement")

9. Compteurs et accumulateurs

10. Calculer une factorielle

11. Boucles infinies

        break
Une boucle while doit généralement posséder une condition d'arrêt atteignable. Sinon, elle peut tourner indéfiniment.

Fonctions : programmation modulaire

1. Pourquoi utiliser les fonctions ?

  • Éviter la répétition du code.
  • Diviser un grand problème en sous-problèmes.

def externe():

Une fonction récursive est une fonction qui s'appelle elle-même pour résoudre une version plus petite du même problème.

def factorielle(n):
    if n < 0:
        raise ValueError("n doit être positif")

    if n == 0 or n == 1:
        return 1

    return n * factorielle(n - 1)

def fibonacci(n):
    if n < 0:
        raise ValueError("n doit être positif")

    if n <= 1:
        return n

    return fibonacci(n-1) + fibonacci(n-2)

print(fibonacci(7))
La version récursive simple de Fibonacci est coûteuse : elle recalcule plusieurs fois les mêmes valeurs. Une approche itérative ou avec mémoïsation est préférable pour les grandes valeurs.

MODULE 15

Algorithmes de recherche et de tri

1. Recherche linéaire

Parcourt les éléments un par un jusqu'à trouver la valeur ou atteindre la fin de la liste. 

def recherche_lineaire(L, valeur):
    for i in range(len(L)):
        if L[i] == valeur:
            return i

    return -1

print(recherche_lineaire([4, 8, 2, 9], 2))

Complexité temporelle : O(n).

2. Recherche binaire

Fonctionne sur une liste triée. Elle élimine la moitié de la zone de recherche à chaque étape. 

def recherche_binaire(L, valeur):
    gauche = 0
    droite = len(L) - 1

    while gauche <= droite:
        milieu = (gauche + droite) // 2

        if L[milieu] == valeur:
            return milieu

        elif L[milieu] < valeur:
            gauche = milieu + 1

        else:
            droite = milieu - 1

    return -1

L = [1, 3, 5, 7, 9, 11]
print(recherche_binaire(L, 7))

Complexité : O(log n).

3. Tri à bulles

def tri_bulles(L):
    L = L.copy()
    n = len(L)

    for i in range(n):
        echange = False

        for j in range(0, n-i-1):
            if L[j] > L[j+1]:
                L[j], L[j+1] = L[j+1], L[j]
                echange = True

        if not echange:
            break

    return L

print(tri_bulles([5, 2, 8, 1, 3]))

Complexité moyenne et pire cas : O(n²).

4. Tri par sélection

def tri_selection(L):
    L = L.copy()
    n = len(L)

    for i in range(n):
        minimum = i

        for j in range(i+1, n):
            if L[j] < L[minimum]:
                minimum = j

        L[i], L[minimum] = L[minimum], L[i]

    return L

5. Tri par insertion

def tri_insertion(L):
    L = L.copy()

    for i in range(1, len(L)):
        valeur = L[i]
        j = i - 1

        while j >= 0 and L[j] > valeur:
            L[j+1] = L[j]
            j -= 1

        L[j+1] = valeur

    return L

6. Tri fusion

def fusionner(gauche, droite):
    resultat = []
    i = j = 0

    while i < len(gauche) and j < len(droite):
        if gauche[i] <= droite[j]:
            resultat.append(gauche[i])
            i += 1
        else:
            resultat.append(droite[j])
            j += 1

    resultat.extend(gauche[i:])
    resultat.extend(droite[j:])

    return resultat

def tri_fusion(L):
    if len(L) <= 1:
        return L

    milieu = len(L) // 2

    gauche = tri_fusion(L[:milieu])
    droite = tri_fusion(L[milieu:])

    return fusionner(gauche, droite)

Complexité : O(n log n).

7. Tri rapide : Quick Sort

def quick_sort(L):
    if len(L) <= 1:
        return L

    pivot = L[len(L)//2]

    gauche = [x for x in L if x < pivot]
    egal = [x for x in L if x == pivot]
    droite = [x for x in L if x > pivot]

    return quick_sort(gauche) + egal + quick_sort(droite)

Cette version pédagogique utilise des listes supplémentaires. Sa complexité moyenne est O(n log n), mais son pire cas est O(n²).

Introduction aux bases de données SQLite

1. Qu'est-ce qu'une base de données ?

Une base de données permet de stocker, organiser, rechercher et modifier des informations de manière structurée. SQLite est un système relationnel léger intégré à la bibliothèque standard Python.

2. Connexion

import sqlite3

connexion = sqlite3.connect("ecole.db")
curseur = connexion.cursor()

3. Créer une table

curseur.execute("""
CREATE TABLE IF NOT EXISTS etudiants (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    nom TEXT NOT NULL,
    age INTEGER,
    moyenne REAL
)
""")

connexion.commit()

4. Insérer des données

curseur.execute(
    "INSERT INTO etudiants (nom, age, moyenne) VALUES (?, ?, ?)",
    ("Ali", 20, 15.5)
)

connexion.commit()

5. Lire les données

curseur.execute("SELECT * FROM etudiants")

etudiants = curseur.fetchall()

for e in etudiants:
    print(e)

6. Modifier

curseur.execute(
    "UPDATE etudiants SET moyenne = ? WHERE nom = ?",
    (17, "Ali")
)

connexion.commit()

7. Supprimer

curseur.execute(
    "DELETE FROM etudiants WHERE nom = ?",
    ("Ali",)
)

connexion.commit()

8. Fermer la connexion

connexion.close()
Utilise toujours les paramètres SQL avec ? au lieu de construire les requêtes par concaténation de chaînes. Cela évite notamment les injections SQL.

MODULE 27

Complexité algorithmique et efficacité

1. Pourquoi mesurer la complexité ?

Deux programmes peuvent produire le même résultat, mais nécessiter des quantités de temps et de mémoire très différentes. La complexité permet d'étudier leur comportement lorsque la taille des données augmente.

2. Complexité temporelle

NotationSignificationExemple
O(1)ConstanteAccès à un indice
O(log n)LogarithmiqueRecherche binaire
O(n)LinéaireParcours d'une liste
O(n log n)Quasi linéaireTri fusion
O(n²)QuadratiqueDeux boucles imbriquées
O(2ⁿ)ExponentielleCertains algorithmes récursifs
O(n!)FactorielleÉnumération de permutations

3. O(1)

def premier_element(L):
    return L[0]

4. O(n)

def afficher(L):
    for x in L:
        print(x)

5. O(n²)

def afficher_paires(L):
    for x in L:
        for y in L:
            print(x, y)

6. Complexité spatiale

Elle mesure la mémoire supplémentaire utilisée par un algorithme. Une solution qui crée une nouvelle liste de taille n utilise généralement un espace supplémentaire O(n).

7. Bonnes habitudes d'optimisation

  • Choisir une structure de données adaptée.
  • Éviter les calculs répétitifs inutiles.
  • Utiliser les fonctions intégrées efficaces.
  • Mesurer avant d'optimiser.
  • Préserver la lisibilité du code.

4. Séparation des responsabilités

def lire_notes():
    texte = input("Notes séparées par des espaces : ")
    return [float(x) for x in texte.split()]

def calculer_moyenne(notes):
    if not notes:
        raise ValueError("Liste vide")
    return sum(notes) / len(notes)

def afficher(moyenne):
    print(f"Moyenne : {moyenne:.2f}")

def main():
    notes = lire_notes()
    resultat = calculer_moyenne(notes)
    afficher(resultat)

if __name__ == "__main__":
    main()

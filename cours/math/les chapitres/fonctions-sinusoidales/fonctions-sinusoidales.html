1. Mesure des angles : degrés et radians

Un angle peut être exprimé en degrés ou en radians. En analyse mathématique, les radians sont indispensables pour les formules de limites et de dérivation.

180° = π radians    et    360° = 2π radians

Conversion des degrés en radians

Angle en radians = Angle en degrés × π / 180

Exemple : 60° = 60 × π/180 = π/3.

Conversion des radians en degrés

Angle en degrés = Angle en radians × 180 / π

Exemple : 3π/4 = 3 × 180/4 = 135°.

2. Le cercle trigonométrique

Le cercle trigonométrique est un cercle de centre O et de rayon 1. Un point M associé à un angle x possède les coordonnées :

M(cos x ; sin x)
Coordonnées du point M : cosinus sur l'axe horizontal et sinus sur l'axe vertical.
cos²(x) + sin²(x) = 1

Cette relation fondamentale découle directement de l'équation du cercle unité : X² + Y² = 1.

Variations du sinus

La dérivée est cos(x). Son signe permet de déterminer les intervalles de croissance et de décroissance.

sin est croissante sur [-π/2 + 2kπ ; π/2 + 2kπ].
sin est décroissante sur [π/2 + 2kπ ; 3π/2 + 2kπ].

Limites

  • lim(x→a) sin(x) = sin(a), pour tout a réel.
  • lim(x→+∞) sin(x) n'existe pas.
  • lim(x→-∞) sin(x) n'existe pas.
  • sin(x) est bornée entre -1 et 1.
Attention : le sinus n'a pas de limite à l'infini car il oscille indéfiniment entre -1 et 1.

5. Fonction tangente : f(x) = tan(x)

tan(x) = sin(x) / cos(x)
PropriétéRésultat

Pourquoi la tangente n'est-elle pas définie partout ?

Parce que son dénominateur cos(x) doit être différent de zéro.

cos(x) ≠ 0 ⇔ x ≠ π/2 + kπ

Variations

Sa dérivée est strictement positive sur chaque intervalle de définition. La tangente est donc strictement croissante sur :

]-π/2 + kπ ; π/2 + kπ[

Limites et asymptotes

lim(x→π/2⁻) tan(x) = +∞
lim(x→π/2⁺) tan(x) = -∞

Les droites x = π/2 + kπ sont des asymptotes verticales.

Courbe schématique : les lignes rouges représentent les asymptotes verticales.

cot(x) = cos(x) / sin(x) = 1/tan(x)

7. Fonctions sécante et cosécante

sec(x) = 1/cos(x)

Domaine : ℝ \ {π/2 + kπ}.

Image : ]-∞ ; -1] ∪ [1 ; +∞[.

Dérivée : sec(x)tan(x).

Période : 2π.

csc(x) = 1/sin(x)

Domaine : ℝ \ {kπ}.

Image : ]-∞ ; -1] ∪ [1 ; +∞[.

Dérivée : -csc(x)cot(x).

Période : 2π.

Les notations sec et csc sont parfois remplacées par 1/cos et 1/sin dans les exercices.

8. Identités trigonométriques fondamentales

A. Identité fondamentale

sin²(x) + cos²(x) = 1

En divisant par cos²(x), lorsque cos(x) ≠ 0 :

1 + tan²(x) = 1/cos²(x) = sec²(x)

En divisant par sin²(x), lorsque sin(x) ≠ 0 :

1 + cot²(x) = 1/sin²(x) = csc²(x)

B. Formules de symétrie

sin(-x) = -sin(x)
cos(-x) = cos(x)
tan(-x) = -tan(x)
cot(-x) = -cot(x)

C. Angles complémentaires et supplémentaires

sin(π/2 - x) = cos(x)
cos(π/2 - x) = sin(x)
sin(π - x) = sin(x)
cos(π - x) = -cos(x)
tan(π - x) = -tan(x)

D. Formules d'addition

sin(a+b) = sin(a)cos(b) + cos(a)sin(b)
sin(a-b) = sin(a)cos(b) - cos(a)sin(b)

cos(a+b) = cos(a)cos(b) - sin(a)sin(b)
cos(a-b) = cos(a)cos(b) + sin(a)sin(b)

tan(a+b) = (tan(a)+tan(b))/(1-tan(a)tan(b))

E. Formules d'angles doubles

sin(2x) = 2sin(x)cos(x)
cos(2x) = cos²(x)-sin²(x)
cos(2x) = 1-2sin²(x)
cos(2x) = 2cos²(x)-1
tan(2x) = 2tan(x)/(1-tan²(x))

F. Formules de réduction de puissance

sin²(x) = (1-cos(2x))/2
cos²(x) = (1+cos(2x))/2

G. Somme et différence de deux sinus ou cosinus

sin(a)+sin(b) = 2sin((a+b)/2)cos((a-b)/2)
sin(a)-sin(b) = 2cos((a+b)/2)sin((a-b)/2)
cos(a)+cos(b) = 2cos((a+b)/2)cos((a-b)/2)
cos(a)-cos(b) = -2sin((a+b)/2)sin((a-b)/2)

9. Résolution des équations trigonométriques

A. Équation sin(x) = a

Elle possède des solutions réelles uniquement si -1 ≤ a ≤ 1.

x = arcsin(a) + 2kπ
ou x = π - arcsin(a) + 2kπ

B. Équation cos(x) = a

Elle possède des solutions réelles uniquement si -1 ≤ a ≤ 1.

x = arccos(a) + 2kπ
ou x = -arccos(a) + 2kπ

C. Équation tan(x) = a

x = arctan(a) + kπ

D. Équation cot(x) = a

x = arccot(a) + kπ

Dans toutes ces formules, k ∈ ℤ.

Si l'énoncé demande les solutions dans un intervalle précis, il faut garder uniquement les solutions appartenant à cet intervalle.

Exemple

Résoudre sin(x) = 1/2 sur [0 ; 2π].

arcsin(1/2) = π/6
x = π/6 ou x = π - π/6 = 5π/6
Ensemble des solutions : {π/6 ; 5π/6}.

10. Fonctions trigonométriques transformées

Une fonction trigonométrique peut être modifiée par des paramètres qui changent son amplitude, sa période et sa position.

f(x) = A sin(Bx+C)+D
ParamètreEffet
AAmplitude = |A|
BPériode = 2π/|B|
CDécalage horizontal = -C/B
DDécalage vertical
Maximum = D + |A|
Minimum = D - |A|
Image = [D-|A| ; D+|A|]

Exemple

f(x) = 3sin(2x - π) + 1.

  • Amplitude : 3.
  • Période : 2π/2 = π.
  • Décalage horizontal : π/2 vers la droite.
  • Décalage vertical : 1 vers le haut.
  • Maximum : 4.
  • Minimum : -2.
Pour A cos(Bx+C)+D, les mêmes règles d'amplitude, de période et de translation s'appliquent.

11. Comprendre les fonctions trigonométriques réciproques

Les fonctions sinus, cosinus et tangente ne sont pas toutes injectives sur ℝ. Pour construire leurs fonctions réciproques, on restreint leurs domaines à des intervalles où elles sont bijectives sur leur image.

Attention : sin⁻¹(x) désigne arcsin(x), et non 1/sin(x). De même, cos⁻¹(x) signifie arccos(x), et non 1/cos(x).

Tableau général des fonctions réciproques

FonctionDomaineImage principale
arcsin(x)[-1 ; 1][-π/2 ; π/2]
arccos(x)[-1 ; 1][0 ; π]
arctan(x)ℝ]-π/2 ; π/2[
arccot(x)ℝ]0 ; π[
arcsec(x)]-∞ ; -1] ∪ [1 ; +∞[[0 ; π], π/2 exclu
arccsc(x)]-∞ ; -1] ∪ [1 ; +∞[[-π/2 ; π/2], 0 exclu

Propriétés fondamentales

sin(arcsin(x)) = x
cos(arccos(x)) = x
tan(arctan(x)) = x

Les compositions dans l'autre sens demandent de respecter les intervalles principaux :

arcsin(sin(x)) = x si x ∈ [-π/2 ; π/2]
arccos(cos(x)) = x si x ∈ [0 ; π]
arctan(tan(x)) = x si x ∈ ]-π/2 ; π/2[
Il est faux d'écrire arcsin(sin(x)) = x pour tout réel x. Par exemple, arcsin(sin(3π/4)) = π/4 et non 3π/4.

12. Fonction arcsinus : f(x) = arcsin(x)

y = arcsin(x) ⇔ sin(y) = x

Arcsin(x) est l'unique angle y appartenant à [-π/2 ; π/2] dont le sinus est égal à x.

Dérivée

arcsin'(x) = 1/√(1-x²)

Cette formule est valable pour -1 < x < 1. La fonction n'a pas de dérivée finie aux extrémités -1 et 1.

Dérivée d'une fonction composée

[arcsin(u(x))]' = u'(x)/√(1-u²(x))

Il faut que u(x) appartienne à ]-1 ; 1[ pour appliquer la formule de dérivation.

Exemple détaillé

Calculer la dérivée de f(x) = arcsin(2x).

u(x) = 2x
u'(x) = 2
f'(x) = 2/√(1-4x²)

Domaine de f : [-1/2 ; 1/2]. Domaine de dérivabilité : ]-1/2 ; 1/2[.

Limites

lim(x→1⁻) arcsin(x) = π/2
lim(x→-1⁺) arcsin(x) = -π/2

Courbe

La fonction arcsin est strictement croissante et impaire.

13. Fonction arccosinus : f(x) = arccos(x)

y = arccos(x) ⇔ cos(y) = x

Arccos(x) est l'unique angle y appartenant à [0 ; π] dont le cosinus vaut x.

PropriétéRésultat
Domaine[-1 ; 1]
Image[0 ; π]
ParitéNi paire ni impaire
ContinuitéSur [-1 ; 1]
MonotonieStrictement décroissante

Relation importante

arcsin(x) + arccos(x) = π/2

Elle est valable pour tout x ∈ [-1 ; 1].

Dérivée

arccos'(x) = -1/√(1-x²)
[arccos(u(x))]' = -u'(x)/√(1-u²(x))

Exemple

f(x) = arccos(3x).

u'(x) = 3
f'(x) = -3/√(1-9x²)

Domaine : [-1/3 ; 1/3]. Dérivabilité : ]-1/3 ; 1/3[.

Limites aux bornes

lim(x→-1⁺) arccos(x) = π
lim(x→1⁻) arccos(x) = 0

Courbe

Arccos est strictement décroissante.

14. Fonction arctangente : f(x) = arctan(x)

y = arctan(x) ⇔ tan(y) = x

Arctan(x) est l'unique angle y appartenant à ]-π/2 ; π/2[ dont la tangente vaut x.

f(x) = arctan(2x+1).

Deux asymptotes horizontales, sans intersection avec la courbe.

15. Fonction arccotangente : f(x) = arccot(x)

y = arccot(x) ⇔ cot(y) = x

On choisit la branche principale y ∈ ]0 ; π[.

16. Arcsecante et arccosécante

A. Arcsecante

arcsec(x) = arccos(1/x)
  • Domaine : |x| ≥ 1.
  • Image : [0 ; π] privé de π/2.
  • Dérivée : 1/(|x|√(x²-1)) pour |x| > 1.
  • Continue sur chacun des intervalles de son domaine.

B. Arccosécante

arccsc(x) = arcsin(1/x)
  • Domaine : |x| ≥ 1.
  • Image : [-π/2 ; 0[ ∪ ]0 ; π/2].
  • Dérivée : -1/(|x|√(x²-1)) pour |x| > 1.
Ces deux fonctions sont moins fréquentes dans certains programmes, mais leurs domaines, images et dérivées sont importants à connaître.

17. Limites trigonométriques : méthodes et résultats

A. Limites fondamentales

lim(x→0) sin(x)/x = 1
lim(x→0) tan(x)/x = 1
lim(x→0) (1-cos(x))/x² = 1/2

B. Formules avec un coefficient

lim(x→0) sin(ax)/x = a
lim(x→0) tan(ax)/x = a
lim(x→0) (1-cos(ax))/x² = a²/2

C. Limites des fonctions réciproques

lim(x→0) arcsin(x)/x = 1
lim(x→0) arctan(x)/x = 1
lim(x→0) arccos(x) = π/2

D. Comportement à l'infini

lim(x→+∞) arctan(x) = π/2
lim(x→-∞) arctan(x) = -π/2
lim(x→+∞) arccot(x) = 0

E. Limites de compositions

Si u(x) → 0, alors :

sin(u(x))/u(x) → 1
tan(u(x))/u(x) → 1
(1-cos(u(x)))/u²(x) → 1/2

F. Équivalents usuels au voisinage de zéro

sin(x) ~ x
tan(x) ~ x
arcsin(x) ~ x
arctan(x) ~ x
1-cos(x) ~ x²/2

Exemple 1

Calculer lim(x→0) sin(5x)/3x.

= 5/3 × sin(5x)/(5x)
= 5/3 × 1
= 5/3

Exemple 2

Calculer lim(x→0) (1-cos(4x))/x².

= 16 × (1-cos(4x))/(16x²)
= 16 × 1/2
= 8

Exemple 3

Calculer lim(x→0) arcsin(3x)/x.

= 3 × arcsin(3x)/(3x)
= 3
Les limites fondamentales avec sin(x)/x et tan(x)/x supposent que les angles sont exprimés en radians.

19. Variations et étude des courbes

Pour étudier les variations d'une fonction, on suit une méthode systématique :

  1. Déterminer le domaine de définition.
  2. Calculer la dérivée.
  3. Déterminer les points où la dérivée est nulle ou n'existe pas.
  4. Étudier le signe de la dérivée.
  5. Construire le tableau de variations.
  6. Calculer les limites aux bornes du domaine.
  7. Identifier les asymptotes et tracer la courbe.

Tableaux de variations types

cos(x)Décroissante puis croissante périodiquement.
tan(x)Strictement croissante sur chaque branche.
cot(x)Strictement décroissante sur chaque branche.
arcsin(x)Strictement croissante.
arccos(x)Strictement décroissante.
arctan(x)Strictement croissante.

Comment trouver une tangente à une courbe ?

Pour une fonction f dérivable en a, l'équation de la tangente au point d'abscisse a est :

y = f(a) + f'(a)(x-a)

Exemple : f(x)=sin(x), au point a=0.

f(0)=0
f'(0)=cos(0)=1
Tangente : y=x

20. Asymptotes et branches infinies

A. Asymptote verticale

La droite x = a est une asymptote verticale si au moins une limite latérale de f(x) en a est infinie.

lim(x→a⁺) f(x) = ±∞ ou lim(x→a⁻) f(x) = ±∞

Exemples :

  • tan(x) : x = π/2 + kπ.
  • cot(x) : x = kπ.

B. Asymptote horizontale

La droite y = L est une asymptote horizontale si :

lim(x→+∞) f(x) = L

ou si la limite vaut L lorsque x tend vers -∞.

Exemple : arctan(x) possède deux asymptotes horizontales : y=π/2 et y=-π/2.

C. Asymptote oblique

Une droite y=ax+b est une asymptote oblique lorsque :

lim(x→∞) [f(x)-(ax+b)] = 0

Pour la déterminer, lorsque les limites existent :

a = lim(x→∞) f(x)/x
b = lim(x→∞) [f(x)-ax]

21. Fonction réciproque f⁻¹ : définition et méthode

Une fonction f admet une fonction réciproque f⁻¹ lorsque f est bijective de son ensemble de départ vers son ensemble d'arrivée.

f⁻¹(f(x)) = x
f(f⁻¹(x)) = x

A. Condition d'existence

Sur un intervalle I, une fonction continue et strictement monotone est bijective de I sur son image f(I). Elle admet donc une réciproque sur cet ensemble image.

B. Comment calculer f⁻¹ ?

  1. Écrire y = f(x).
  2. Résoudre cette équation en x en fonction de y.
  3. Échanger les lettres x et y.
  4. Déterminer le domaine de la réciproque.

Exemple 1

f(x)=2x+3, définie sur ℝ.

y = 2x+3
x = (y-3)/2
f⁻¹(x) = (x-3)/2

Exemple 2 : fonction sinus restreinte

f(x)=sin(x), avec x ∈ [-π/2 ; π/2].

f⁻¹(x)=arcsin(x)

Exemple 3 : fonction cosinus restreinte

f(x)=cos(x), avec x ∈ [0 ; π].

f⁻¹(x)=arccos(x)

Exemple 4 : fonction tangente restreinte

f(x)=tan(x), avec x ∈ ]-π/2 ; π/2[.

f⁻¹(x)=arctan(x)

C. Relation entre les courbes

La courbe de f⁻¹ est le symétrique de la courbe de f par rapport à la droite y=x.

Les deux courbes sont symétriques par rapport à y=x.

D. Dérivée de la fonction réciproque

Si f est dérivable et f'(f⁻¹(x)) ≠ 0, alors :

(f⁻¹)'(x) = 1 / f'(f⁻¹(x))

Exemple : si f(x)=sin(x) sur [-π/2 ; π/2], alors f⁻¹(x)=arcsin(x).

(f⁻¹)'(x) = 1/cos(arcsin(x))
= 1/√(1-x²)
La fonction f doit être injective sur l'intervalle choisi. On ne peut pas inverser directement le sinus sur tout ℝ.

22. Fonctions composées et mélanges trigonométriques

A. Relations entre les fonctions réciproques

arcsin(x)+arccos(x)=π/2
arctan(x)+arccot(x)=π/2
arcsec(x)=arccos(1/x)
arccsc(x)=arcsin(1/x)

B. Formules de complémentarité

sin(arccos(x)) = √(1-x²)
cos(arcsin(x)) = √(1-x²)
tan(arcsin(x)) = x/√(1-x²)
tan(arccos(x)) = √(1-x²)/x

Attention aux conditions de définition : dans les deux dernières formules, le dénominateur doit être non nul.

C. Formules de composition avec arctan

sin(arctan(x)) = x/√(1+x²)
cos(arctan(x)) = 1/√(1+x²)

D. Formules de somme de deux arctangentes

Sous réserve de tenir compte de la branche principale :

tan(arctan(a)+arctan(b)) = (a+b)/(1-ab)

Cette identité est valable lorsque 1-ab ≠ 0, mais elle ne suffit pas à déterminer la valeur principale de la somme : il faut éventuellement ajouter ou retrancher π.

E. Exemple de simplification

Simplifier A = arcsin(x)+arccos(x).

A = π/2

Condition : x ∈ [-1 ; 1].

F. Dérivées des compositions complexes

f(x)=arcsin(sin(2x))
f'(x) = 2cos(2x)/√(1-sin²(2x))

Cette expression se simplifie sur les intervalles où cos(2x) garde un signe constant. Il faut toutefois respecter les points où la fonction composée change de branche.

23. Méthode générale pour étudier une fonction trigonométrique

Exemple : f(x) = arctan(2x-1)
  1. Domaine : arctan accepte tous les réels, donc Df=ℝ.
  2. Continuité : f est continue sur ℝ.
  3. Dérivée : f'(x)=2/[1+(2x-1)²].
  4. Signe : le dénominateur est strictement positif, donc f'(x)>0.
  5. Variations : f est strictement croissante sur ℝ.
  6. Limite en +∞ : π/2.
  7. Limite en -∞ : -π/2.
  8. Asymptotes : y=π/2 et y=-π/2.
Conclusion : f est continue et strictement croissante sur ℝ, son image est ]-π/2 ; π/2[ et elle possède deux asymptotes horizontales.

Exercice 02 — Domaine de définition

Facile

Déterminer le domaine de définition des fonctions :

  1. f(x)=tan(x)
  2. g(x)=cot(x)
  3. h(x)=arcsin(2x-1)
  4. p(x)=arccos(3x)
  5. q(x)=arctan(1/(x-2))
  6. r(x)=arcsec(x+1)
Correction :
  1. D=ℝ \ {π/2+kπ}.
  2. D=ℝ \ {kπ}.
  3. -1≤2x-1≤1, donc D=[0 ; 1].
  4. -1≤3x≤1, donc D=[-1/3 ; 1/3].
  5. x≠2, donc D=ℝ\{2}.
  6. |x+1|≥1, donc x≤-2 ou x≥0.

Exercice 03 — Identités trigonométriques

Moyen

Démontrer les égalités suivantes en précisant les conditions de définition :

  1. 1+tan²(x)=1/cos²(x).
  2. 1+cot²(x)=1/sin²(x).
  3. sin(2x)=2sin(x)cos(x).
  4. cos(2x)=1-2sin²(x).
  5. sin²(x)+cos²(x)=1.
Correction :

1. En divisant sin²(x)+cos²(x)=1 par cos²(x), on obtient tan²(x)+1=1/cos²(x), pour cos(x)≠0.

2. En divisant par sin²(x), on obtient cot²(x)+1=1/sin²(x), pour sin(x)≠0.

3. Formule d'addition avec a=b=x.

4. cos(2x)=cos²(x)-sin²(x), puis cos²(x)=1-sin²(x).

5. C'est l'identité fondamentale du cercle trigonométrique.

Exercice 04 — Équations trigonométriques

Moyen

  2. cos(x)=1/2.
  3. tan(x)=1.
  4. cot(x)=√3.
Correction :
  1. x=π/3+2kπ ou x=2π/3+2kπ.
  2. x=π/3+2kπ ou x=-π/3+2kπ.
  3. x=π/4+kπ.
  4. x=π/6+kπ.

Dans tous les cas k∈ℤ.

Exercice 08 — Identités avec arcsin et arccos

Difficile

Difficile

Étudier la fonction :

f(x)=arctan(2x)
  1. Déterminer son domaine.
  2. Étudier sa continuité.
  3. Calculer sa dérivée.
  4. Étudier le sens de variation.

Exercice 10 — Étude de la tangente

Difficile

Soit f(x)=tan(x).

  1. Déterminer le domaine de définition.
  2. Calculer la dérivée.
  3. Étudier les variations sur ]-π/2 ; π/2[.
  4. Calculer les limites aux extrémités.
  5. Déterminer les asymptotes.
  6. Calculer l'équation de la tangente en x=π/4.

Exercice 11 — Dérivée de la fonction réciproque

Difficile

Soit f(x)=sin(x) sur I=[-π/2 ; π/2].

  1. Montrer que f est bijective de I sur [-1 ; 1].
  2. Déterminer f⁻¹.
  3. Calculer (f⁻¹)'(x).
  4. Préciser le domaine de dérivabilité.
Correction :

La fonction sin est continue et strictement croissante sur I, et son image est [-1 ; 1]. Elle est donc bijective.

f⁻¹(x)=arcsin(x)
(f⁻¹)'(x)=1/√(1-x²)

Cette dérivée existe pour x∈]-1 ; 1[.

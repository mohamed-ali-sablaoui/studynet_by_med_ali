Cours complet de langage C

Cette formation explique les notions essentielles et avancées du C. L'objectif est d'apprendre à analyser un problème, construire un algorithme, écrire un programme correct, comprendre son fonctionnement en mémoire, détecter les erreurs et développer des solutions efficaces.

Méthode de travail : Lis chaque notion, comprends les exemples, recopie-les dans un fichier .c, compile-les et exécute-les. Modifie ensuite les valeurs pour observer les résultats. Ne te contente pas de mémoriser le code.
MODULE 01

Introduction au langage C

1. Qu'est-ce que la programmation ?

La programmation consiste à écrire des instructions précises afin qu'un ordinateur réalise une tâche. Un programme reçoit éventuellement des données, les traite selon un algorithme et produit un résultat.

2. Qu'est-ce que le langage C ?

Le C est un langage de programmation généraliste, compilé, procédural et proche du fonctionnement matériel. Il permet de contrôler précisément les types de données, les opérations et la mémoire.

Il est utilisé notamment dans :

  • Les systèmes d'exploitation et les noyaux.
  • Les pilotes et logiciels proches du matériel.
  • Les systèmes embarqués et les microcontrôleurs.
  • Les compilateurs et interpréteurs.
  • Les bibliothèques performantes et les outils système.
  • Les applications nécessitant un contrôle précis des ressources.

3. Pourquoi apprendre le C ?

  • Comprendre comment les données sont représentées en mémoire.
  • Maîtriser les pointeurs et les adresses.
  • Comprendre la compilation et l'édition de liens.
  • Apprendre les bases de l'algorithmique.
  • Développer une discipline de programmation rigoureuse.

4. Langage compilé : comment fonctionne le C ?

Contrairement à un langage interprété de manière classique, le programme C est généralement transformé en programme exécutable par une chaîne de compilation.

  1. Édition : écrire le code source dans un fichier .c.
  2. Prétraitement : traiter les directives comme #include et #define.
  3. Compilation : traduire le code C en code assembleur ou en représentation intermédiaire.
  4. Assemblage : produire des fichiers objets.
  5. Édition de liens : relier les fichiers objets et les bibliothèques.
  6. Exécution : lancer le programme produit.

5. Installer un compilateur

Sur Windows, GCC peut être installé avec MSYS2. Dans le terminal UCRT64, la commande de compilation est : 

gcc --version

Pour compiler un fichier :

gcc programme.c -o programme.exe

Pour exécuter :

./programme.exe

Sur Linux :

gcc programme.c -o programme
./programme

gcc -std=c17 -Wall -Wextra -Wpedantic programme.c -o programme

MODULE 02

Structure générale d'un programme C

1. Premier programme

#include <stdio.h>

int main(void)
{
    printf("Bonjour tout le monde !\n");
    return 0;
}

2. Explication ligne par ligne

  • #include <stdio.h> : inclut les déclarations des fonctions d'entrée et de sortie standard.
  • int main(void) : définit le point d'entrée habituel du programme hébergé.
  • { } : délimitent un bloc d'instructions.
  • printf() : affiche un texte ou des valeurs formatées.
  • \n : représente un saut de ligne.
  • return 0; : indique une fin normale du programme.

3. La fonction main

La fonction main est le point de départ d'un programme C hébergé. Une forme courante est int main(void). Une autre forme standard permet de recevoir les arguments de la ligne de commande : 

int main(int argc, char *argv[])
{
    return 0;
}

4. Les instructions et le point-virgule

La plupart des instructions simples se terminent par un point-virgule. Oublier ce caractère provoque souvent une erreur de compilation. 

int age = 20;
age = age + 1;
printf("%d\n", age);

5. Les commentaires

// Commentaire sur une ligne

/*
   Commentaire
   sur plusieurs lignes
*/

int main(void)
{
    // Affichage
    printf("Bonjour\n");
    return 0;
}

6. Identificateurs et mots réservés

Un identificateur est un nom donné à une variable, une fonction, un type ou un autre élément du programme.

  • Il peut contenir des lettres, des chiffres et le caractère underscore.
  • Il ne peut pas commencer par un chiffre.
  • Il ne peut pas contenir d'espace.
  • Il ne doit pas être un mot réservé du langage.
  • Le C distingue les majuscules et les minuscules.
int age;
int age_etudiant;
int note1;
int totalPrix;

// Identificateurs invalides :
// int 2age;
// int prix total;

7. Les mots-clés du C

Le langage C possède des mots réservés comme : int, char, float, double, if, else, switch, case, for, while, do, break, continue, return, void, struct, union, enum, typedef, static, extern, const, sizeof et volatile.

8. Sensibilité à la casse

int age = 20;
int Age = 30;

printf("%d\n", age);  // 20
printf("%d\n", Age);  // 30
MODULE 03

Variables, constantes et types de données

1. Qu'est-ce qu'une variable ?

Une variable est un objet nommé qui permet de stocker une valeur en mémoire. En C, une variable possède un type qui détermine la nature des valeurs qu'elle peut représenter et les opérations possibles. 

int age = 20;
float moyenne = 14.5f;
char lettre = 'A';
double distance = 125.75;

2. Déclaration, initialisation et affectation

int nombre;       // Déclaration
nombre = 10;      // Affectation

int age = 20;     // Déclaration + initialisation

age = 25;         // Nouvelle affectation
Une variable locale automatique non initialisée possède une valeur indéterminée. Ne l'utilise pas avant de lui avoir attribué une valeur.

3. Types entiers

TypeRôle

shortType entier court.
intType entier usuel.
longType entier long.
long longType entier long long.

Les types entiers peuvent être signés (signed) ou non signés (unsigned). Les tailles exactes dépendent de l'implémentation, à l'exception de certaines garanties du standard. 

short age = 20;
int population = 120000;
long distance = 500000L;
long long grand_nombre = 9000000000LL;

unsigned int compteur = 100U;
signed int temperature = -5;

4. Types réels

TypeUtilisation

float prix = 12.5f;
double pi = 3.141592653589793;
long double valeur = 123.456L;

5. Le type char

Le type char permet de représenter un caractère de l'ensemble d'exécution de base. Les caractères sont écrits entre apostrophes. 

char lettre = 'A';
char chiffre = '7';
char symbole = '#';

printf("%c\n", lettre);
printf("%d\n", lettre);

Le format %c affiche le caractère. Le format %d affiche sa valeur entière après promotion.

6. Le type booléen

En C traditionnel, les expressions de condition utilisent une valeur entière : zéro signifie faux et une valeur non nulle signifie vrai. Depuis C99, on peut utiliser _Bool ou inclure <stdbool.h> pour disposer des noms bool, true et false. 

#include <stdio.h>
#include <stdbool.h>

int main(void)
{
    bool est_admis = true;

    if (est_admis)
        printf("Admis\n");

    return 0;
}

7. Le type void

void indique notamment qu'une fonction ne retourne aucune valeur ou qu'un pointeur ne possède pas de type d'objet spécifique. 

void afficherBonjour(void)
{
    printf("Bonjour\n");
}

8. Le type size_t et sizeof

sizeof donne la taille en octets d'un type ou d'un objet. Son résultat possède le type size_t. 

#include <stdio.h>
#include <stddef.h>

int main(void)
{
    int nombre = 10;

    printf("int : %zu octets\n", sizeof(int));
    printf("nombre : %zu octets\n", sizeof nombre);

    return 0;
}

Il ne faut pas supposer que int occupe toujours quatre octets sur toutes les plateformes.

9. Constantes avec const

const double PI = 3.141592653589793;
const int MAX_ETUDIANTS = 50;

Une variable déclarée const ne peut pas être modifiée à travers ce nom après son initialisation.

10. Les constantes symboliques avec #define

#define MAX 100
#define TAUX_TVA 0.19

int notes[MAX];

Contrairement à une variable const, une macro est remplacée par le préprocesseur avant la compilation.

11. Conversion de types

int a = 5;
int b = 2;

float resultat1 = a / b;          // 2.0
float resultat2 = (float)a / b;   // 2.5

double x = 12.75;
int y = (int)x;                   // 12

Lorsqu'une expression utilise des types différents, le langage applique des conversions arithmétiques usuelles. Une conversion explicite s'écrit avec un cast : (type)expression.

12. Débordement des entiers

Le débordement d'un entier signé entraîne un comportement indéfini en C. Les calculs doivent être conçus pour rester dans les limites du type. Les entiers non signés suivent des règles arithmétiques modulo leur plage.

13. Types de largeur fixe

L'en-tête <stdint.h> fournit des types comme int8_t, uint32_t et int64_t lorsque l'implémentation les prend en charge. 

#include <stdint.h>

int32_t temperature = -10;
uint32_t compteur = 100;
int64_t population = 8000000000LL;

La fonction printf, déclarée dans <stdio.h>, affiche des données selon une chaîne de format.

}

3. Contrôler la précision

double prix = 123.456789;

printf("%.2f\n", prix);   // 123.46
printf("%.3f\n", prix);   // 123.457
printf("%10.2f\n", prix); // Largeur minimale de 10

4. Lire une valeur avec scanf()

La fonction scanf lit des données formatées. Pour modifier une variable, on transmet généralement son adresse avec l'opérateur &. 

#include <stdio.h>

int main(void)
{
    int age;

    printf("Donner votre age : ");

    if (scanf("%d", &age) != 1) {
        printf("Saisie invalide.\n");
        return 1;
    }

    printf("Vous avez %d ans.\n", age);
    return 0;
}

5. Pourquoi utilise-t-on & avec scanf ?

int nombre = 0;

scanf("%d", &nombre);

nombre représente sa valeur. &nombre représente son adresse mémoire. scanf doit recevoir cette adresse afin d'écrire la valeur saisie dans la variable.

6. Lire plusieurs valeurs

int age;
float moyenne;

printf("Age et moyenne : ");

if (scanf("%d %f", &age, &moyenne) == 2) {
    printf("Age = %d, moyenne = %.2f\n", age, moyenne);
}

7. Lire un caractère

char lettre;

scanf(" %c", &lettre);

L'espace placé avant %c permet d'ignorer les caractères blancs précédents, notamment un retour à la ligne restant dans le flux d'entrée.

8. Lire une chaîne avec scanf

char nom[30];

scanf("%29s", nom);
printf("Nom : %s\n", nom);

Le nombre 29 limite la lecture pour laisser une place au caractère nul de fin de chaîne. Cette forme ne lit pas les espaces dans le nom.

9. Lire une ligne avec fgets

#include <stdio.h>
#include <string.h>

int main(void)
{
    char nom[100];

    printf("Donner votre nom complet : ");

    if (fgets(nom, sizeof nom, stdin) != NULL) {
        nom[strcspn(nom, "\n")] = '\0';
        printf("Bonjour %s\n", nom);
    }

    return 0;
}

fgets lit au maximum la taille indiquée moins une place pour le caractère nul. Elle conserve éventuellement le retour à la ligne si celui-ci a été lu.

10. getchar, putchar et puts

int c;

c = getchar();       // Lire un caractère
putchar(c);          // Afficher un caractère

puts("Bonjour");     // Afficher une chaîne avec retour à la ligne
N'utilise jamais gets() : cette fonction a été supprimée du standard C parce qu'elle ne permet pas de limiter correctement la taille de la saisie. Préfère fgets().

8. Incrémentation et décrémentation

int x = 5;

La pré-incrémentation modifie la variable avant de produire sa valeur. La post-incrémentation produit d'abord l'ancienne valeur, puis incrémente. 

int a = 5;
int b = a++;  // b = 5, a = 6

int c = 5;
int d = ++c;  // c = 6, d = 6

La forme générale est condition ? valeur_si_vrai : valeur_si_faux.

11. Évaluation à court-circuit

int x = 0;

1. Instruction if

2. Structure if / else

int nombre;

}
else if (note >= 16) {

int age = 20;
int permis = 1;

if (age >= 18) {
    if (permis == 1) {
        printf("Vous pouvez conduire\n");
    } else {
        printf("Vous devez obtenir le permis\n");

    printf("Age insuffisant\n");

5. Plusieurs conditions

int note = 15;
int absences = 2;

if (note >= 10 && note <= 20 && absences <= 5) {
    printf("Validation possible\n");
}

6. switch / case

La structure switch permet de choisir un bloc selon la valeur d'une expression entière ou énumérée. Les chaînes de caractères ne sont pas directement utilisables comme expression de switch en C standard. 

int choix;

printf("1. Ajouter\n");
printf("2. Modifier\n");
printf("3. Supprimer\n");
scanf("%d", &choix);

switch (choix) {
    case 1:
        printf("Ajout\n");
        break;

    case 2:
        printf("Modification\n");
        break;

    case 3:
        printf("Suppression\n");
        break;

    default:
        printf("Choix invalide\n");
}

break termine le switch. Sans lui, l'exécution peut continuer dans les cases suivantes : ce comportement s'appelle le fall-through.

7. Regrouper plusieurs cases

char lettre = 'a';

switch (lettre) {
    case 'a':
    case 'e':
    case 'i':
    case 'o':
    case 'u':
    case 'y':
        printf("Voyelle\n");
        break;

    default:
        printf("Autre caractere\n");
}

8. Vérifier un intervalle

int note = 15;

if (note >= 0 && note <= 20) {
    printf("Note valide\n");
} else {
    printf("Note invalide\n");
}
En C, écris deux comparaisons reliées par &&. L'expression mathématique 0 <= note <= 20 ne fonctionne pas comme en mathématiques.
MODULE 07

Structures répétitives : les boucles

1. Pourquoi utiliser une boucle ?

Une boucle permet de répéter un ensemble d'instructions sans recopier le même code plusieurs fois. Elle est utilisée pour parcourir des tableaux, calculer des sommes, effectuer des recherches et répéter des saisies.

2. La boucle for

La boucle for est particulièrement adaptée lorsque le nombre de répétitions est connu.

for (int i = 0; i < 5; i++) {
    printf("%d\n", i);
}

Les trois parties sont :

  • Initialisation : int i = 0.
  • Condition : i < 5.
  • Modification : i++.

Exemple : afficher les nombres de 1 à 10.

for (int i = 1; i <= 10; i++) {
    printf("%d ", i);
}

3. La boucle while

La boucle while répète ses instructions tant que la condition reste vraie. La condition est vérifiée avant chaque itération. 

int i = 1;

while (i <= 5) {
    printf("%d\n", i);
    i++;
}

4. La boucle do while

La boucle do while exécute son bloc au moins une fois, car la condition est testée après l'exécution. 

int choix;

do {
    printf("1. Continuer\n");
    printf("0. Quitter\n");
    scanf("%d", &choix);
} while (choix != 0);

5. Différence entre for, while et do while

BoucleQuand l'utiliser ?
forNombre de répétitions connu ou parcours indexé.
whileRépéter tant qu'une condition est vraie.
do whileExécuter au moins une fois avant de tester.

6. Boucles imbriquées

for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 4; j++) {
        printf("* ");
    }
    printf("\n");
}

Résultat :

* * * *
* * * *
* * * *

7. break

L'instruction break arrête immédiatement la boucle la plus proche ou le switch courant. 

for (int i = 1; i <= 10; i++) {
    if (i == 5) {
        break;
    }

    printf("%d ", i);
}

8. continue

L'instruction continue saute le reste du corps de l'itération actuelle et passe à l'itération suivante. 

for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) {
        continue;
    }

    printf("%d ", i);
}

9. Boucle infinie

while (1) {
    printf("Boucle infinie\n");
    break;
}

Une boucle infinie peut être volontaire, notamment dans un programme embarqué ou un serveur, mais elle doit disposer d'une stratégie de sortie ou de contrôle adaptée.

10. Compteur et accumulateur

int compteur = 0;
int somme = 0;

for (int i = 1; i <= 10; i++) {
    compteur++;
    somme += i;
}

printf("Compteur = %d\n", compteur);
printf("Somme = %d\n", somme);

11. Boucle avec sentinelle

Une sentinelle est une valeur spéciale qui indique la fin de la saisie. 

int nombre;
int somme = 0;

printf("Donner un nombre (0 pour terminer) : ");
scanf("%d", &nombre);

while (nombre != 0) {
    somme += nombre;

    printf("Donner un nombre (0 pour terminer) : ");
    scanf("%d", &nombre);
}

printf("Somme = %d\n", somme);

12. Parcourir les chiffres d'un entier

int nombre = 5382;

while (nombre > 0) {
    int chiffre = nombre % 10;
    printf("%d\n", chiffre);
    nombre /= 10;
}

Le modulo extrait le dernier chiffre. La division entière supprime ce dernier chiffre.

MODULE 08

Fonctions et modularité

1. Qu'est-ce qu'une fonction ?

Une fonction est un bloc de code qui réalise une tâche précise. Elle permet de découper un problème en sous-problèmes, de réutiliser du code et d'améliorer la lisibilité.

2. Déclaration, définition et appel

#include <stdio.h>

// Prototype
int addition(int a, int b);

// Définition
int addition(int a, int b)
{
    return a + b;
}

int main(void)
{
    int resultat = addition(5, 3);
    printf("%d\n", resultat);

  • Le prototype annonce la fonction.

Pointeurs et adresses mémoire

1. Qu'est-ce qu'un pointeur ?

Un pointeur est une variable qui stocke l'adresse d'un objet ou d'une fonction. Les pointeurs sont essentiels en C pour manipuler les tableaux, transmettre des objets aux fonctions, gérer la mémoire dynamique et construire des structures de données.

2. Comprendre les adresses

int nombre = 10;

printf("Valeur : %d\n", nombre);
printf("Adresse : %p\n", (void *)&nombre);

L'opérateur & fournit l'adresse d'un objet. L'opérateur *, lorsqu'il est appliqué à un pointeur valide, permet d'accéder à l'objet pointé.

3. Déclaration d'un pointeur

int nombre = 10;
int *p = &nombre;

printf("%d\n", *p);

int *p signifie que p est un pointeur vers un entier. *p désigne l'entier situé à l'adresse contenue dans p.

4. Modifier une variable avec un pointeur

int nombre = 10;
int *p = &nombre;

*p = 50;

printf("%d\n", nombre); // 50

5. Pointeur NULL

int *p = NULL;

if (p == NULL) {
    printf("Aucune adresse valide associee\n");
}

Un pointeur NULL ne désigne aucun objet. Il ne faut pas le déréférencer.

6. Pointeurs et fonctions

void echanger(int *a, int *b)
{
    int temp = *a;
    *a = *b;
    *b = temp;
}

int main(void)
{
    int x = 10;
    int y = 20;

    echanger(&x, &y);

    printf("%d %d\n", x, y);
    return 0;
}

7. Pointeurs et tableaux

int t[4] = {10, 20, 30, 40};

int *p = t;

printf("%d\n", *p);       // 10
printf("%d\n", *(p + 1)); // 20
printf("%d\n", p[2]);     // 30

Dans la plupart des expressions, le nom d'un tableau est converti en pointeur vers son premier élément. Cette conversion ne signifie pas qu'un tableau et un pointeur sont le même type.

8. Arithmétique des pointeurs

int t[4] = {10, 20, 30, 40};
int *p = t;

p++;  // Pointe vers t[1]
p--;  // Pointe vers t[0]

Ajouter 1 à un pointeur vers int avance vers l'entier suivant, donc de sizeof(int) octets. L'arithmétique des pointeurs n'est définie que dans les limites du même tableau et jusqu'à sa position juste après le dernier élément.

9. Pointeur et tableau : différence

int t[5];
int *p = t;

printf("%zu\n", sizeof t); // Taille totale du tableau
printf("%zu\n", sizeof p); // Taille du pointeur

Dans cette fonction, le tableau est ajusté en pointeur : 

void afficher(int t[], int taille)
{
    for (int i = 0; i < taille; i++)
        printf("%d ", t[i]);
}

10. Pointeur vers pointeur

int nombre = 10;
int *p = &nombre;
int **pp = &p;

printf("%d\n", **pp);

Un pointeur vers pointeur contient l'adresse d'un autre pointeur.

11. Pointeur void *

void * est un pointeur générique vers un objet. Il peut recevoir un pointeur d'objet de différents types. Avant de déréférencer un tel pointeur, il faut le convertir vers un type d'objet approprié. 

int nombre = 10;
void *p = &nombre;

printf("%d\n", *(int *)p);

12. const et pointeurs

int a = 10;
int b = 20;

const int *p1 = &a; // Valeur non modifiable via p1
int *const p2 = &a; // Adresse de p2 non modifiable
const int *const p3 = &a; // Les deux sont fixes

13. Pointeur non initialisé et pointeur pendant

Ne déréférence jamais un pointeur non initialisé, libéré, pendant ou invalide. Un pointeur doit désigner un objet vivant et accessible avant tout accès à l'objet pointé.
MODULE 12

Allocation dynamique de mémoire

1. Pourquoi allouer dynamiquement ?

Les tableaux classiques possèdent une taille déterminée selon leur déclaration. L'allocation dynamique permet de réserver de la mémoire pendant l'exécution, par exemple lorsque la taille dépend d'une saisie.

2. malloc()

La fonction malloc, déclarée dans <stdlib.h>, réserve un bloc de mémoire non initialisé et retourne un pointeur vers ce bloc, ou NULL en cas d'échec. 

#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int n = 5;
    int *t = malloc((size_t)n * sizeof *t);

    if (t == NULL) {
        printf("Allocation impossible\n");
        return 1;
    }

    for (int i = 0; i < n; i++)
        t[i] = i * 10;

    for (int i = 0; i < n; i++)
        printf("%d ", t[i]);

    free(t);
    return 0;
}

3. calloc()

calloc réserve un tableau de blocs et initialise tous les bits du bloc alloué à zéro. 

int n = 10;

int *t = calloc((size_t)n, sizeof *t);

if (t == NULL) {
    return 1;
}

free(t);

4. realloc()

realloc tente de modifier la taille d'un bloc alloué. Le bloc peut être déplacé. En cas d'échec, l'ancien bloc reste valide. 

int *temp = realloc(t, nouvelle_taille * sizeof *t);

if (temp != NULL) {
    t = temp;
} else {
    // t reste valide : ne pas perdre son adresse
}

Il faut vérifier les dépassements possibles lors du calcul de la taille.

5. free()

int *p = malloc(sizeof *p);

if (p != NULL) {
    *p = 100;
    free(p);
    p = NULL;
}

free libère un bloc alloué dynamiquement. Après libération, il ne faut plus accéder à ce bloc.

6. Les erreurs de gestion mémoire

ErreurDescription
Memory leakBloc alloué qui n'est jamais libéré.
Double freeLibérer deux fois le même bloc.
Use after freeAccéder à un bloc après sa libération.
Buffer overflowÉcrire au-delà de la zone réservée.
NULL dereferenceDéréférencer un pointeur NULL.

7. Bonnes habitudes

  • Vérifier chaque allocation.
  • Libérer chaque bloc lorsque son utilisation est terminée.
  • Ne pas perdre le pointeur original en cas d'échec de realloc.
  • Vérifier les calculs de taille avant l'allocation.
  • Ne jamais utiliser un pointeur après free.

MODULE 19

Récursivité

1. Définition

Une fonction récursive est une fonction qui s'appelle elle-même. Elle permet de résoudre certains problèmes en les décomposant en sous-problèmes de même nature.

2. Les deux éléments obligatoires

  • Cas de base : condition qui arrête les appels récursifs.
  • Cas récursif : appel avec un problème plus petit.

3. Factorielle

long long factorielle(int n)
{
    if (n < 0)
        return -1;

    if (n == 0 || n == 1)
        return 1;

    return n * factorielle(n - 1);
}

Mathématiquement :

n! = n × (n - 1) × ... × 2 × 1 et 0! = 1.

4. Somme de 1 à n

int somme(int n)
{
    if (n <= 0)
        return 0;

    return n + somme(n - 1);
}

5. Fibonacci

int fibonacci(int n)
{
    if (n <= 1)
        return n;

    return fibonacci(n - 1) + fibonacci(n - 2);
}
Cette version récursive simple est très coûteuse pour les grandes valeurs de n. Une solution itérative ou une mémorisation des résultats est beaucoup plus efficace.

6. PGCD récursif

int pgcd(int a, int b)
{
    if (b == 0)
        return a;

    return pgcd(b, a % b);
}

7. Tour de Hanoï

void hanoi(int n, char depart, char arrivee, char auxiliaire)
{
    if (n == 1) {
        printf("%c -> %c\n", depart, arrivee);
        return;
    }

    hanoi(n - 1, depart, auxiliaire, arrivee);
    printf("%c -> %c\n", depart, arrivee);
    hanoi(n - 1, auxiliaire, arrivee, depart);
}

8. Avantages et limites

  • Le code peut être plus naturel pour les arbres et les problèmes récursifs.
  • La pile d'appels consomme de la mémoire.
  • Une profondeur trop importante peut provoquer un débordement de pile.
  • Une mauvaise condition d'arrêt peut provoquer une récursion infinie.
MODULE 20

Algorithmes de recherche

1. Recherche séquentielle

La recherche séquentielle examine les éléments un par un jusqu'à trouver la valeur recherchée ou atteindre la fin du tableau. 

int rechercheLineaire(const int t[], int n, int valeur)
{
    for (int i = 0; i < n; i++) {
        if (t[i] == valeur)
            return i;
    }

    return -1;
}

Complexité temporelle : O(n) dans le pire cas.

2. Recherche dichotomique

La recherche dichotomique divise à chaque étape la zone de recherche en deux. Le tableau doit être trié. 

int rechercheDichotomique(const int t[], int n, int valeur)
{
    int gauche = 0;
    int droite = n - 1;

    while (gauche <= droite) {
        int milieu = gauche + (droite - gauche) / 2;

        if (t[milieu] == valeur)
            return milieu;

        if (t[milieu] < valeur)
            gauche = milieu + 1;
        else
            droite = milieu - 1;
    }

    return -1;
}

Complexité temporelle : O(log n).

MODULE 21

Algorithmes de tri

1. Pourquoi trier ?

Le tri consiste à organiser les éléments selon un ordre croissant, décroissant ou selon un critère particulier.

2. Tri à bulles (Bubble Sort)

Le tri à bulles compare des éléments voisins et les échange lorsqu'ils sont dans le mauvais ordre. 

void triBulles(int t[], int n)
{
    for (int i = 0; i < n - 1; i++) {
        int echange = 0;

        for (int j = 0; j < n - 1 - i; j++) {
            if (t[j] > t[j + 1]) {
                int temp = t[j];
                t[j] = t[j + 1];
                t[j + 1] = temp;
                echange = 1;
            }
        }

        if (!echange)
            break;
    }
}

Complexité moyenne et pire cas : O(n²).

3. Tri par sélection

Le tri par sélection recherche le plus petit élément de la partie non triée et le place à sa position définitive. 

void triSelection(int t[], int n)
{
    for (int i = 0; i < n - 1; i++) {
        int min = i;

        for (int j = i + 1; j < n; j++) {
            if (t[j] < t[min])
                min = j;
        }

        int temp = t[i];
        t[i] = t[min];
        t[min] = temp;
    }
}

4. Tri par insertion

void triInsertion(int t[], int n)
{
    for (int i = 1; i < n; i++) {
        int cle = t[i];
        int j = i - 1;

        while (j >= 0 && t[j] > cle) {
            t[j + 1] = t[j];
            j--;
        }

        t[j + 1] = cle;
    }
}

Structures de données fondamentales

1. Liste chaînée

Une liste chaînée est constituée de nœuds. Chaque nœud contient une donnée et un pointeur vers le nœud suivant. 

typedef struct Noeud {
    int valeur;
    struct Noeud *suivant;
} Noeud;

2. Créer un nœud

#include <stdlib.h>

Noeud *creerNoeud(int valeur)
{
    Noeud *n = malloc(sizeof *n);

    if (n == NULL)
        return NULL;

    n->valeur = valeur;
    n->suivant = NULL;

    return n;
}

3. Ajouter au début

void ajouterDebut(Noeud **tete, int valeur)
{
    Noeud *n = creerNoeud(valeur);

    if (n == NULL)
        return;

    n->suivant = *tete;
    *tete = n;
}

4. Parcourir une liste

void afficherListe(const Noeud *tete)
{
    while (tete != NULL) {
        printf("%d -> ", tete->valeur);
        tete = tete->suivant;
    }

    printf("NULL\n");
}

5. Libérer une liste

void libererListe(Noeud **tete)
{
    Noeud *courant = *tete;

    while (courant != NULL) {
        Noeud *suivant = courant->suivant;
        free(courant);
        courant = suivant;
    }

    *tete = NULL;
}

6. Pile (Stack)

Une pile suit le principe LIFO : le dernier élément ajouté est le premier retiré. Les opérations classiques sont push, pop et peek.

7. File (Queue)

Une file suit le principe FIFO : le premier élément ajouté est le premier retiré. Les opérations classiques sont enqueue et dequeue.

8. Arbre binaire

typedef struct NoeudArbre {
    int valeur;
    struct NoeudArbre *gauche;
    struct NoeudArbre *droite;
} NoeudArbre;

Un arbre binaire possède au maximum deux enfants par nœud. Les parcours classiques sont préfixe, infixe et postfixe.

6. Undefined Behavior

Un comportement indéfini signifie que le standard C n'impose aucun résultat pour une opération. Le compilateur peut optimiser le programme en supposant que ces situations ne se produisent pas.

Exemples à éviter :

  • Lire une variable locale non initialisée.
  • Dépasser les limites d'un tableau.
  • Déréférencer un pointeur invalide.
  • Diviser un entier par zéro.
  • Déborder un entier signé.
  • Utiliser une zone mémoire après sa libération.
  • Écrire dans une chaîne littérale.
  • Utiliser des spécificateurs printf/scanf incompatibles avec les types.

7. const, volatile et restrict

  • const limite les modifications à travers un identificateur.
  • volatile indique que les accès à l'objet doivent respecter les règles particulières d'accès observables, notamment pour certains registres matériels.
  • restrict est une promesse concernant l'accès à un objet par certains pointeurs pendant la durée de leur association.
void copier(size_t n,
            int * restrict destination,
            const int * restrict source)
{
    for (size_t i = 0; i < n; i++)
        destination[i] = source[i];
}

Ne déclare pas une variable volatile simplement pour rendre un programme multithread sûr. La synchronisation entre threads nécessite des mécanismes adaptés, notamment ceux de C11.

  • Les valeurs ordinaires.
  • La valeur minimale et maximale autorisées.
  • Les entrées nulles.
  • Les tableaux vides ou de taille minimale lorsque cela est permis.
  • Les données invalides.
  • Les cas particuliers et les erreurs d'allocation.

  2. Déterminer les données d'entrée.
  3. Déterminer les résultats attendus.
  4. Identifier les contraintes et les cas limites.
  5. Écrire l'algorithme en langage naturel ou en pseudo-code.
  6. Choisir les variables et les types adaptés.
  7. Découper le programme en fonctions si nécessaire.
  8. Écrire le code C.
  9. Compiler avec les avertissements activés.
  10. Tester plusieurs jeux de données.
  11. Corriger les erreurs et vérifier la gestion mémoire.

1. Qu’est-ce qu’Arduino Uno ?

Arduino Uno est une carte électronique programmable. Elle contient un microcontrôleur qui exécute le programme enregistré dans sa mémoire. Elle peut lire des informations provenant de capteurs (bouton, lumière, température…) puis commander des composants (LED, buzzer, moteur…) selon les instructions du programme.

ENTRÉE

Mesurer / détecter

Un bouton, un potentiomètre ou un capteur fournit une information à la carte.

TRAITEMENT

Décider

Le microcontrôleur lit les valeurs et applique la logique du programme.

SORTIE

Agir

Une LED s’allume, un buzzer sonne ou un moteur reçoit une commande adaptée.

Les éléments principaux de la carte

Illustration pédagogique simplifiée, non destinée au câblage réel.

Microcontrôleur

L’ATmega328P exécute le programme. Il gère les entrées, les sorties, les temporisations et les communications.

Port USB

Il sert généralement à téléverser le programme depuis l’ordinateur et à alimenter la carte pendant les essais.

Régulateur et alimentation

Ils permettent d’alimenter la carte dans les limites prévues. Respecte toujours les caractéristiques officielles de la carte.

Bouton RESET

Il redémarre le programme depuis le début. Il n’efface pas le programme téléversé.

2. Les broches et caractéristiques importantes

Sur l’Arduino Uno R3 classique, les broches numériques sont numérotées de 0 à 13 et les entrées analogiques de A0 à A5. La logique de la carte fonctionne en 5 V. Une broche n’est pas une alimentation puissante : elle sert à transmettre un signal et possède une limite de courant.

3. Préparer le matériel et réaliser un branchement

Pour commencer, prépare une carte Uno, un câble USB de données, une breadboard, des fils Dupont, des LED, des résistances, des boutons et quelques capteurs. La breadboard permet de relier les composants sans soudure.

Comment fonctionne une breadboard ?

  • Les groupes de cinq trous d’une même rangée sont reliés entre eux dans la zone centrale.
  • La fente centrale sépare les deux côtés.
  • Les rails latéraux servent souvent à distribuer le 5 V et le GND.
  • Selon le modèle, les rails peuvent être coupés au milieu : vérifie la continuité.

Méthode de câblage

  1. Débranche l’alimentation.
  2. Identifie chaque broche dans le schéma du composant.
  3. Place les composants sans court-circuit.
  4. Relie les masses communes.
  5. Vérifie le câblage avant d’alimenter.
  6. Teste d’abord un montage simple.

Exemple : connecter une LED à D8

Relie D8 à une résistance, puis à l’anode de la LED (patte longue). Relie la cathode (patte courte) au GND. La résistance est indispensable pour limiter le courant. Une valeur de 220 Ω à 330 Ω convient souvent pour un montage pédagogique avec une LED ordinaire, sous réserve de ses caractéristiques.

Attention : ne branche jamais une LED directement entre une sortie et GND sans résistance. Ne relie jamais directement 5 V à GND : cela crée un court-circuit.

4. Installer l’environnement et téléverser un programme

  1. Installe Arduino IDE depuis le site officiel : arduino.cc/en/software.
  2. Branche l’Arduino avec un câble USB qui transporte les données.
  3. Dans Arduino IDE, choisis Tools / Outils → Board / Type de carte → Arduino Uno.
  4. Choisis le port série correspondant dans Tools / Outils → Port.
  5. Écris le programme, clique sur Verify pour compiler, puis Upload pour téléverser.
  6. Si la carte n’apparaît pas, vérifie le câble, le port USB et le pilote USB-série de ta carte.

Structure d’un programme Arduino

void setup() {
  // Exécutée une seule fois au démarrage
}

void loop() {
  // Répétée tant que la carte est alimentée
}

setup() sert à initialiser les broches et les communications. loop() contient les actions répétées. Les instructions se terminent généralement par un point-virgule ;. Les blocs sont délimités par { }.

Premier programme : faire clignoter la LED intégrée

void setup() {
  pinMode(LED_BUILTIN, OUTPUT);
}

void loop() {
  digitalWrite(LED_BUILTIN, HIGH);
  delay(1000);

  digitalWrite(LED_BUILTIN, LOW);
  delay(1000);
}

pinMode() définit le rôle d’une broche. digitalWrite() place une sortie à HIGH ou LOW. delay(1000) attend 1000 millisecondes, soit une seconde. Sur Uno, la LED intégrée est généralement reliée à D13.

4.2 Les conditions : if, else if et else

Une condition permet au programme de prendre une décision. Le programme teste une expression : si elle est vraie, il exécute un bloc ; sinon, il peut exécuter un autre bloc.

int temperature = 32;

void setup() {
  Serial.begin(9600);
}

void loop() {
  if (temperature > 30) {
    Serial.println("Temperature elevee");
  } else {
    Serial.println("Temperature normale");
  }

  delay(2000);
}

Ici, la température vaut 32. L'expression temperature > 30 est vraie : le programme affiche donc « Temperature elevee ».

Pour gérer plusieurs situations, on utilise else if :

int valeur = 650;

void setup() {
  Serial.begin(9600);
}

void loop() {
  if (valeur < 300) {
    Serial.println("Faible");
  } else if (valeur < 700) {
    Serial.println("Moyenne");
  } else {
    Serial.println("Elevee");
  }

  delay(1000);
}

Avec une valeur de 650, la première condition est fausse et la deuxième est vraie : le résultat est « Moyenne ». Le bloc else est exécuté uniquement si toutes les conditions précédentes sont fausses.

4.4 La boucle for

La boucle for est pratique lorsque l'on connaît le nombre de répétitions. Elle contient trois parties : initialisation, condition et mise à jour.

for (int i = 0; i < 5; i++) {
  Serial.println(i);
}

Résultat affiché : 0, 1, 2, 3, 4. La boucle commence avec i = 0, continue tant que i < 5, puis augmente i de 1 à chaque tour avec i++.

Exemple : faire clignoter une LED cinq fois :

const int led = 8;

void setup() {
  pinMode(led, OUTPUT);

  for (int i = 0; i < 5; i++) {
    digitalWrite(led, HIGH);
    delay(500);
    digitalWrite(led, LOW);
    delay(500);
  }
}

void loop() {
  // Rien à répéter ici
}

4.5 La boucle while

La boucle while répète un bloc tant que sa condition reste vraie. Elle est utile lorsqu'on ne connaît pas à l'avance le nombre de répétitions.

int compteur = 0;

void setup() {
  Serial.begin(9600);

  while (compteur < 5) {
    Serial.println(compteur);
    compteur++;
  }
}

void loop() {
}

La boucle affiche 0 à 4. Il est important de modifier la variable utilisée dans la condition. Sinon, si la condition reste toujours vraie, le programme peut rester bloqué dans une boucle infinie.

4.6 La boucle do...while

La boucle do...while exécute son bloc au moins une fois, puis vérifie la condition.

int compteur = 0;

void setup() {
  Serial.begin(9600);

  do {
    Serial.println(compteur);
    compteur++;
  } while (compteur < 3);
}

void loop() {
}

Résultat : 0, 1, 2. Même si la condition était fausse dès le départ, le bloc do serait exécuté une première fois.

4.7 Combiner boucles et conditions

Dans un projet réel, on combine souvent une boucle et une condition. Exemple : allumer une LED cinq fois seulement si une température dépasse 30 °C.

const int led = 8;
float temperature = 35.0;

void setup() {
  pinMode(led, OUTPUT);

  if (temperature > 30) {
    for (int i = 0; i < 5; i++) {
      digitalWrite(led, HIGH);
      delay(300);
      digitalWrite(led, LOW);
      delay(300);
    }
  }
}

void loop() {
}

4.8 Les fonctions

Une fonction regroupe des instructions qui réalisent une tâche précise. Elle évite de répéter le même code à plusieurs endroits et rend le programme plus facile à comprendre.

int additionner(int a, int b) {
  return a + b;
}

void afficherMessage() {
  Serial.println("Bonjour Arduino");
}

void setup() {
  Serial.begin(9600);

  int resultat = additionner(4, 6);
  Serial.println(resultat);

  afficherMessage();
}

void loop() {
}

La fonction additionner() reçoit deux paramètres et retourne leur somme avec return. La fonction afficherMessage() est de type void : elle ne retourne aucune valeur.

4.9 delay() et millis()

delay() bloque l'exécution du programme pendant une durée donnée. Pendant cette attente, le programme ne revient pas immédiatement lire les boutons ou les capteurs. Pour des systèmes qui doivent rester réactifs, on peut utiliser millis(), qui retourne le nombre de millisecondes écoulées depuis le démarrage.

const int led = 8;
unsigned long ancienTemps = 0;
const unsigned long intervalle = 1000;
bool etatLed = false;

void setup() {
  pinMode(led, OUTPUT);
}

void loop() {
  unsigned long maintenant = millis();

  if (maintenant - ancienTemps >= intervalle) {
    ancienTemps = maintenant;
    etatLed = !etatLed;
    digitalWrite(led, etatLed);
  }

  // Le programme peut faire d'autres tâches ici.
}

Cette LED change d'état toutes les secondes sans bloquer la boucle principale avec un long delay(). Cette technique est utile lorsqu'il faut surveiller plusieurs capteurs et boutons en même temps.

5. Entrées et sorties : les notions indispensables

5.1 Entrée numérique : bouton poussoir

Un bouton fournit deux états logiques. Avec INPUT_PULLUP, la résistance interne de tirage maintient l’entrée à HIGH au repos ; quand le bouton relie la broche à GND, elle passe à LOW. La logique est donc inversée.

const int bouton = 2;
const int led = 8;

void setup() {
  pinMode(bouton, INPUT_PULLUP);
  pinMode(led, OUTPUT);
}

void loop() {
  bool appuye = (digitalRead(bouton) == LOW);
  digitalWrite(led, appuye ? HIGH : LOW);
}
À retenir : avec INPUT_PULLUP, bouton relâché = HIGH et bouton appuyé = LOW. Le bouton doit être câblé entre la broche choisie et GND.

5.2 Entrée analogique : potentiomètre

Une entrée analogique convertit une tension en une valeur numérique. Sur Uno R3, analogRead() retourne normalement une valeur de 0 à 1023 avec la référence par défaut. Un potentiomètre se branche avec ses deux extrémités sur 5 V et GND, et son curseur sur A0.

const int potentiometre = A0;

void setup() {
  Serial.begin(9600);
}

void loop() {
  int valeur = analogRead(potentiometre);
  Serial.println(valeur);
  delay(200);
}

5.3 Sortie PWM : régler une luminosité

Le PWM (modulation de largeur d’impulsion) permet de simuler une sortie analogique pour certains usages, par exemple régler la luminosité d’une LED. Sur Uno R3, les broches PWM sont 3, 5, 6, 9, 10 et 11. analogWrite() utilise généralement une valeur de 0 à 255.

const int led = 9;
const int potentiometre = A0;

void setup() {
  pinMode(led, OUTPUT);
}

void loop() {
  int mesure = analogRead(potentiometre);
  int luminosite = map(mesure, 0, 1023, 0, 255);
  analogWrite(led, luminosite);
}

5.4 Les LED : types, branchement et commande

Une LED (diode électroluminescente) transforme l'énergie électrique en lumière. Elle est polarisée : le courant doit circuler dans le bon sens. Sur une LED classique, la patte longue correspond généralement à l'anode (+) et la patte courte à la cathode (-). Le côté plat du boîtier indique souvent la cathode.

Type de LEDCaractéristiqueUtilisation
LED classiqueUne seule couleur, deux pattesVoyant d'état
LED RGBRouge, vert et bleu dans le même composantCréer différentes couleurs
LED intégréeDéjà montée sur la carteTests rapides avec LED_BUILTIN
Ruban LED adressableLED commandées individuellement selon le modèleÉclairage et animations

Une résistance en série limite le courant. La valeur doit être choisie selon la tension d'alimentation, la tension directe de la LED et le courant souhaité. Une estimation simple est :

R = (V alimentation − V LED) / I LED

Exemple : alimentation 5 V, LED rouge de tension directe approximative 2 V, courant choisi 10 mA (0,01 A) :

R = (5 − 2) / 0,01 = 300 Ω

Une résistance normalisée proche de 330 Ω peut convenir dans cet exemple. Il faut toujours vérifier les caractéristiques de la LED et les limites de la broche.

LED RGB : commander trois couleurs

Une LED RGB contient trois LED : rouge, vert et bleu. En réglant l'intensité de chaque couleur avec le PWM, on peut mélanger les couleurs. Il existe des modèles à anode commune et à cathode commune : le câblage et la logique de commande diffèrent.

const int rouge = 9;
const int vert = 10;
const int bleu = 11;

void setup() {
  pinMode(rouge, OUTPUT);
  pinMode(vert, OUTPUT);
  pinMode(bleu, OUTPUT);
}

void loop() {
  // Rouge
  analogWrite(rouge, 255);
  analogWrite(vert, 0);
  analogWrite(bleu, 0);
  delay(1000);

  // Vert
  analogWrite(rouge, 0);
  analogWrite(vert, 255);
  analogWrite(bleu, 0);
  delay(1000);

  // Bleu
  analogWrite(rouge, 0);
  analogWrite(vert, 0);
  analogWrite(bleu, 255);
  delay(1000);

  // Blanc : les trois couleurs sont activées
  analogWrite(rouge, 255);
  analogWrite(vert, 255);
  analogWrite(bleu, 255);
  delay(1000);
}

Ce code suppose une LED RGB à cathode commune. Pour une LED à anode commune, la logique est inversée : une valeur PWM faible peut correspondre à une luminosité élevée. Utilise une résistance adaptée sur chaque canal.

5.6 Capteur LDR : mesurer la lumière

Une LDR est une résistance photosensible. Sa résistance diminue généralement lorsque la lumière augmente. Pour la lire avec Arduino, on l'associe à une résistance fixe afin de former un diviseur de tension. Le point central est connecté à une entrée analogique, par exemple A0.

const int ldr = A0;

void setup() {
  Serial.begin(9600);
}

void loop() {
  int lumiere = analogRead(ldr);

  Serial.print("Valeur de luminosite : ");
  Serial.println(lumiere);

  if (lumiere < 300) {
    Serial.println("Il fait sombre");
  } else if (lumiere < 700) {
    Serial.println("Luminosite moyenne");
  } else {
    Serial.println("Forte luminosite");
  }

  delay(500);
}

Les seuils 300 et 700 sont des exemples : ils doivent être ajustés en observant les valeurs réelles de ton montage. Le sens de variation peut être inversé selon la position de la LDR et de la résistance dans le diviseur.

5.7 Capteur LM35 : mesurer la température

Le LM35 est un capteur analogique dont la sortie varie avec la température. Pour un LM35 classique, la sensibilité est d'environ 10 mV par degré Celsius. La formule simplifiée est donc : Température (°C) = tension de sortie (V) × 100.

const int capteur = A0;

void setup() {
  Serial.begin(9600);
}

void loop() {
  int valeur = analogRead(capteur);

  float tension = valeur * (5.0 / 1023.0);
  float temperature = tension * 100.0;

  Serial.print("Temperature : ");
  Serial.print(temperature);
  Serial.println(" C");

  if (temperature > 30) {
    Serial.println("Attention : temperature elevee");
  }

  delay(1000);
}

Cette conversion suppose une référence ADC de 5 V et un LM35 classique. La précision réelle dépend de la référence de tension, du capteur et du montage. Vérifie le brochage du modèle avant de l'alimenter.

5.8 Capteurs DHT11 et DHT22

Les capteurs DHT11 et DHT22 fournissent une température et une humidité relative. Ils utilisent un protocole numérique spécifique. Une bibliothèque adaptée simplifie leur lecture. Le DHT22 offre généralement une plage et une précision différentes du DHT11 ; consulte la fiche technique pour choisir le bon modèle.

#include <DHT.h>

#define DHTPIN 2
#define DHTTYPE DHT11

DHT dht(DHTPIN, DHTTYPE);

void setup() {
  Serial.begin(9600);
  dht.begin();
}

void loop() {
  float humidite = dht.readHumidity();
  float temperature = dht.readTemperature();

  if (isnan(humidite) || isnan(temperature)) {
    Serial.println("Erreur de lecture du capteur");
  } else {
    Serial.print("Temperature : ");
    Serial.print(temperature);
    Serial.println(" C");

    Serial.print("Humidite : ");
    Serial.print(humidite);
    Serial.println(" %");
  }

  delay(2000);
}

Installe une bibliothèque DHT compatible depuis le gestionnaire de bibliothèques Arduino. Le type défini dans DHTTYPE doit correspondre au capteur réellement utilisé. Respecte l'intervalle minimal entre deux mesures indiqué dans sa documentation.

5.9 Capteur ultrason HC-SR04 : mesurer une distance

Le HC-SR04 envoie une impulsion ultrasonore et mesure le temps nécessaire au retour de l'écho. La broche TRIG déclenche la mesure et la broche ECHO fournit une impulsion dont la durée est liée au temps de trajet.

La formule approximative est : distance en cm = durée en µs × 0,0343 / 2. On divise par deux parce que l'onde parcourt la distance aller puis retour.

const int trig = 7;
const int echo = 6;

void setup() {
  pinMode(trig, OUTPUT);
  pinMode(echo, INPUT);
  Serial.begin(9600);
}

void loop() {
  digitalWrite(trig, LOW);
  delayMicroseconds(2);

  digitalWrite(trig, HIGH);
  delayMicroseconds(10);
  digitalWrite(trig, LOW);

  long duree = pulseIn(echo, HIGH, 30000);

  if (duree == 0) {
    Serial.println("Aucun echo detecte");
  } else {
    float distance = duree * 0.0343 / 2.0;

    Serial.print("Distance : ");
    Serial.print(distance);
    Serial.println(" cm");
  }

  delay(100);
}

Le délai maximal de pulseIn() évite une attente trop longue. La portée dépend du capteur et des conditions de mesure. Vérifie aussi la compatibilité des niveaux logiques ECHO avec ta carte ou ton module.

5.10 Capteur PIR : détecter un mouvement

Un capteur PIR détecte les variations du rayonnement infrarouge dans son champ de vision. Il fournit généralement un signal numérique : HIGH lorsqu'un mouvement est détecté et LOW lorsqu'il ne l'est pas, selon la configuration du module.

const int pir = 2;
const int led = 8;

void setup() {
  pinMode(pir, INPUT);
  pinMode(led, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int mouvement = digitalRead(pir);

  if (mouvement == HIGH) {
    digitalWrite(led, HIGH);
    Serial.println("Mouvement detecte");
  } else {
    digitalWrite(led, LOW);
    Serial.println("Aucun mouvement");
  }

  delay(200);
}

Certains modules PIR ont un temps de stabilisation au démarrage et des réglages de sensibilité ou de durée. Attends la fin de cette phase avant de tirer des conclusions sur les mesures.

5.11 Commander un buzzer

Un buzzer actif peut produire un son lorsqu'il est alimenté correctement. Un buzzer passif a besoin d'un signal de fréquence, que l'on peut générer avec tone(). Vérifie le courant et les caractéristiques du composant avant de le connecter directement à une sortie.

const int buzzer = 8;

void setup() {
}

void loop() {
  tone(buzzer, 1000); // Son de 1000 Hz
  delay(500);

  noTone(buzzer);
  delay(500);
}

Un moteur transforme l'énergie électrique en mouvement. Tous les moteurs ne se commandent pas de la même manière : le choix du circuit de commande dépend du type de moteur, de sa tension, de son courant et de l'application.

HIGHLOWSens 1
LOWHIGHSens 2
LOWLOWArrêt ou roue libre selon le driver
HIGHHIGHFreinage ou état particulier selon le driver

Exemple générique pour un driver possédant IN1, IN2 et ENA :

const int IN1 = 8;
const int IN2 = 9;
const int ENA = 5;

void setup() {
  pinMode(IN1, OUTPUT);
  pinMode(IN2, OUTPUT);
  pinMode(ENA, OUTPUT);
}

void loop() {
  // Sens 1 à vitesse moyenne
  digitalWrite(IN1, HIGH);
  digitalWrite(IN2, LOW);
  analogWrite(ENA, 150);
  delay(2000);

  // Arrêt
  analogWrite(ENA, 0);
  delay(1000);

  // Sens 2
  digitalWrite(IN1, LOW);
  digitalWrite(IN2, HIGH);
  analogWrite(ENA, 200);
  delay(2000);

  // Arrêt
  analogWrite(ENA, 0);
  delay(1000);
}

Servomoteur : contrôler une position

Un servomoteur classique permet de commander une position angulaire, souvent dans une plage proche de 0° à 180° selon le modèle. Il possède généralement trois fils : alimentation, GND et signal. La bibliothèque Servo.h facilite son pilotage.

#include <Servo.h>

Servo monServo;

void setup() {
  monServo.attach(9);
}

void loop() {
  monServo.write(0);
  delay(1000);

  monServo.write(90);
  delay(1000);

  monServo.write(180);
  delay(1000);
}

La broche 9 est utilisée ici comme signal de commande. Le servomoteur peut nécessiter une alimentation externe adaptée à son courant. Si une alimentation externe est utilisée, relie les masses conformément au schéma du montage. Ne suppose pas que la sortie 5 V de l'Arduino peut alimenter n'importe quel servo.

Moteur pas à pas : principe

Un moteur pas à pas tourne par petits déplacements appelés pas. Un driver spécialisé reçoit les signaux de commande et alimente les bobines du moteur. Des modules comme A4988 ou DRV8825 sont courants, mais ils exigent un réglage de courant, un câblage et une alimentation conformes à leur documentation.

La bibliothèque Stepper peut commander certains moteurs pas à pas avec un câblage et un étage de puissance adaptés. Ne connecte pas directement les bobines d'un moteur pas à pas aux broches Arduino.

#include <Stepper.h>

// Exemple pédagogique : nombre de pas à adapter au moteur et au montage.
const int pasParTour = 200;

Stepper moteur(pasParTour, 8, 10, 9, 11);

void setup() {
  moteur.setSpeed(30); // Tours par minute
}

void loop() {
  moteur.step(pasParTour);   // Un tour dans un sens
  delay(500);

  moteur.step(-pasParTour);  // Un tour dans l'autre sens
  delay(500);
}
Sécurité des moteurs : ne branche jamais un moteur directement sur une broche Arduino. Utilise un driver adapté au courant de démarrage et au courant nominal du moteur, une alimentation moteur appropriée et les protections prévues par le fabricant. Une masse commune est généralement nécessaire pour les signaux de commande. Les moteurs peuvent provoquer des perturbations électriques : respecte le schéma du driver et ses recommandations de protection.

6. Communication avec d’autres appareils

UART / SÉRIE

Serial

Communication point à point via TX/RX. Sert au moniteur série, aux modules GPS ou Bluetooth série. Attention aux niveaux logiques du module.

I²C

SDA / SCL

Bus à deux lignes pour plusieurs composants adressables, comme certains écrans et capteurs. Sur Uno R3 : SDA=A4 et SCL=A5.

SPI

MOSI / MISO / SCK

Bus synchrone rapide utilisé par des cartes SD, modules radio et lecteurs RFID. Une ligne CS/SS sélectionne généralement le périphérique.

Lire les messages dans le moniteur série

void setup() {
  Serial.begin(9600);
  Serial.println("Arduino pret !");
}

void loop() {
  int valeur = analogRead(A0);
  Serial.print("Mesure : ");
  Serial.println(valeur);
  delay(500);
}

Ouvre le moniteur série et sélectionne le même débit (ici 9600 bauds). Pour recevoir des données, on peut utiliser Serial.available() puis Serial.read().

7. Alimentation, sécurité et dépannage

Règles de sécurité

  • Travaille uniquement en basse tension pour les exercices de débutant.
  • Débranche avant de modifier les fils.
  • Ne dépasse jamais les limites de tension et de courant de la carte et des composants.
  • N’alimente pas un moteur directement depuis une broche Arduino.
  • Vérifie la polarité des LED, condensateurs et alimentations.
  • N’interviens jamais sur le secteur 230 V sans formation et matériel adaptés.

Erreurs fréquentes

  • Port COM incorrect ou carte non reconnue.
  • Câble USB réservé à la charge, sans données.
  • Type de carte incorrect dans l’IDE.
  • Oubli de pinMode().
  • Absence de GND commun entre modules.
  • Broche différente entre le code et le câblage.
  • Erreur de syntaxe : point-virgule ou accolade manquante.

Une méthode efficace pour réussir un projet

  1. Décris précisément ce que le système doit faire.
  2. Liste les entrées, les sorties et les contraintes électriques.
  3. Consulte la documentation de chaque composant.
  4. Dessine le câblage avant de brancher.
  5. Teste chaque composant séparément.
  6. Écris le programme par petites étapes.
  7. Affiche les mesures dans le moniteur série.
  8. Teste les cas normaux et les cas limites.
  9. Documente les broches, les connexions et le fonctionnement.

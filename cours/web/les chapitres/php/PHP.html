CHAPITRE 01 · INTRODUCTION

Comprendre PHP

Définition : PHP (Hypertext Preprocessor) est un langage de programmation exécuté côté serveur. Il permet de créer des pages web dynamiques, de traiter les données des utilisateurs et de communiquer avec une base de données.

1.1. Pourquoi utiliser PHP ?

HTML permet de structurer une page web, CSS permet de la mettre en forme et JavaScript permet d'ajouter des interactions côté navigateur. Mais pour traiter les données sur un serveur, PHP est particulièrement utile.

HTML / CSS / JavaScript

Exécutés principalement dans le navigateur de l'utilisateur.

PHP

Exécuté sur le serveur avant l'envoi du résultat au navigateur.

1.2. Comment fonctionne PHP ?

  1. L'utilisateur demande une page PHP.
  2. Le serveur reçoit la demande.
  3. Le serveur exécute le code PHP.
  4. PHP peut consulter ou modifier une base de données.
  5. Le serveur renvoie le résultat HTML au navigateur.

1.3. Premier programme PHP

premier.php 
<?php
echo "Bonjour tout le monde !";
?>

Explication de chaque instruction

  • <?php : indique le début du code PHP.
  • echo : affiche un contenu dans le résultat HTML.
  • "Bonjour tout le monde !" : texte à afficher.
  • ; termine l'instruction PHP.
  • ?> : marque la fin du bloc PHP dans ce fichier.

RÉSULTAT DANS LE NAVIGATEUR

Bonjour tout le monde !

Dans un fichier PHP contenant uniquement du code PHP, il est recommandé de ne pas écrire la balise de fermeture ?>. Cela évite certains problèmes liés aux espaces ou aux retours à la ligne envoyés accidentellement.

1.4. PHP statique et PHP dynamique

exemple.php 
<?php
$nom = "Mohamed";

echo "Bienvenue " . $nom;
?>

PHP construit ici le message à partir d'une variable. Si la valeur de $nom change, le résultat change également.

RÉSULTAT

Bienvenue Mohamed

CHAPITRE 04 · VARIABLES

Les variables et les constantes

4.1. Qu'est-ce qu'une variable ?

Une variable est un espace nommé qui permet de stocker une valeur utilisée ou modifiée pendant l'exécution du programme.
variables.php
<?php

$nom = "Mohamed";
$age = 20;
$moyenne = 15.5;
$inscrit = true;

echo $nom;
echo $age;

?>

Explication

  • $nom : nom de la variable.
  • = : opérateur d'affectation.
  • "Mohamed" : valeur stockée.
  • ; : fin de l'instruction.

4.2. Les règles de nommage

  • Une variable commence obligatoirement par $.
  • Le nom commence par une lettre ou un underscore.
  • Il peut contenir des lettres, des chiffres et des underscores.
  • Les noms sont sensibles à la casse.
noms.php
<?php

$nom = "Ali";
$Nom = "Ahmed";
$age_etudiant = 20;

echo $nom;
echo $Nom;

?>

Résultat : Ali et Ahmed sont deux valeurs différentes car $nom et $Nom sont deux variables distinctes.

4.3. Modifier une variable

modification.php
<?php

$prix = 100;

$prix = 150;

echo $prix;

?>

RÉSULTAT

4.4. Les constantes

Une constante est une valeur nommée qui ne change pas pendant l'exécution normale du programme.

constantes.php
<?php

define("SITE_NAME", "StudyNet");

const TVA = 0.19;

echo SITE_NAME;
echo TVA;

?>

define() permet de définir une constante à partir de son nom et de sa valeur. Le mot-clé const permet également de déclarer une constante.

CHAPITRE 07 · CONDITIONS

Les structures conditionnelles

Une condition permet d'exécuter différentes instructions selon qu'une expression est vraie ou fausse.

7.1. La condition if

if.php
<?php

$age = 20;

if ($age >= 18) {
    echo "Majeur";
}

?>

PHP vérifie si l'âge est supérieur ou égal à 18. Si la condition est vraie, le message est affiché.

7.2. if / else

if_else.php
<?php

$note = 12;

if ($note >= 10) {
    echo "Admis";
} else {
    echo "Non admis";
}

?>

Si la note est supérieure ou égale à 10, PHP affiche « Admis ». Sinon, il affiche « Non admis ».

7.3. if / elseif / else

elseif.php
<?php

$note = 15;

if ($note >= 16) {
    echo "Très bien";
} elseif ($note >= 14) {
    echo "Bien";
} elseif ($note >= 10) {
    echo "Passable";
} else {
    echo "Insuffisant";
}

?>

Les conditions sont testées dans l'ordre. Dès qu'une condition est vraie, son bloc est exécuté et les autres branches ne sont pas examinées.

7.4. switch

switch.php
<?php

$jour = 2;

switch ($jour) {
    case 1:
        echo "Lundi";
        break;

    case 2:
        echo "Mardi";
        break;

    case 3:
        echo "Mercredi";
        break;

    default:
        echo "Jour inconnu";
}

?>

switch compare une expression à plusieurs valeurs. break permet de sortir du switch. default est exécuté si aucun cas ne correspond.

7.5. L'opérateur ternaire

ternaire.php
<?php

$age = 20;

$message = ($age >= 18)
    ? "Majeur"
    : "Mineur";

echo $message;

?>

Le ternaire permet d'écrire une condition simple sous une forme courte.

CHAPITRE 08 · BOUCLES

Les boucles

Une boucle permet de répéter plusieurs fois un ensemble d'instructions sans écrire le même code manuellement.

8.1. La boucle for

for.php
<?php

for ($i = 1; $i <= 5; $i++) {
    echo $i . "<br>";
}

?>

Les trois éléments de for

  • $i = 1 : initialisation du compteur.
  • $i <= 5 : condition de continuation.
  • $i++ : augmentation du compteur après chaque tour.

8.2. La boucle while

while.php
<?php

$i = 1;

while ($i <= 5) {
    echo $i . "<br>";
    $i++;
}

?>

La boucle while continue tant que sa condition est vraie. Le compteur doit être modifié pour éviter une boucle infinie.

8.3. La boucle do while

do_while.php
<?php

$i = 1;

do {
    echo $i;
    $i++;
} while ($i <= 5);

?>

Contrairement à while, do while exécute le bloc au moins une fois avant de vérifier la condition.

8.4. break et continue

break_continue.php
<?php

for ($i = 1; $i <= 10; $i++) {

    if ($i == 5) {
        continue;
    }

    if ($i == 8) {
        break;
    }

    echo $i . "<br>";
}

?>
  • continue saute le reste du tour actuel.
  • break arrête complètement la boucle.

8.5. Boucles imbriquées

imbriquees.php
<?php

for ($i = 1; $i <= 3; $i++) {

    for ($j = 1; $j <= 3; $j++) {
        echo "$i - $j <br>";
    }

}

?>

Une boucle imbriquée est une boucle placée à l'intérieur d'une autre. Elle est utile pour parcourir des tableaux multidimensionnels et construire des tableaux HTML.

CHAPITRE 09 · TABLEAUX

Les tableaux PHP

Un tableau est une structure qui permet de stocker plusieurs valeurs dans une seule variable.

9.1. Tableau indexé

tableau.php
<?php

$fruits = ["Pomme", "Banane", "Orange"];

echo $fruits[0];
echo $fruits[1];
echo $fruits[2];

?>

Les indices commencent par zéro. Ainsi, $fruits[0] contient Pomme.

9.2. Ajouter et modifier une valeur

modifier_tableau.php
<?php

$fruits = ["Pomme", "Banane"];

$fruits[] = "Orange";

$fruits[0] = "Fraise";

print_r($fruits);

?>
  • [] ajoute une valeur à la fin.
  • $fruits[0] = ... modifie une valeur existante.
  • print_r() affiche la structure du tableau.

9.3. Tableau associatif

Un tableau associatif utilise des clés nommées au lieu d'indices numériques.

associatif.php
<?php

$etudiant = [
    "nom" => "Ali",
    "prenom" => "Mohamed",
    "age" => 20,
    "moyenne" => 15.5
];

echo $etudiant["nom"];
echo $etudiant["moyenne"];

?>

=> associe une clé à une valeur. Pour accéder à une valeur, on utilise sa clé entre crochets.

9.4. Parcourir un tableau avec foreach

foreach.php
<?php

$fruits = ["Pomme", "Banane", "Orange"];

foreach ($fruits as $fruit) {
    echo $fruit . "<br>";
}

?>

À chaque tour, la variable $fruit reçoit une valeur du tableau.

9.5. Parcourir un tableau associatif

foreach_associatif.php
<?php

$etudiant = [
    "nom" => "Ali",
    "age" => 20,
    "note" => 15
];

foreach ($etudiant as $cle => $valeur) {
    echo $cle . " : " . $valeur . "<br>";
}

?>

La variable $cle reçoit la clé et $valeur reçoit la valeur correspondante.

CHAPITRE 10 · FONCTIONS

Les fonctions PHP

Une fonction est un bloc de code réutilisable qui effectue une tâche précise. Elle permet d'éviter les répétitions et d'organiser le programme.

10.1. Déclarer une fonction

fonction.php
<?php

function bonjour() {
    echo "Bonjour tout le monde";
}

bonjour();

?>
  • function : mot-clé de déclaration.
  • bonjour : nom de la fonction.
  • () : emplacement des paramètres.
  • { } : bloc d'instructions.
  • bonjour() : appel de la fonction.

10.2. Les paramètres

parametres.php
<?php

function saluer($nom) {
    echo "Bonjour " . $nom;
}

saluer("Mohamed");

?>

Le paramètre $nom reçoit la valeur transmise lors de l'appel de la fonction.

10.3. return

return.php
<?php

function addition($a, $b) {
    return $a + $b;
}

$resultat = addition(10, 5);

echo $resultat;

?>

return renvoie un résultat à l'endroit où la fonction a été appelée et termine son exécution.

10.4. Les paramètres par défaut

defaut.php
<?php

function saluer($nom = "visiteur") {
    echo "Bonjour " . $nom;
}

saluer();
saluer("Ali");

?>

10.5. Les types des paramètres et du retour

types_fonction.php
<?php

function multiplier(int $a, int $b): int {
    return $a * $b;
}

echo multiplier(4, 5);

?>

Ici, les paramètres sont déclarés comme des entiers et la fonction annonce un retour de type entier.

10.6. Portée des variables

portee.php
<?php

$nom = "Mohamed";

function afficher() {
    $message = "Bonjour";
    echo $message;
}

afficher();

?>

Une variable définie dans une fonction est locale à cette fonction. Une variable extérieure n'est pas automatiquement disponible à l'intérieur de la fonction.

CHAPITRE 12 · FORMULAIRES HTML

Les formulaires HTML et PHP

Notion fondamentale : Un formulaire HTML permet à l'utilisateur de saisir des informations. PHP récupère ensuite les données envoyées pour les vérifier, les traiter et éventuellement les enregistrer dans une base de données.

12.1. Pourquoi les formulaires sont-ils importants ?

Dans une application réelle, les utilisateurs doivent pouvoir envoyer des informations au serveur. Par exemple :

  • Créer un compte.
  • Se connecter.
  • Ajouter un étudiant.
  • Modifier un produit.
  • Envoyer un message.
  • Effectuer une recherche.

12.2. Structure d'un formulaire HTML

formulaire.html
<form action="traitement.php" method="POST">

    <label>Nom :</label>
    <input type="text" name="nom">

    <label>Email :</label>
    <input type="email" name="email">

    <button type="submit">
        Envoyer
    </button>

</form>

Explication de chaque élément

ÉlémentRôle
formDélimite le formulaire.
actionDétermine le fichier qui reçoit les données.
methodDétermine la méthode d'envoi.
labelDécrit un champ.
inputPermet de saisir une information.
nameDéfinit le nom utilisé pour récupérer la donnée en PHP.
submitEnvoie le formulaire.
Le point le plus important : l'attribut name. Sans cet attribut, un champ classique n'est pas envoyé comme donnée de formulaire. PHP utilise ce nom pour retrouver sa valeur.

12.3. Comprendre action et method

formulaire.html
<form action="traitement.php" method="POST">

    <input type="text" name="nom">

    <button type="submit">Envoyer</button>

</form>
  • action="traitement.php" : le navigateur envoie les données vers ce fichier.
  • method="POST" : les données sont envoyées dans le corps de la requête HTTP.
  • name="nom" : PHP pourra récupérer la valeur avec $_POST['nom'].

La validation consiste à vérifier si une donnée respecte les règles attendues avant de l'utiliser ou de l'enregistrer.

14.1. Pourquoi valider ?

Un utilisateur peut envoyer une donnée vide, un email incorrect, un âge négatif ou une valeur inattendue. Il faut donc vérifier les informations côté serveur.

15.11. Relations entre les tables

Une base de données relationnelle permet de relier différentes tables. Par exemple, un étudiant peut être inscrit dans plusieurs cours.

CREATE TABLE cours (

    id INT AUTO_INCREMENT PRIMARY KEY,

    titre VARCHAR(150) NOT NULL

);

CREATE TABLE inscriptions (

    id INT AUTO_INCREMENT PRIMARY KEY,

    etudiant_id INT NOT NULL,

    cours_id INT NOT NULL,

    FOREIGN KEY (etudiant_id)
        REFERENCES etudiants(id),

        REFERENCES cours(id)

La table inscriptions relie les étudiants aux cours. Les clés étrangères garantissent que les références pointent vers des enregistrements existants, selon les contraintes définies.

16.8. Les requêtes préparées : prepare et bind_param

Indispensable pour la sécurité
Une requête préparée sépare la structure SQL des valeurs fournies par l'utilisateur. Elle permet notamment de prévenir les injections SQL.

<?php

require_once "connexion.php";

$stmt = $conn->prepare($sql);

$stmt->bind_param("s", $nom);

$stmt->execute();

$resultat = $stmt->get_result();

while ($etudiant = $resultat->fetch_assoc()) {

    echo htmlspecialchars($etudiant["nom"]);

}

$stmt->close();

?>

Comprendre chaque instruction

  • prepare() : prépare la requête SQL.
  • ? : représente un paramètre à fournir.
  • bind_param() : associe une variable au paramètre.
  • "s" : indique que la variable est une chaîne.
  • execute() : exécute la requête.
  • get_result() : récupère un résultat exploitable lorsque le pilote mysqlnd est disponible.
  • close() : libère la requête préparée.

Un cookie est une petite information enregistrée dans le navigateur. Il peut être utilisé pour mémoriser certaines préférences.

CHAPITRE 19 · SÉCURITÉ

Sécuriser une application PHP

La sécurité consiste à protéger les informations, les comptes et les opérations de l'application contre les utilisations malveillantes ou non autorisées.

19.1. Prévenir les injections SQL

Une injection SQL peut se produire lorsqu'une donnée utilisateur est directement intégrée dans une requête SQL sans protection.

MAUVAISE PRATIQUE
$nom = $_POST["nom"];

$sql = "SELECT * FROM etudiants
        WHERE nom = '$nom'";

$resultat = $conn->query($sql);
Ne construis pas une requête SQL en concaténant directement les données reçues d'un formulaire.
BONNE PRATIQUE
$nom = $_POST["nom"] ?? "";

$sql = "SELECT * FROM etudiants WHERE nom = ?";

$stmt = $conn->prepare($sql);

$stmt->bind_param("s", $nom);

$stmt->execute();

Une attaque CSRF tente de faire exécuter une action à un utilisateur authentifié sans son intention. Un jeton CSRF permet de vérifier que la requête provient d'un formulaire autorisé de l'application.

19.6. Autres règles importantes

  • Utiliser HTTPS.
  • Valider les données côté serveur.
  • Utiliser les requêtes préparées MySQLi.
  • Ne jamais afficher les erreurs techniques aux utilisateurs en production.
  • Limiter les permissions du compte SQL.
  • Protéger les pages réservées aux utilisateurs connectés.
  • Contrôler les fichiers téléversés.
  • Utiliser des jetons CSRF pour les opérations sensibles.
  • Éviter de stocker des secrets dans des fichiers accessibles publiquement.

HTML — HyperText Markup Language

1. Introduction à HTML

HTML est un langage de balisage qui permet de structurer le contenu d'une page web.

Une balise HTML est généralement composée d'une balise ouvrante, d'un contenu et d'une balise fermante. 

<p>Bonjour le monde</p>

Certaines balises sont vides, comme <br>, <hr>, <img> et <input>.

2. Structure de base d'une page HTML

Structure HTML complète

Les éléments indispensables

<!DOCTYPE html> indique au navigateur que le document utilise HTML5.

  • <html> : racine du document.
  • <head> : métadonnées.
  • <title> : titre de l'onglet.
  • <meta> : informations du document.
  • <body> : contenu visible.

CSS — Cascading Style Sheets

1. Introduction à CSS

CSS permet de définir l'apparence des éléments HTML : couleurs, tailles, espacements, positionnement et mise en page. 

p {
    color: red;
    font-size: 20px;
}
  • p : sélecteur.
  • color : propriété.
  • red : valeur.
  • ; : termine une déclaration.

Projet 01 — Portfolio personnel

Créer un site personnel pour présenter un étudiant, ses compétences et ses projets.

Pages à réaliser :
  • Page d'accueil.
  • Page de présentation.
  • Page des projets.
  • Page de contact.
Travail demandé :
  • Utiliser header, nav, main, section et footer.
  • Créer une navigation entre les sections.
  • Utiliser des images et des liens.
  • Créer une mise en page CSS responsive.

Corrigé — Portfolio personnel

La page contient une structure sémantique, un menu, une présentation et un pied de page. 

<header>
  <h1>Mon Portfolio</h1>
  <nav>
    <a href="#accueil">Accueil</a>
    <a href="#projets">Projets</a>
    <a href="#contact">Contact</a>
  </nav>
</header>

<main>
  <section id="accueil">
    <h2>Bienvenue</h2>
    <p>Je suis étudiant en STI.</p>
  </section>

  <section id="projets">
    <h2>Mes projets</h2>
    <article>
      <h3>Projet HTML</h3>
      <p>Création d'une page web.</p>
    </article>
  </section>

  <section id="contact">
    <h2>Contact</h2>
    <p>contact@example.com</p>
  </section>
</main>

<footer>
  <p>© 2026 Mon Portfolio</p>
</footer>

CSS :

* {
  box-sizing: border-box;
}

  padding: 40px 20px;

  background: white;

Explication : header contient le titre et la navigation. main contient les sections principales. footer contient les informations de fin. CSS gère la mise en page, les couleurs et les espacements.

Projet 04 — Boutique en ligne

Corrigé — Boutique

<header>

<main>

    <div class="produits">

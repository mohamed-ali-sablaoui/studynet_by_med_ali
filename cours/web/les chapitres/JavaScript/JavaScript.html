Cours complet JavaScript

Des bases jusqu'au développement d'applications interactives.

Objectif pédagogique : à la fin de ce cours, vous devez pouvoir analyser un problème, construire son algorithme, écrire le code JavaScript nécessaire, manipuler une page HTML, vérifier les données saisies et réaliser un projet complet.

1. Introduction à JavaScript

JavaScript est un langage de programmation principalement utilisé pour rendre les pages Web interactives et dynamiques. Il travaille généralement avec HTML et CSS.

HTML

Structure et contenu d'une page.

Structure

CSS

Apparence, couleurs, tailles et disposition.

Design

JavaScript

Comportement, logique et interactions.

Interaction

Exemple : les trois technologies

HTML crée le bouton, CSS lui donne son apparence et JavaScript définit son comportement.

HTML + CSS + JS
<button id="monBouton">Cliquez ici</button>

<style>
button {
    background: orange;
    color: white;
    padding: 12px;
    border: none;
}
</style>

<script>
document.getElementById("monBouton")
    .addEventListener("click", function() {
        alert("Bonjour !");
    });

Fonction de chaque partie :
  • HTML : crée un bouton.
  • CSS : change sa couleur et son apparence.
  • JavaScript : affiche un message lorsque l'utilisateur clique.

2. Comment fonctionne JavaScript ?

Le navigateur contient un moteur JavaScript qui interprète et exécute le code. JavaScript peut accéder à la structure HTML à travers le DOM, réagir aux actions de l'utilisateur et communiquer avec des serveurs.

Les différentes manières d'intégrer JavaScript

Méthode 1 : JavaScript interne

HTML
<script>
    console.log("Bonjour JavaScript");
</script>

Fonction : écrire directement le code JavaScript dans la page HTML.

Méthode 2 : JavaScript externe

HTML
<script src="script.js" defer></script>

Fonction : charger un fichier JavaScript séparé. L'attribut defer permet de l'exécuter après l'analyse du HTML. C'est une méthode recommandée pour organiser les projets.

Méthode 3 : Console du navigateur

Ouvrez les outils de développement avec F12, puis choisissez Console. Vous pouvez y tester des instructions JavaScript.

JavaScript
console.log("Test JavaScript");
alert("Bonjour");
2 + 3

Fonction : tester rapidement une instruction sans modifier un fichier.

4. Variables et constantes

Une variable est un espace logique qui permet de conserver une valeur pendant l'exécution du programme.

let

Déclare une variable dont la valeur peut changer.

const

Déclare une variable dont la réaffectation est interdite.

var

Ancienne déclaration, avec une portée différente de let et const.

JavaScript
let age = 20;
age = 21;

const pays = "Tunisie";

// pays = "France"; // Erreur : réaffectation interdite

var ancienneVariable = "Exemple";

Fonction de let : conserver une valeur qui peut évoluer. Exemple : le score d'un joueur.

Fonction de const : conserver une référence qui ne doit pas être réaffectée. Exemple : une configuration.

Fonction de var : déclarer une variable avec une portée de fonction ou globale. Elle est généralement évitée dans le nouveau code.

Règle : privilégiez const par défaut. Utilisez let lorsqu'une réaffectation est nécessaire. Un objet déclaré avec const peut néanmoins voir ses propriétés modifiées.

Les règles de nommage

  • Un nom ne commence pas par un chiffre.
  • Les espaces sont interdits.
  • Les mots réservés ne doivent pas être utilisés.
  • Privilégiez des noms compréhensibles.
  • La convention camelCase est courante : nombreEtudiants.

7. Les conditions

Une condition permet d'exécuter différentes instructions selon qu'une expression est vraie ou fausse.

if

JavaScript
let moyenne = 15;

if (moyenne >= 10) {
    console.log("Admis");
}

Fonction : vérifier si la moyenne est supérieure ou égale à 10.

if / else

JavaScript
let age = 16;

if (age >= 18) {
    console.log("Majeur");
} else {
    console.log("Mineur");
}

Fonction : choisir entre deux possibilités.

if / else if / else

JavaScript
let moyenne = 15;

if (moyenne >= 16) {
    console.log("Très bien");
} else if (moyenne >= 14) {
    console.log("Bien");
} else if (moyenne >= 10) {
    console.log("Passable");
} else {
    console.log("Non admis");
}

Fonction : sélectionner une catégorie parmi plusieurs intervalles.

switch

JavaScript
let jour = 2;

switch (jour) {
    case 1:
        console.log("Lundi");
        break;

    case 2:
        console.log("Mardi");
        break;

    case 3:
        console.log("Mercredi");
        break;

    default:
        console.log("Jour inconnu");
}

Fonction : comparer une expression à plusieurs valeurs possibles. break arrête le switch après le cas correspondant.

8. Les boucles

Une boucle permet de répéter des instructions plusieurs fois sans devoir les écrire à nouveau.

Boucle for

JavaScript
for (let i = 1; i <= 5; i++) {
    console.log(i);
}

Fonction : répéter cinq fois. Initialisation : i = 1. Condition : i <= 5. Mise à jour : i++.

Boucle while

JavaScript
let i = 1;

while (i <= 5) {
    console.log(i);
    i++;
}

Fonction : répéter tant que la condition reste vraie.

Boucle do...while

JavaScript
let i = 1;

do {
    console.log(i);
    i++;
} while (i <= 5);

Fonction : exécuter le bloc au moins une fois avant de tester la condition.

for...of

JavaScript
let fruits = ["Pomme", "Banane", "Orange"];

for (let fruit of fruits) {
    console.log(fruit);
}

Fonction : parcourir directement les valeurs d'un tableau.

for...in

JavaScript
let personne = {
    nom: "Ali",
    age: 20
};

for (let propriete in personne) {
    console.log(propriete, personne[propriete]);
}

Fonction : parcourir les clés énumérables d'un objet.

break et continue

JavaScript
for (let i = 1; i <= 10; i++) {

    if (i === 3) {
        continue;
    }

    if (i === 7) {
        break;
    }

    console.log(i);
}

continue passe à l'itération suivante. break arrête complètement la boucle.

9. Les fonctions

Une fonction est un bloc de code réutilisable qui réalise une tâche précise. Elle peut recevoir des paramètres et retourner un résultat.

Déclaration d'une fonction

JavaScript
function addition(a, b) {
    return a + b;
}

let resultat = addition(10, 5);

console.log(resultat); // 15

function crée la fonction. a et b sont les paramètres. return renvoie le résultat. addition(10, 5) appelle la fonction.

Fonction sans paramètre

JavaScript
function saluer() {
    console.log("Bonjour !");
}

saluer();

Fonction : exécuter une tâche qui ne nécessite aucune donnée extérieure.

Paramètres par défaut

JavaScript
function saluer(nom = "Utilisateur") {
    return "Bonjour " + nom;
}

console.log(saluer());
console.log(saluer("Ali"));

Fonction : utiliser une valeur de remplacement si aucun argument n'est fourni.

Fonction anonyme

JavaScript
const calculer = function(a, b) {
    return a * b;
};

console.log(calculer(4, 5));

Fonction : stocker une fonction dans une variable.

Fonction fléchée (Arrow Function)

JavaScript
const addition = (a, b) => {
    return a + b;
};

const carre = x => x * x;

console.log(addition(3, 4));
console.log(carre(5));

Fonction : écrire des fonctions avec une syntaxe plus concise.

Portée des variables (Scope)

JavaScript
let global = "Accessible dans le bloc externe";

function exemple() {
    let local = "Accessible dans cette fonction";
    console.log(global);
    console.log(local);
}

exemple();

La portée détermine où une variable est accessible. let et const ont une portée de bloc.

Closure (fermeture)

JavaScript
function creerCompteur() {
    let compteur = 0;

    return function() {
        compteur++;
        return compteur;
    };
}

const compteur = creerCompteur();

console.log(compteur()); // 1
console.log(compteur()); // 2
console.log(compteur()); // 3

Une closure permet à une fonction interne de conserver l'accès aux variables de son environnement même après l'exécution de la fonction externe.

10. Les tableaux (Arrays)

Un tableau permet de stocker plusieurs valeurs dans une seule variable. Chaque élément possède un indice qui commence à zéro.

JavaScript
let notes = [12, 15, 18, 10];

console.log(notes[0]); // 12
console.log(notes[2]); // 18
console.log(notes.length); // 4

Les principales méthodes des tableaux

MéthodeFonction

includes()Vérifier si une valeur existe
indexOf()Rechercher l'indice d'une valeur
slice()Extraire une portion sans modifier l'original
splice()Ajouter, remplacer ou supprimer des éléments

let nombres = [5, 2, 10, 1];

nombres.sort((a, b) => a - b);

map()

JavaScript
let nombres = [1, 2, 3, 4];

let doubles = nombres.map(function(n) {
    return n * 2;
});

console.log(doubles); // [2, 4, 6, 8]

Fonction : créer un nouveau tableau en transformant chaque élément.

filter()

JavaScript
let notes = [8, 12, 16, 9, 18];

let admis = notes.filter(note => note >= 10);

console.log(admis); // [12, 16, 18]

Fonction : créer un tableau contenant uniquement les éléments qui satisfont une condition.

reduce()

JavaScript
let nombres = [10, 20, 30];

let somme = nombres.reduce((total, n) => {
    return total + n;
}, 0);

console.log(somme); // 60

Fonction : accumuler les valeurs du tableau pour produire un seul résultat.

find() et findIndex()

JavaScript
let notes = [8, 12, 16, 18];

let resultat = notes.find(n => n > 15);
let indice = notes.findIndex(n => n > 15);

console.log(resultat); // 16
console.log(indice);   // 2

Fonction : trouver le premier élément ou l'indice du premier élément correspondant.

some() et every()

JavaScript
let notes = [12, 14, 16];

console.log(notes.some(n => n < 10)); // false
console.log(notes.every(n => n >= 10)); // true

some() vérifie si au moins un élément satisfait une condition. every() vérifie si tous les éléments la satisfont.

11. Les objets

Un objet regroupe plusieurs informations sous forme de propriétés et de valeurs. Il peut aussi contenir des fonctions appelées méthodes.

JavaScript
let etudiant = {
    nom: "Mohamed",
    age: 20,
    moyenne: 15,

    afficher: function() {
        return this.nom + " - " + this.moyenne;

};

console.log(etudiant.nom);
console.log(etudiant.age);
console.log(etudiant.afficher());

etudiant.nom accède à une propriété. this fait ici référence à l'objet qui appelle la méthode.

Modifier un objet

JavaScript
let personne = {
    nom: "Ali",
    age: 20
};

personne.age = 21;
personne.ville = "Mahdia";

delete personne.age;

console.log(personne);

Fonction : modifier, ajouter ou supprimer les propriétés d'un objet.

Destructuring

JavaScript
const personne = {
    nom: "Ali",
    age: 20
};

const { nom, age } = personne;

console.log(nom, age);

const nombres = [10, 20];

const [a, b] = nombres;

console.log(a, b);

Fonction : extraire facilement des valeurs d'un objet ou d'un tableau.

Spread operator

JavaScript
const a = [1, 2, 3];
const b = [...a, 4, 5];

console.log(b);

const personne = {nom: "Ali", age: 20};
const copie = {...personne, ville: "Mahdia"};

console.log(copie);

Fonction : étendre ou copier les éléments d'un tableau ou les propriétés d'un objet.

Classes et objets

JavaScript

    constructor(nom, moyenne) {
        this.nom = nom;
        this.moyenne = moyenne;
    }

Héritage

12. Les chaînes de caractères

Une chaîne de caractères permet de représenter du texte.

13. Le DOM (Document Object Model)

Le DOM est une représentation structurée de la page HTML sous forme d'objets. JavaScript peut utiliser le DOM pour lire et modifier les éléments HTML.

Notion essentielle : le DOM établit le lien entre JavaScript et HTML. Il permet de changer le contenu, les attributs, les classes, les styles et les éléments d'une page.

Sélectionner les éléments

MéthodeFonction
getElementById()Sélectionner un élément par son ID
getElementsByClassName()Sélectionner par classe
getElementsByTagName()Sélectionner par balise
querySelector()Sélectionner le premier élément correspondant
querySelectorAll()Sélectionner tous les éléments correspondants
HTML
<h1 id="titre">Ancien titre</h1>
<p class="description">Texte</p>
JavaScript
const titre = document.getElementById("titre");
const description = document.querySelector(".description");

console.log(titre);
console.log(description);

Modifier le contenu

JavaScript
const titre = document.getElementById("titre");

titre.textContent = "Nouveau titre";

textContent modifie le texte d'un élément sans interpréter les balises HTML.

innerHTML

JavaScript
const zone = document.getElementById("zone");

zone.innerHTML = "<strong>Texte important</strong>";

Fonction : lire ou remplacer le contenu HTML d'un élément. Attention : ne placez jamais directement du contenu utilisateur non fiable dans innerHTML.

Modifier les attributs

JavaScript
const image = document.querySelector("img");

image.setAttribute("alt", "Photo descriptive");
image.setAttribute("title", "Mon image");

console.log(image.getAttribute("alt"));

image.removeAttribute("title");

setAttribute() ajoute ou modifie un attribut. getAttribute() lit un attribut. removeAttribute() le supprime.

Créer et supprimer des éléments

JavaScript
const liste = document.getElementById("liste");

const element = document.createElement("li");

element.textContent = "Nouvel élément";

liste.appendChild(element);

// Supprimer l'élément
element.remove();

createElement() crée un élément HTML. appendChild() l'ajoute à un parent. remove() supprime l'élément.

14. Les événements JavaScript

Un événement est une action ou un changement détecté par le navigateur : clic, saisie, déplacement de souris, validation d'un formulaire, etc.

ÉvénementFonction
clickDétecter un clic
dblclickDétecter un double clic
inputDétecter une modification immédiate d'une saisie
changeDétecter un changement validé
submitDétecter la soumission d'un formulaire
focusDétecter le focus
blurDétecter la perte de focus
keydownDétecter l'appui sur une touche
keyupDétecter le relâchement d'une touche
mouseoverDétecter le passage de la souris
loadDétecter le chargement

addEventListener()

HTML
<button id="btn">Cliquez</button>
<p id="message"></p>
JavaScript
const bouton = document.getElementById("btn");
const message = document.getElementById("message");

bouton.addEventListener("click", function() {
    message.textContent = "Vous avez cliqué !";
});

Fonction : associer une fonction à un événement sans mélanger le comportement et le HTML.

L'objet event

JavaScript
document.addEventListener("click", function(event) {
    console.log(event.target);
});

event représente les informations relatives à l'événement. event.target désigne l'élément qui a déclenché l'événement.

preventDefault()

JavaScript
document.querySelector("form").addEventListener("submit", function(event) {
    event.preventDefault();

    console.log("Soumission contrôlée par JavaScript");
});

Fonction : empêcher le comportement par défaut d'une action, par exemple l'envoi automatique d'un formulaire.

Propagation des événements

Lorsqu'un événement se produit sur un élément imbriqué, il peut se propager vers ses éléments parents. Ce mécanisme est appelé propagation.

  • Capturing : propagation de l'extérieur vers l'intérieur.
  • Target : élément qui reçoit l'événement.
  • Bubbling : propagation de l'intérieur vers l'extérieur.
JavaScript
parent.addEventListener("click", function() {
    console.log("Parent");
});

enfant.addEventListener("click", function(event) {
    console.log("Enfant");
    event.stopPropagation();
});

stopPropagation() arrête la propagation de l'événement.

Exemple complet : validation d'un formulaire

HTML
<form id="inscription">

    <input type="text" id="nom" placeholder="Nom">

    <input type="email" id="email" placeholder="Email">

    <input type="password" id="password"
           placeholder="Mot de passe">

    <input type="password" id="confirmation"
           placeholder="Confirmer le mot de passe">

    <button type="submit">S'inscrire</button>

    <p id="erreur"></p>
    <p id="succes"></p>

</form>
JavaScript
const formulaire = document.getElementById("inscription");

formulaire.addEventListener("submit", function(event) {

    event.preventDefault();

    const nom = document.getElementById("nom").value.trim();
    const email = document.getElementById("email");
    const password = document.getElementById("password").value;
    const confirmation = document.getElementById("confirmation").value;

    const erreur = document.getElementById("erreur");
    const succes = document.getElementById("succes");

    erreur.textContent = "";
    succes.textContent = "";

    if (nom.length < 3) {
        erreur.textContent = "Le nom doit contenir au moins 3 caractères.";
        return;
    }

    if (!email.validity.valid || email.value.trim() === "") {
        erreur.textContent = "Adresse email invalide.";
        return;
    }

    if (password.length < 8) {
        erreur.textContent = "Le mot de passe doit contenir 8 caractères minimum.";
        return;
    }

    if (password !== confirmation) {
        erreur.textContent = "Les mots de passe ne correspondent pas.";
        return;
    }

    succes.textContent = "Inscription validée !";
});
À comprendre :
  • submit détecte l'envoi du formulaire.
  • preventDefault() empêche le rechargement automatique.
  • value récupère les informations saisies.
  • trim() élimine les espaces inutiles.
  • return arrête la fonction si une vérification échoue.
  • textContent affiche un message.

Les Promises

Une Promise représente le résultat futur d'une opération asynchrone. Elle peut être en attente, réussie ou rejetée.

JavaScript
const operation = new Promise(function(resolve, reject) {

    let succes = true;

    if (succes) {
        resolve("Opération réussie");
    } else {
        reject("Opération échouée");
    }

});

    .then(resultat => {
        console.log(resultat);
    })
    .catch(erreur => {
        console.log(erreur);
    });

resolve() valide l'opération. reject() signale un échec. then() traite le résultat. catch() traite le rejet.

JavaScript
function attendre() {
    return new Promise(resolve => {
        setTimeout(() => {
            resolve("Terminé");
        }, 1000);

async function executer() {

    console.log("Début");

    const resultat = await attendre();

    console.log(resultat);
}

executer();

async déclare une fonction asynchrone. await attend le résultat d'une Promise dans un contexte autorisé, sans bloquer le navigateur.

23. Fetch API et communication avec un serveur

Fetch permet d'effectuer des requêtes HTTP pour envoyer ou récupérer des données depuis une API.

Récupérer des données

JavaScript
async function chargerUtilisateurs() {

    try {

            "https://jsonplaceholder.typicode.com/users"

        console.error(erreur.message);

chargerUtilisateurs();

fetch() envoie une requête. response.ok indique si la réponse HTTP est dans la plage de succès. response.json() lit et transforme le corps JSON.

Envoyer des données avec POST

JavaScript
async function ajouterUtilisateur() {

    const utilisateur = {
        nom: "Mohamed",
        age: 20
    };

    try {

        const reponse = await fetch(
            "https://jsonplaceholder.typicode.com/users",
            {
                method: "POST",

                },

                body: JSON.stringify(utilisateur)
            }
        );

            throw new Error("Erreur d'envoi");
        }

        const resultat = await reponse.json();

        console.log(resultat);

    } catch (erreur) {

        console.error(erreur);

    }
}

method définit la méthode HTTP. headers définit les informations de la requête. body contient les données envoyées. JSON.stringify() transforme l'objet en JSON.

24. Gestion des erreurs

Une erreur peut apparaître lorsqu'une instruction est incorrecte, lorsqu'une donnée manque ou lorsqu'une opération échoue.

26. Sécurité JavaScript

La sécurité est indispensable dans les applications Web, particulièrement lorsque les utilisateurs saisissent des informations.

1. Éviter les injections HTML

Bonne pratique
const message = document.getElementById("message");

message.textContent = valeurUtilisateur;

Utilisez textContent pour afficher du texte non fiable plutôt que de l'interpréter comme du HTML.

2. Ne pas faire confiance aux données reçues

Une donnée envoyée par un formulaire peut être modifiée par l'utilisateur. Le serveur doit toujours vérifier les valeurs.

3. Protéger les informations sensibles

Ne mettez pas de clés secrètes, mots de passe ou jetons privés directement dans le code JavaScript exécuté dans le navigateur.

4. Utiliser des méthodes sûres

  • Privilégier textContent pour le texte utilisateur.
  • Valider les données côté serveur.
  • Éviter eval() avec des données externes.
  • Utiliser HTTPS pour les communications sensibles.
  • Contrôler les autorisations sur le serveur.

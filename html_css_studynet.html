1. Commencer depuis zéro

HTML décrit le contenu d'une page : titres, paragraphes, images, liens, formulaires… CSS décore ce contenu : couleurs, tailles, alignement, espacements et disposition.

HTML = structure

<h1>Bonjour !</h1>\n<p>Bienvenue sur mon site.</p>

Bonjour !

Bienvenue sur mon site.

CSS = apparence

h1 { color: royalblue; }

Bonjour !

Le titre est maintenant bleu.

Pour tester : copie le code dans un fichier nommé index.html, puis ouvre-le avec Chrome, Edge ou Firefox. Dans cette page, tu peux aussi écrire du code dans l'atelier et cliquer sur « Exécuter ».

Les trois parties d'une page

<!doctype html> <!-- annonce HTML5 --> <html lang="fr"> <head> <!-- informations invisibles et CSS --> <meta charset="UTF-8"> <title>Ma page</title> </head> <body> <!-- contenu visible --> <h1>Bonjour</h1> <p>Ma première page web.</p> </body> </html>

2. Structure HTML et règles importantes

Une balise

<p> commence un paragraphe et </p> le termine.

<p>Mon texte</p>

Mon texte

Un élément

L'élément comprend la balise ouvrante, le contenu et souvent la balise fermante.

<strong>Important</strong>
Important

Un attribut

Il ajoute une information dans la balise.

<a href="https://example.com">Visiter</a>
Visiter
Attention : les balises img, br, hr, input et meta n'ont normalement pas de balise fermante en HTML. Écris les noms d'attributs et les valeurs entre guillemets lorsque c'est nécessaire.

4. Attributs HTML fréquents

Un attribut global peut être utilisé sur de nombreux éléments. Exemple : class="carte" permet de cibler plusieurs éléments avec CSS, tandis que id="menu" doit être unique dans la page.

5. Comprendre CSS

Une règle CSS contient un sélecteur, puis des déclarations entre accolades. Chaque déclaration contient une propriété et une valeur.

p { /* sélecteur : tous les paragraphes */ color: #1d4ed8; /* propriété : color ; valeur : bleu */ font-size: 18px; /* taille du texte */ }

Voilà le résultat : texte bleu de 18 pixels.

Trois façons d'ajouter du CSS

CSS externe (recommandé)

<link rel="stylesheet" href="style.css">

Dans le fichier HTML, à l'intérieur de head.

CSS interne

<style> p { color: blue; } </style>

Dans la balise style du fichier HTML.

CSS en ligne

<p style="color:blue">Salut</p>

Directement sur un élément, à limiter pour les grands projets.

9. Glossaire rapide

Balise

Mot entre chevrons, par exemple <p>.

Attribut

Information ajoutée dans une balise, par exemple href.

Sélecteur

Indique à quels éléments CSS s'applique, par exemple .carte.

Propriété

Ce que l'on veut modifier, par exemple color.

Valeur

Le réglage choisi, par exemple blue.

Responsive

Une page qui s'adapte aux petits et grands écrans.

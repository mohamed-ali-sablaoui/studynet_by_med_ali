Important : les algorithmes ci-dessous utilisent une notation pédagogique en français : Lire, Écrire, Si, Pour, etc. Selon l'enseignant, les mots exacts peuvent varier, mais la logique reste la même.

Introduction à la programmation

Comprendre le problème, l'algorithme et le programme.

1. Qu'est-ce qu'un algorithme ?

Un algorithme est une suite finie d'étapes logiques qui permet de résoudre un problème. Il reçoit éventuellement des données, effectue des traitements, puis produit un résultat.

Entrées
Les données fournies au programme : par exemple deux nombres a et b.
Traitement
Les opérations appliquées aux données : par exemple calculer s = a + b.
Sorties
Les résultats affichés ou enregistrés : par exemple la somme s.
Programme C
La traduction de l'algorithme dans le langage C, avec sa syntaxe.

2. Exemple : calculer la somme de deux entiers

Algorithme
Algorithme Somme
Variables
  a, b, s : entier
Début
  Lire(a, b)
  s ← a + b
  Écrire(s)
Fin
Langage C
#include <stdio.h>

int main(void) {
    int a, b, s;
    scanf("%d %d", &a, &b);
    s = a + b;
    printf("Somme = %d\\n", s);
    return 0;
}

Explication : on réserve trois variables entières. On lit deux valeurs, on additionne ces valeurs, puis on affiche la somme. En C, chaque instruction se termine généralement par un point-virgule ;.

01

Variables, constantes et types

Déclarer, initialiser, modifier et choisir le type d'une donnée.

1. Définition d'une variable

Une variable est une zone mémoire identifiée par un nom. Elle possède un type qui détermine les valeurs qu'elle peut représenter. Sa valeur peut changer pendant l'exécution.

Déclaration en C
int age;             // déclaration
age = 20;            // affectation
float moyenne = 14.5f; // déclaration + initialisation
char lettre = 'A';   // un seul caractère

Déclarer signifie annoncer l'existence d'une variable. Initialiser signifie lui donner sa première valeur. Une variable locale non initialisée ne doit pas être utilisée avant d'avoir reçu une valeur.

2. Les types les plus utilisés

Type CUtilisationExempleFormat courant
intEntierint n = 12;%d
floatRéel en précision simplefloat x = 3.5f;%f
doubleRéel en précision plus élevéedouble pi = 3.14159;%f avec printf
charUn caractèrechar c = 'Z';%c
_Bool / boolValeur logique (0 ou 1)#include <stdbool.h>
bool ok = true;		%d pour afficher sa valeur numérique

3. Règles de nommage

  • Un nom peut contenir des lettres, des chiffres et le caractère _.
  • Il ne doit pas commencer par un chiffre : note1 est correct, 1note ne l'est pas.
  • Les espaces et les accents sont à éviter dans les identifiants.
  • Le C distingue les majuscules des minuscules : age et Age sont deux noms différents.
  • Un mot réservé comme int ou while ne peut pas servir de nom.

4. Constantes

Une constante représente une valeur qu'on ne souhaite pas modifier pendant le programme. En C, on peut utiliser const.

Algorithme
Constante
  TVA = 0.19
Variables
  prixHT, prixTTC : réel
Début
  Lire(prixHT)
  prixTTC ← prixHT * (1 + TVA)
  Écrire(prixTTC)
Fin
Langage C
#include <stdio.h>

int main(void) {
    const float TVA = 0.19f;
    float prixHT, prixTTC;
    scanf("%f", &prixHT);
    prixTTC = prixHT * (1 + TVA);
    printf("Prix TTC = %.2f\\n", prixTTC);
    return 0;
}
À retenir : %.2f affiche un réel avec deux chiffres après la virgule. Dans une expression, * signifie la multiplication.

Entrées et sorties : Lire, Écrire, scanf, printf

Communiquer avec l'utilisateur.

1. Afficher avec printf

La fonction printf(), déclarée dans stdio.h, affiche du texte et des valeurs. Les marqueurs de format indiquent le type de la valeur à afficher.

Affichage
printf("Bonjour !\\n");
printf("Age : %d\\n", age);
printf("Moyenne : %.2f\\n", moyenne);
printf("Lettre : %c\\n", lettre);

\n provoque un retour à la ligne. Le texte entre guillemets est affiché tel quel, sauf les séquences spéciales comme \n et les marqueurs comme %d.

2. Lire avec scanf

La fonction scanf() lit des données saisies au clavier. Pour une variable simple, on passe généralement son adresse à l'aide de &.

Algorithme
Variables
  age : entier
  nom : chaîne
Début
  Écrire("Votre âge ?")
  Lire(age)
  Écrire("Âge = ", age)
Fin
Langage C
#include <stdio.h>

int main(void) {
    int age;
    printf("Votre age ? ");
    if (scanf("%d", &age) == 1) {
        printf("Age = %d\\n", age);
    }
    return 0;
}

Attention : pour lire un caractère après un nombre, écris souvent scanf(" %c", &c) : l'espace avant %c permet d'ignorer les espaces et retours à la ligne restés dans l'entrée. Pour lire une phrase avec des espaces, préfère fgets().

3. Affectation

x = 5; affecte la valeur 5 à x. Ce n'est pas la même chose que x == 5, qui vérifie si x vaut 5. Les formes x += 2, x -= 1, x++ et x-- permettent de modifier une variable.

Algorithme

produit ← a * b

FinSi

scanf("%d%d", &a, &b);

    quotient = (float)a / b;
}
Erreur fréquente : ne jamais écrire if (x = 5) pour comparer. Il faut écrire if (x == 5).

04

Conditions : Si, Sinon Si, Sinon

Exécuter des instructions selon une condition.

1. Condition simple

Une condition est une expression logique qui est vraie ou fausse. La structure conditionnelle permet de choisir les instructions à exécuter selon le résultat.

Algorithme
Lire(note)
Si note >= 10 Alors
  Écrire("Admis")
FinSi
Langage C
scanf("%f", ¬e);
if (note >= 10) {
    printf("Admis\\n");
}

2. Si / Sinon

Algorithme
Lire(n)
Si n mod 2 = 0 Alors
  Écrire("Pair")
Sinon
  Écrire("Impair")
FinSi
Langage C
int n;
scanf("%d", &n);
if (n % 2 == 0) {
    printf("Pair\\n");
} else {
    printf("Impair\\n");
}

L'opérateur % calcule le reste. Si le reste de la division par 2 est zéro, le nombre est pair ; sinon, il est impair.

3. Plusieurs cas avec Sinon Si

Algorithme
Lire(note)
Si note < 0 OU note > 20 Alors
  Écrire("Note invalide")
Sinon Si note >= 16 Alors
  Écrire("Très bien")
Sinon Si note >= 14 Alors
  Écrire("Bien")
Sinon Si note >= 10 Alors
  Écrire("Admis")
Sinon
  Écrire("Refusé")
FinSi
Langage C
if (note < 0 || note > 20) {
    printf("Note invalide");
} else if (note >= 16) {
    printf("Tres bien");
} else if (note >= 14) {
    printf("Bien");
} else if (note >= 10) {
    printf("Admis");
} else {
    printf("Refuse");
}
Pourquoi cet ordre ? On vérifie d'abord les notes les plus élevées. Dès qu'une condition est vraie, son bloc s'exécute et les autres branches sont ignorées. Il faut aussi traiter les valeurs invalides.

4. Conditions imbriquées

Une condition imbriquée est une condition placée à l'intérieur d'une autre. Elle est utile lorsque le deuxième test ne doit être effectué que si le premier est satisfait.

Exemple : accès autorisé
if (age >= 18) {
    if (aCarte == 1) {
        printf("Acces autorise\\n");
    } else {
        printf("Carte necessaire\\n");
    }
} else {
    printf("Age insuffisant\\n");
}

Selon en algorithmique et switch en C

Choisir entre plusieurs valeurs discrètes.

La structure Selon est pratique quand une variable peut prendre plusieurs valeurs distinctes, comme un numéro de mois ou un choix de menu. En C, on utilise switch.

Algorithme
Lire(choix)
Selon choix Faire
  1 : Écrire("Ajouter")
  2 : Écrire("Modifier")
  3 : Écrire("Supprimer")
  4 : Écrire("Quitter")
  Sinon : Écrire("Choix invalide")
FinSelon
Langage C
switch (choix) {
  case 1:
    printf("Ajouter");
    break;
  case 2:
    printf("Modifier");
    break;
  case 3:
    printf("Supprimer");
    break;
  case 4:
    printf("Quitter");
    break;
  default:
    printf("Choix invalide");
}

Rôle de break et default

  • case correspond à une valeur possible.
  • break sort du switch. Sans lui, l'exécution peut continuer dans le cas suivant.
  • default s'exécute si aucune valeur ne correspond.
Limite : en C, les étiquettes case doivent utiliser des constantes entières ou des valeurs compatibles, pas des chaînes de caractères. Pour tester des intervalles comme « note entre 10 et 12 », une structure if / else if est généralement plus adaptée.

Exemple : mois en lettres

mois.c
int mois;
scanf("%d", &mois);
switch (mois) {
    case 1: printf("Janvier"); break;
    case 2: printf("Fevrier"); break;
    case 3: printf("Mars"); break;
    case 4: printf("Avril"); break;
    case 5: printf("Mai"); break;
    case 6: printf("Juin"); break;
    case 7: printf("Juillet"); break;
    case 8: printf("Aout"); break;
    case 9: printf("Septembre"); break;
    case 10: printf("Octobre"); break;
    case 11: printf("Novembre"); break;
    case 12: printf("Decembre"); break;
    default: printf("Numero invalide");
}

Structures répétitives : Pour, Tant que, Répéter

Répéter des instructions sans recopier le même code.

1. Boucle Pour / for

On utilise for quand le nombre de répétitions est connu ou contrôlé par un compteur. La boucle comprend une initialisation, une condition et une mise à jour.

Algorithme
somme ← 0
Pour i de 1 à 5 Faire
  somme ← somme + i
FinPour
Écrire(somme)
Langage C
int somme = 0;
for (int i = 1; i <= 5; i++) {
    somme = somme + i;
}
printf("Somme = %d", somme);

Le compteur i prend les valeurs 1, 2, 3, 4 et 5. La somme finale vaut 15. L'expression i++ augmente le compteur de 1.

2. Boucle Tant que / while

La condition est testée avant chaque tour. Si elle est fausse dès le départ, le bloc peut ne jamais s'exécuter.

Algorithme
Lire(n)
Tant que n < 0 Faire
  Écrire("Recommencez")
  Lire(n)
FinTantQue
Langage C
int n;
scanf("%d", &n);
while (n < 0) {
    printf("Recommencez : ");
    scanf("%d", &n);
}

3. Répéter ... Jusqu'à / do ... while

Cette structure exécute le bloc au moins une fois, puis teste la condition. En C, do...while continue tant que la condition est vraie, alors que le pseudo-code « Répéter jusqu'à condition » s'arrête lorsque la condition devient vraie : il faut donc inverser la condition lors de la traduction.

Algorithme
Répéter
  Lire(code)
Jusqu'à code = 1234
Langage C
int code;
do {
    printf("Code : ");
    scanf("%d", &code);
} while (code != 1234);

4. Calculer une factorielle

La factorielle de N, notée N!, est le produit des entiers de 1 à N. Par convention, 0! = 1. Cet exemple montre l'accumulation dans une boucle.

Algorithme
Lire(N)
fact ← 1
Pour i de 1 à N Faire
  fact ← fact * i
FinPour
Écrire(fact)
Langage C
int n;
long long fact = 1;
scanf("%d", &n);
if (n < 0 || n > 20) {
    printf("Valeur invalide");
} else {
    for (int i = 1; i <= n; i++)
        fact *= i;
    printf("%d! = %lld", n, fact);
}
Attention aux boucles infinies : assure-toi que la condition finira par devenir fausse. Dans un while (i < 10), si i n'augmente jamais, la boucle ne se termine pas.

5. Quelle boucle choisir ?

StructureÀ utiliser quand…Test
forLe nombre de tours est connu ou un compteur est naturel.Avant le tour
whileOn répète tant qu'une condition est vraie.Avant le tour
do...whileLe bloc doit s'exécuter au moins une fois.Après le tour

Tableaux à une et deux dimensions

Stocker plusieurs valeurs du même type dans une seule structure.

1. Définition et indices

Un tableau contient un nombre fixe d'éléments de même type. En C, les indices commencent à 0. Pour un tableau de 5 éléments, les indices valides sont 0, 1, 2, 3 et 4.

Déclarer et remplir
int notes[5] = {12, 15, 9, 17, 14};
printf("Premiere note = %d", notes[0]);
notes[2] = 10; // modifier le troisième élément

2. Saisir et afficher un tableau

Algorithme
Variables
  T : tableau[0..4] d'entiers
  i : entier
Pour i de 0 à 4 Faire
  Lire(T[i])
FinPour
Pour i de 0 à 4 Faire
  Écrire(T[i])
FinPour
Langage C
int T[5];
for (int i = 0; i < 5; i++) {
    printf("T[%d] = ", i);
    scanf("%d", &T[i]);
}
for (int i = 0; i < 5; i++) {
    printf("%d ", T[i]);
}

3. Somme et moyenne

Algorithme
somme ← 0
Pour i de 0 à 4 Faire
  somme ← somme + T[i]
FinPour
moyenne ← somme / 5.0
Écrire(somme, moyenne)
Langage C
int somme = 0;
for (int i = 0; i < 5; i++) {
    somme += T[i];
}
double moyenne = somme / 5.0;
printf("Somme=%d, moyenne=%.2f",
       somme, moyenne);

4. Maximum et minimum

On initialise le maximum avec le premier élément, puis on compare les éléments suivants. Évite d'initialiser le maximum à zéro : si toutes les valeurs sont négatives, le résultat serait incorrect.

Recherche du maximum
int T[5] = {4, -2, 15, 7, 9};
int max = T[0];
for (int i = 1; i < 5; i++) {
    if (T[i] > max) {
        max = T[i];
    }
}
printf("Maximum = %d", max);

5. Tableau à deux dimensions (matrice)

Une matrice est un tableau de lignes et de colonnes. Pour accéder à un élément, on utilise deux indices : M[i][j].

Algorithme
Pour i de 0 à 1 Faire
  Pour j de 0 à 2 Faire
    Lire(M[i][j])
  FinPour
FinPour
Langage C
int M[2][3];
for (int i = 0; i < 2; i++) {
    for (int j = 0; j < 3; j++) {
        scanf("%d", &M[i][j]);
    }
}
Erreur classique : si le tableau a 5 éléments, n'accède pas à T[5]. Cet indice dépasse la dernière position valide, qui est T[4]. Le C ne vérifie pas automatiquement les limites des tableaux.

Chaînes de caractères

Stocker et manipuler des mots et des phrases en C.

1. Une chaîne en C

Le C ne possède pas un type chaîne natif comme certains langages. Une chaîne est généralement un tableau de caractères terminé par le caractère spécial '\0', appelé caractère nul. Il marque la fin de la chaîne.

Déclaration
char prenom[20] = "Sami";
// En mémoire : 'S' 'a' 'm' 'i' '\0' ...
printf("Bonjour %s", prenom);

Le tableau doit avoir suffisamment de place pour les caractères et le caractère final \0. Par exemple, le texte "Sami" nécessite 5 cases.

2. Lire une chaîne

scanf("%s", nom) s'arrête au premier espace. Pour lire une ligne contenant des espaces, utilise fgets().

Lecture sûre d'une ligne
#include <stdio.h>
#include <string.h>

int main(void) {
    char nom[80];
    printf("Votre nom complet : ");
    if (fgets(nom, sizeof nom, stdin) != NULL) {
        nom[strcspn(nom, "\\n")] = '\0';
        printf("Bonjour %s !\\n", nom);
    }
    return 0;
}

sizeof nom indique la capacité du tableau. strcspn(nom, "\n") trouve la position du retour à la ligne s'il est présent, puis on le remplace par \0.

3. Fonctions de string.h

FonctionRôleExemple
strlen(s)Longueur sans compter \0strlen("Salut") vaut 5
strcmp(a,b)Comparer deux chaînesRenvoie 0 si elles sont égales
strcpy(dest,src)Copier une chaîneLa destination doit être assez grande
strcat(dest,src)Ajouter une chaîne à la finLa destination doit avoir assez de place

Ces fonctions nécessitent #include <string.h>. On ne compare pas deux chaînes avec == : on utilise généralement strcmp().

4. Exemple : compter les voyelles

Algorithme
Lire(texte)
nb ← 0
Pour i de 0 à longueur(texte)-1 Faire
  c ← minuscule(texte[i])
  Si c est une voyelle Alors
    nb ← nb + 1
  FinSi
FinPour
Écrire(nb)
Langage C
#include <stdio.h>
#include <ctype.h>
#include <string.h>

int main(void) {
    char texte[200];
    int nb = 0;
    fgets(texte, sizeof texte, stdin);
    for (int i = 0; texte[i] != '\0'; i++) {
        char c = (char)tolower((unsigned char)texte[i]);
        if (c=='a'||c=='e'||c=='i'||c=='o'||c=='u'||c=='y')
            nb++;
    }
    printf("Voyelles = %d", nb);
    return 0;
}
Note : cet exemple compte les voyelles latines non accentuées. La gestion complète des caractères accentués dépend de l'encodage et nécessite un traitement supplémentaire.

Fonctions et procédures

Découper un programme en blocs réutilisables.

Une fonction reçoit éventuellement des paramètres, effectue un traitement et peut renvoyer une valeur. En algorithmique, certains cours distinguent fonction (renvoie une valeur) et procédure (effectue une action sans valeur de retour).

1. Fonction qui calcule le carré

Algorithme
Fonction Carre(x : réel) : réel
Début
  Retourner x * x
Fin

Début principal
  Lire(n)
  Écrire(Carre(n))
Fin
Langage C
double carre(double x) {
    return x * x;
}

int main(void) {
    double n;
    scanf("%lf", &n);
    printf("%.2f", carre(n));
    return 0;
}

2. Les parties d'une fonction

  • Type de retour : ici double, car la fonction renvoie un réel.
  • Nom : carre, qui décrit son rôle.
  • Paramètre : x, la valeur reçue par la fonction.
  • return : renvoie le résultat à l'endroit où la fonction est appelée.

3. Procédure sans valeur retournée

Afficher un message
void afficherBienvenue(void) {
    printf("Bienvenue sur StudyNet !\\n");
}

int main(void) {
    afficherBienvenue();
    return 0;
}

void signifie ici que la fonction ne renvoie pas de valeur. Le mot entre parenthèses (void) indique qu'elle ne reçoit aucun paramètre.

4. Prototype et ordre

En C, une fonction doit être déclarée ou définie avant son utilisation. On peut écrire un prototype au début du fichier, puis la définition plus bas :

Prototype
int maximum(int a, int b);  // prototype

int main(void) {
    printf("%d", maximum(7, 4));
    return 0;
}

int maximum(int a, int b) {
    if (a > b) return a;
    return b;
}

Introduction aux pointeurs

Comprendre les adresses mémoire et le passage par adresse.

Un pointeur est une variable qui contient l'adresse mémoire d'un autre objet. L'opérateur & donne l'adresse d'une variable ; l'opérateur *, lorsqu'il est utilisé sur un pointeur valide, permet d'accéder à la valeur située à cette adresse.

Pointeur simple
int x = 10;
int *p = &x;  // p contient l'adresse de x
printf("%d", *p); // affiche 10
*p = 25;      // modifie x via le pointeur
printf("%d", x);  // affiche 25

Modifier deux variables dans une fonction

Algorithme
Procédure Echanger(a, b)
  temporaire ← a
  a ← b
  b ← temporaire
FinProcédure

L'algorithme modifie directement les deux paramètres selon la notation choisie.

Langage C
void echanger(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

int main(void) {
    int x = 2, y = 9;
    echanger(&x, &y);
    printf("%d %d", x, y); // 9 2
    return 0;
}
Prudence : ne déréférence pas un pointeur non initialisé ou nul. Un pointeur incorrect peut provoquer un comportement indéfini ou faire planter le programme.

Fichiers : lire et écrire

Conserver des données après la fin du programme.

Les fonctions de gestion de fichiers sont déclarées dans stdio.h. Le type FILE * représente un flux de fichier. Il faut vérifier que l'ouverture a réussi et fermer le fichier après utilisation.

ModeSignification
"r"Lire un fichier existant
"w"Écrire ; crée ou remplace le contenu existant
"a"Ajouter à la fin du fichier

#include <stdio.h>

fopen ouvre le fichier, fprintf écrit dedans, fclose le ferme. Le fichier est créé dans le répertoire de travail du programme, selon la configuration de l'environnement.

Exercice 3 — Factorielle

Lire N et calculer N! en vérifiant que N est entre 0 et 20.

Afficher la correction et l'explication
Algorithme
Lire(N)
Si N < 0 OU N > 20 Alors
  Écrire("Valeur invalide")
Sinon
  fact ← 1
  Pour i de 1 à N Faire
    fact ← fact * i
  FinPour
  Écrire(fact)
FinSi
C
int n;
long long fact = 1;
scanf("%d", &n);
if (n < 0 || n > 20) {
    printf("Valeur invalide");
} else {
    for (int i = 1; i <= n; i++)
        fact *= i;
    printf("%lld", fact);
}

On utilise long long car les factorielles grandissent très vite. La limite 20 évite le dépassement de capacité de ce type sur les plateformes courantes.
